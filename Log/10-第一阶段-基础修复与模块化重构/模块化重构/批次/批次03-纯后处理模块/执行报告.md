# 批次 3 执行报告：纯后处理模块

## 结果

批次 3 已完成。英文/中文标点与大小写、句子合并、句内重复和句级重复算法已从四个 Core 抽取到无 GPU、无文件系统副作用的纯 domain 模块；四个 Preset 现在通过统一策略注册表选择处理链。旧 Core 函数名与调用方式保持兼容，模型加载、媒体发现、输出目录和写盘行为未改动。

本批没有执行 Git 暂存、提交、标签或推送，没有删除或修改 `.workbuddy`。

## 实现内容

新增 `src/whisper_subtitle/domain/postprocess/`：

| 文件 | 职责 |
|---|---|
| `english.py` | 英文大小写与标点规范化 |
| `chinese.py` | 中文标点规范化 |
| `segments.py` | 通用句子合并及中英文终止规则 |
| `repetition.py` | 句内和句级重复清理 |
| `strategies.py` | 可组合策略、注册表、查找与执行入口 |
| `__init__.py` | 稳定的 domain 导出面 |

Preset 与流程接线：

| Preset | 策略 ID | 处理链 |
|---|---|---|
| `en_v1` | `english_standard` | 英文大小写 → 英文标点 |
| `en_v2` | `english_anti_hallucination` | 英文大小写 → 英文标点 → 句级去重 |
| `cn` | `chinese_standard` | 中文标点 |
| `cn2` | `chinese_anti_hallucination` | 中文标点 → 句内去重 → 句级去重 |

四个 Core 仍导出原有后处理函数，但函数体仅转发到 domain 实现。AST 审计确认这些入口都是薄包装器，Core 中未发现复制的正则、专有名词表或后处理调用链。

## 兼容性处理

- 保留全部旧 Core 函数入口及参数/返回形式。
- 保留 GUI 后处理展示文案，避免界面行为变化。
- 保留四种 Preset 的原算法顺序与输出。
- 标准版输出、强制目录备份和桌面保存继续复用同一处理结果，路径与写入模式不变。
- 旧中文单引号映射存在历史解析缺陷。为满足本批“算法输出不变”，新实现精确保留该异常行为；应在后续独立行为修复批次中评估，不能混入纯重构提交。
