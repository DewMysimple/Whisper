## 1. 批次目标

建立无 GUI、长期运行、可复用模型的 Python Worker，并保持现有 CLI、PyQt5、四 preset、后处理、命名和默认输出行为独立可用。

## 2. 实现内容

### Worker 入口与传输

- 新增 `python -m whisper_subtitle worker` 和 `whisper-subtitle worker`。
- stdin 接收一行一个 UTF-8 Desktop IPC v1 command；stdout 只写一行一个协议 JSON。
- 普通日志和异常堆栈只写 stderr。
- Worker 启动发出 `worker.ready`，EOF 或 `worker.shutdown` 会取消剩余任务、等待安全边界并释放模型。
- 坏 JSON、非 command 消息、未知版本和命令异常返回稳定 error envelope，后续命令仍可继续处理。

### 协议运行时增补

- Desktop IPC v1 增加 `command.completed` 事件，为 health、environment、load/unload、cancel 和 shutdown 提供带 `request_id` 的机器可读成功响应。
- 这是首个运行时消费者出现前的最小增补；现有 command、task event 和 error shape 未改变。
- schema、Python enum、校验器和契约测试同步更新。

### 任务与模型生命周期

- stdin 命令线程持续接收 health、cancel、shutdown；独立 dispatcher 串行执行推理任务。
- 支持活动任务和排队任务取消，任务终态严格收敛到 completed、failed 或 cancelled。
- Worker 持有一个模型缓存；同模型连续任务复用同一实例。
- `--model-idle-timeout` 默认 900 秒；超时后删除模型引用并执行垃圾回收。
- 任务执行异常只结束对应任务，不终止 dispatcher 或污染下一任务。
- Windows 首次 faster-whisper/CTranslate2 惰性加载在 stdin 命令线程完成，避免主线程阻塞读取 stdin 时后台首次初始化卡住；之后推理仍在 dispatcher 中执行。

### 输入、参数和输出

- 去除路径首尾空白和一层成对双引号，不进行 shell 拆词。
- 文件与文件夹按来源顺序展开；文件夹内部保持递归排序；按 Windows 不区分大小写键稳定去重。
- 任一非法来源返回结构化错误，不静默丢弃。
- Worker 再次校验参数白名单和范围，以任务局部派生 preset，绝不写回四 preset 注册表。
- 任务创建时冻结最终生效参数快照。
- 支持兼容输出与自定义输出；自定义模式实现共享根目录下 `Text`/`Markdown`、独立目录覆盖和源 TXT 保留开关。
- `fail`、`auto_rename`、显式 `overwrite` 冲突策略在推理前规划；活动/排队任务之间也保留目标路径。
- TXT 与 Markdown 都继续使用同目录临时文件和 `os.replace` 原子写入。
- application 增加可选取消检查点；CLI/PyQt5 未传入取消探针时行为不变。
