## 3. 媒体统计与交互结果

Rust 测试构造嵌套目录，确认只递归计入 Worker 支持的媒体扩展名并忽略普通 TXT。空目录或没有支持媒体的目录返回无效输入。React 任务行和详情都使用 `mediaCount` / `task.queued.input_count` 显示真实总数。

Playwright 与 Vitest 确认：

- 输入操作默认不展示 Windows 路径文本框；
- 展开后输入框出现，整个带仍支持拖放；
- 标准版 `cn` / `en_v1` 的按钮与 `Ctrl + Enter` 都进入同一确认框；
- 防幻觉版 `cn2` / `en_v2` 不增加确认步骤；
- 弹窗存在时快捷键不会绕过确认；
- 任务接受后进入性能监控顶部；
- 所有重新转录入口先确认，并保留原历史。

## 4. Worker 日志结果

Rust 确定性测试输入真实协议形状，确认以下事件生成时间戳可读日志：

- `worker.ready`；
- `model.loading` / `model.ready`；
- `task.queued`；
- 每条 `task.progress`；
- `task.completed` / `task.failed` / `task.cancelled`；
- Worker error 与 stderr。

`command.completed` 不进入日志缓冲，200 行以上只保留最新 200 行。前端验证自动跟随、向上滚动暂停及回到底部恢复；浅色、深色和三档字号均通过截图/DOM 验收。复制与导出内容使用同一份 CRLF 文本；空缓冲禁用。

正式系统剪贴板和另存为路径已经通过 Tauri 插件生产编译，Bridge 调用与 UTF-8 文件写入通过自动化。由于本次无人操作可见原生对话框，仍需用户手动点一次“复制全部”和“导出 TXT”确认 Windows 交互体验。
