# 功能测试 003：本地模型切换与按任务模型冻结

测试日期：2026-07-22。  
状态：自动化、真实 turbo CUDA、冻结 Worker、正式 EXE 启动和浅/深 UI 验收通过；第二个真实模型待用户以后自行放入目录后补做 GPU 交叉验收。

## 1. 测试目标

验证新增模型工作台只管理真实本地模型，默认仍为 `large-v3-turbo`，并确保每个任务冻结提交时模型：运行中任务不被切换打断，排队任务按各自快照在任务边界切换，历史重试沿用原模型。

## 2. 测试范围与判定

- 六个固定模型 ID：`tiny`、`base`、`small`、`medium`、`large-v3`、`large-v3-turbo`；
- 托管目录与 Hugging Face 缓存精确匹配，缺少 `config.json` 或 `model.bin` 即判为不完整；
- `large-v3` 不得误命中 turbo；Mobius 与旧 Systran turbo 缓存都能精确识别；
- 空闲选择调用真实 `model.load`，忙碌选择只影响新任务；
- `transcription.start` 省略模型时兼容 turbo，提供模型时由 `task.queued` 原样回显并冻结；
- 任务列表、详情、重试确认和缺失模型拦截显示真实模型；
- 不联网下载、不引入模拟正式状态、不改变 Preset 和输出行为。

## 3. 自动化结果

- Python：`256 passed`，覆盖路径发现、环境检查、可选协议字段、旧请求回退、混合模型队列和加载失败；
- Rust：15 项通过、2 项按设计忽略，覆盖托管/HF 精确发现、旧 Systran turbo、Host 参数映射、目录与协议；
- 前端：Prettier、ESLint、TypeScript 全部通过，Vitest 27/27；
- Playwright：8/8，覆盖六卡工作台、忙碌等待生效、缺失禁用、浅/深主题、按钮对比度、现有任务与设置工作流；
- Vite production build 与 Tauri `--no-bundle` Release 构建通过。

## 4. 真实 Worker 与 CUDA

本机只存在一个真实模型：

- 模型：`large-v3-turbo`；
- 正式目录：`apps\desktop\src-tauri\target\release\models\large-v3-turbo`；
- 完整文件：5 个，总计 1,621,665,983 字节；
- 运行方式：NVIDIA CUDA / float16；
- 媒体：`tests\fixtures\chinese_short.wav`。

源码 Host 的显式 GPU 测试完成 Worker 启动、环境检查、真实模型加载、Worker 重启、性能指标和短媒体任务，结果 1/1 通过，输出 `build\batch17-source-gpu\chinese_short.txt/.md`。

PyInstaller 候选 Worker 随后直接使用正式模型目录执行：

1. `worker.ready`；
2. `model.load(large-v3-turbo)` → `model.ready`；
3. `transcription.start.model_id=large-v3-turbo`；
4. `task.queued.data.model_id=large-v3-turbo`；
5. `task.completed`，输出 TXT/MD；
6. `worker.shutdown`，进程返回 0。

冻结 Worker 输出位于 `build\batch17-candidate-gpu`。正式 EXE 最终又完成一次 Host/相邻 Worker 启动和退出烟测，无残留进程。

## 5. 第二模型边界

本批次没有下载第二个模型。`medium` 等第二模型的混合队列、任务冻结、延迟切换和失败恢复使用注入测试引擎与 Mock Bridge 验证，不冒充真实 GPU 结果。

以后用户自行把第二个完整 CTranslate2 模型放入 `应用目录\models\<model-id>` 后，应追加以下真实测试：

- 空闲 turbo → 第二模型 → turbo 预加载；
- turbo 与第二模型交错排队；
- 运行期间切换默认模型不改变在途任务；
- 模型目录在检查后移走时真实返回 `model.load_failed`；
- 两个模型各完成一条短媒体 CUDA 任务。

## 6. 结论

当前版本已达到第一版本地模型管理目标：真实磁盘决定安装状态，任务模型在提交时冻结，旧客户端和旧历史安全回退到 turbo，正式软件不联网、不下载、不删除模型。唯一待后续补充的是第二个真实模型到位后的 GPU 交叉验收，不影响当前 turbo 默认工作流。
