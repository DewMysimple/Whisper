# 功能测试 005：性能任务进度与历史日期筛选删除

测试日期：2026-07-22。  
状态：状态层、UI 自动化、响应式视觉、全量回归与正式 EXE 烟测全部通过。

## 1. 测试目标

验证性能监控可以简洁显示当前真实任务快照，同时让本机任务历史具备可靠年月日、有效日期范围筛选、终态单条删除和桌面两列浏览能力，并确保这些操作不会影响真实媒体或输出文件。

## 2. 判定标准

- 运行任务优先于排队任务；没有活动任务时显示空闲；
- 进度、阶段、耗时、媒体总数和当前媒体均来自任务快照；
- 进度卡与实时性能趋势卡宽度一致；
- 新任务时间可按本机时区显示完整年月日，旧 `HH:mm` 不伪造日期；
- 月历只允许选择有任务的日期，单日/跨日范围和状态/搜索可以叠加；
- 删除只适用于终态历史，确认后不删除源媒体、模型或输出；
- 活动任务即使直接调用状态层删除动作也必须保留；
- 任务工作台桌面两列，窄窗口单列，按钮不溢出；
- 键盘焦点、Escape、减少动态效果与减少透明度规则有效。

- `deleteTaskHistory()` 只过滤持久化任务快照；没有调用文件删除、移动、回收站或输出定位接口；
