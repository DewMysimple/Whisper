# 第 11 次修改：TXT/Markdown 路径规则与媒体旁副本

执行日期：2026-07-19。  
状态：输出契约、正式 React UI、冻结 Worker、真实 CUDA 输出、全量测试、Tauri Release 构建和桌面烟测均已完成；等待用户目视与实际任务验收。

## 1. 用户规则

用户明确要求：

- 未选择自定义输出路径时，TXT 直接输出到媒体旁自动创建的 `Text` 文件夹；Markdown 直接输出到媒体旁自动创建的 `Markdown` 文件夹，文件夹内部不再创建新的层级。
- 选择自定义输出路径后，TXT 与 Markdown 分别询问是否额外在媒体旁的 `Text` / `Markdown` 文件夹保存一份。
- 自定义路径卡片不能使用突兀的蓝色，需回到橙白体系；顶部“自选目录”状态可保留蓝色点缀。
- 使用 Apple Design 方法论做协调性修正，不重做整个输出区。
- 用户随后补充：“恢复默认位置”按钮也不得使用蓝色，本补充继续并入第 11 次修改，不另行编号。
- 用户进一步澄清：该按钮不是改成无色或中性灰，而是必须使用与整体协调的标志性橙色。

本次是正式软件第 11 次 UI/功能修改，仅修改 `F:\WhisperSubtitle`；没有修改第三阶段 `C:\Users\Administrator\Desktop\WhisperUI`。

## 2. 最终路径矩阵

假设媒体为 `D:\媒体\访谈.mp4`，自定义根目录为 `E:\转录输出`。

默认“跟随媒体”：

- TXT：`D:\媒体\Text\访谈.txt`
- Markdown：`D:\媒体\Markdown\访谈.md`

自定义目录的主要输出：

- TXT：`E:\转录输出\Text\访谈.txt`
- Markdown：`E:\转录输出\Markdown\访谈.md`

自定义目录下的可选媒体旁副本：

- 勾选“TXT 副本”：额外生成 `D:\媒体\Text\访谈.txt`
- 勾选“Markdown 副本”：额外生成 `D:\媒体\Markdown\访谈.md`

TXT 和 Markdown 的副本开关完全独立。没有勾选对应主要格式时，不会因为隐藏的旧状态生成该格式副本。默认模式的主要路径已经是媒体旁路径，因此不会再规划重复副本。

## 3. UI 与 Apple Design 约束

- “媒体旁副本”只在自定义目录、文本模式且至少启用 TXT/Markdown 时出现。
- TXT、Markdown 各显示一个明确问题和开关；默认均为关闭，用户主动选择后才生成额外文件。
- 选择自定义目录时，从默认路径进入自定义路径会清空旧副本选择，确保每次都由用户明确决定；更换另一个自定义文件夹时保留当前选择。
- 恢复默认位置会关闭并清空两个副本开关，避免下次自定义时静默复用。
- 副本控制紧邻受影响的格式，遵循 Apple Design 的 grouping/mapping、agency、predictability 和 forgiveness 原则；没有增加阻断式弹窗。
- 自定义路径卡片的边框、背景和路径框改为橙白体系；顶部“自选目录”状态保留蓝色点缀。
- “恢复默认位置”按钮使用正式 Token `--accent` 的标志性橙色（亮色主题 `#ff5b04`），白色卡面保持克制；悬停和键盘聚焦继续使用橙色反馈，不再出现蓝色。
- 位置按钮提供即时轻微按压反馈、明确 focus-visible；`prefers-reduced-motion` 下取消缩放反馈。
- UI 文案明确使用“文件夹，文件直接存放”，避免“子目录”被理解为继续创建嵌套层级。

## 4. 契约与实现

新增前端状态 `preserveSourceMarkdown`，与 `preserveSourceTxt` 独立冻结进任务。

Desktop IPC v1 增加可选字段 `preserve_source_markdown`，默认 `false`。这是向后兼容的可选扩展：旧请求不包含该字段时行为不变，`schema_version` 仍为 1。Rust Host 使用 serde 默认值接收旧形状，并把当前值转发给 Worker；Python 协议层只接受布尔值。

`OutputPlan` 新增 `backup_md`：

- 参与冲突预检、自动重命名、目录准备和原子 UTF-8 写入；
- TXT 副本仅在 TXT 主要输出启用时规划；
- Markdown 副本仅在 Markdown 主要输出启用时规划；
- 两个副本的内容分别与其主要输出完全一致。

没有修改 faster-whisper、CTranslate2、CUDA 推理、Preset 参数、防幻觉后处理、SRT 时间戳、文件基名或同名冲突语义。
