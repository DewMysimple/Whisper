## 4. 快捷键、自动跳转与通知

- 删除了 `App` 的全局键盘监听：不再响应 `Ctrl+O`、`Ctrl+Enter`、`Ctrl+0–4` 或全局 `Escape`；启动卡片也不再显示 `CTRL + ENTER`。
- 保留组件内部用于无障碍关闭浮层的局部键盘行为；它们不是软件级快捷键。
- 新任务和“重试任务”只有在 `desktopBridge.startTranscription` 成功返回后才切换到“性能监控”；前置校验失败或 Worker 拒绝时不会误跳转。
- `task.completed`、`task.failed`、`task.cancelled` 到达正式状态层后，会请求 Windows 任务栏注意提示，并通过 Tauri Notification 插件发送系统通知。
- 通知设置 `silent: false`，因此使用 Windows 当前通知声音策略；用户关闭系统声音、勿扰或通知权限时不会强行发声，也不会影响任务收尾。
- 失败通知使用关键注意级别，完成和取消使用信息级别；任何权限拒绝或通知 API 异常都会被隔离，不会把已结束任务重新标成失败。

Windows/Tauri 官方限制：系统 Toast 在 Windows 上以已安装应用为可靠运行前提。本轮遵守“不要生成安装程序或发布包”，因此没有伪造已安装环境，也没有把一次直接 EXE 的实际 Toast 弹出写成已验收。当前无安装包 EXE 仍具备任务栏注意提示后备路径；通知调用、权限拒绝和系统声音请求已由单元测试覆盖。实际 Toast/提示音需在未来用户明确授权安装包后，或由用户在其正式安装环境中完成目视/听觉验收。
