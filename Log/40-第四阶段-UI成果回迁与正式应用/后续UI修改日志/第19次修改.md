## 2. 性能监控任务进度

“实时性能趋势”下方新增与其等宽的“任务进度监视”卡：

- 优先显示 `running` 任务；没有运行任务时显示队首 `queued` 任务；
- 直接使用 `TaskSnapshot` 中的真实任务名称、阶段、百分比、耗时、媒体总数和当前输入路径；
- 其余排队任务只汇总为“另有 N 项等待”；
- 没有活动任务时显示明确空闲状态；
- 进度轨道提供正式 `progressbar` 语义，减少动态效果时取消宽度动画。

没有添加静态演示任务，也没有修改或扩展 Desktop IPC。正式 Tauri 模式下卡片只会显示 Worker 生命周期事件已经形成的任务快照。

## 3. 日期筛选、单条删除与两列布局

- 新提交任务的 `createdAt` 现在保存 ISO 8601 完整时间戳，界面按本机时区显示 `YYYY-MM-DD HH:mm`；
- schemaVersion 仍为 1；旧的 `HH:mm` 记录显示“日期未知”，只在“全部日期”下出现，不伪造日期；
- 内置月历只允许点击实际有任务的日期，支持单日或两次点击形成的起止范围；日期范围与状态、名称搜索共同过滤；
- 终态任务操作顺序为删除、重新转录、定位输出、查看详情；运行和排队任务没有删除入口；
- 删除前使用现有焦点约束确认框，明确说明只删除本机历史，不触碰源媒体、模型或输出文件；
- 状态层新增 `deleteTaskHistory(taskId)`，即使绕过 UI 也拒绝删除活动任务；删除当前详情任务时同步关闭详情并清空预览；
- 任务记录工作台在桌面宽度使用两列卡片，`1120px` 以下自动回落一列，其他页面的最近任务布局不受影响。

本轮新增 `TaskDateFilter` 和独立的 `taskHistory` 日期工具层。月历从筛选按钮原位展开，支持 Escape 返回触发控件、键盘焦点、减少动态效果和减少透明度偏好。
