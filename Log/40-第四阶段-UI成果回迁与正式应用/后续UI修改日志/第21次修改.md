## 3. 执行前确认跳过同名文件

输出冲突策略新增 `confirm_skip`：

- 首次提交沿用 Worker 的真实冲突预检，不创建失败任务历史；
- 确认框按源媒体分组展示冲突目标；
- 某一媒体只要任一目标文件冲突，确认后就整项跳过该媒体，不生成它的其他格式；
- 无冲突媒体继续进入同一任务；
- 全部媒体均冲突时不创建任务、不跳转工作台；
- 确认时重新执行预检，避免确认期间磁盘状态变化；
- 重试历史同样重新预检，不持久化本次跳过授权。

Python 输出层新增内部 `skip` 冲突策略和结构化 `media_paths` / `skipped_media` 数据。Desktop IPC 继续为 v1，只增加向后兼容的可选字段；旧客户端和既有 `overwrite`、`fail`、`rename` 行为保持不变。
