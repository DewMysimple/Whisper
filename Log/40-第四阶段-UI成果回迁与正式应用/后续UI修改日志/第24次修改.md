## 3. 界面与启动链路

### 3.1 休眠移除

- “执行完”只保留“无操作／关机”；
- `FinishAction` 收窄为 `none | shutdown`；
- 删除 Windows 休眠能力查询和 `SetSuspendState` 执行分支；
- Host 只接受 `shutdown`，旧的 `hibernate` 请求会被明确拒绝；
- 移除不再需要的 `Win32_System_Power` 构建能力。

### 3.2 错误横幅

- 顶部统一错误横幅出现 4.84 秒后开始短透明度淡出，并在 5 秒时清除；
- 手动关闭仍立即生效；
- 新错误替换旧错误时重新计时；
- 减少动态效果时取消淡出过程，保留五秒自动清除。

### 3.3 关机确认

新增冻结草稿 `PendingShutdownStart` 和主题化确认框：

- 标准版任务顺序为“标准版确认 → 关机确认 → 同名冲突确认 → 正式提交”；
- 防幻觉版本直接进入关机确认；
- 按钮与 `Ctrl + Enter` 使用同一链路，任一确认框开启时快捷键不能绕过；
- 取消关机确认保留媒体、参数、输出策略和“关机”选择；
- 同名冲突确认继续携带同一冻结草稿和一次性关机授权，并显示“执行完成：60 秒后关机”；
- Worker 接受任务后恢复“无操作”并进入性能监控顶部。

## 4. 系统通知

- 普通完成、失败和取消通知不再显示媒体或任务名称，第一行统一为“总耗时 MM:SS”；
- Windows Toast 改为长通知，继续使用 WhisperSubtitle 自有身份和蜘蛛侠圆形 Logo；
- 增加“返回 WhisperSubtitle”按钮；
- 点击通知正文或按钮都会尝试显示、取消最小化并聚焦主窗口，不自动切换工作台；
- 通知命令统一负责一次提示音，删除前端的第二次声音调用；
- 关机队列成功时，60 秒提示合并任务完成和总耗时，不再额外产生第五条完成通知；
- 30、15、5 秒阈值由 Rust Host 计时，使用去重集合确保每个阈值最多发送一次；
- 失败、取消、部分失败、新任务或手动取消继续解除关机。

通知权限、Windows 勿扰或焦点请求失败不会反向改变任务终态、输出文件或关机状态。
