### 翻译能力的实测收紧

原计划允许两个 V3 模型选择翻译。真实 CUDA 使用纯中文 20 秒媒体后确认：

- Large V3 能按 `task=translate` 输出英语。
- Large V3 Turbo 即使收到真实 `task=translate` 仍返回原语言。

这与 [OpenAI Whisper 官方说明](https://github.com/openai/whisper/blob/main/README.md)一致：Turbo 未针对翻译任务训练。为避免把原语言输出伪装成翻译成功，正式语义调整为：

- 只有 `Large V3 + en_v1/en_v2` 可选择“翻译为英语”。
- Turbo 参数页明确显示“Turbo 仅转录”，模型卡说明同步更新。
- UI 状态层、Rust Host、Python IPC、Preset 派生和 JSON Schema 一致拒绝 Turbo 翻译。
- 旧 Turbo 翻译参数档案自动迁回原声转录；历史 Turbo 翻译任务禁止重试/续接，并引导使用 Large V3。
- 不暗中替换任务模型，不调用联网翻译，不产生模拟成功状态。
