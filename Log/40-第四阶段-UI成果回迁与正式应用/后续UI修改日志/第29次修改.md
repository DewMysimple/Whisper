## 正式校准结论

固定候选矩阵覆盖：

- 语音块上限：6、8、12 秒；
- VAD 静音分隔：200、300、500 毫秒；
- 英语概率阈值：0.65、0.75、0.85。

最终采用 `8 秒 / 300 毫秒 / 0.75`。选择遵循“无中文误替换、英文锚点、中文 CER、运行时间”的固定顺序，不在产品中写入用户给出的验收时间段。

完整 429 秒媒体真实 CUDA 结果：

- Large V3 + cn2：中文 CER 从稳定模式 `10.6024%` 降至 `7.8916%`；可信英文区间恢复了 “baby are you busy…”, “I’m free…”, “can you come…” 和 “blessings / stories”等锚点。
- Large V3 Turbo + cn2：中文 CER 从 `11.5663%` 降至 `6.0241%`；可信英文片段被保留，低置信度 `like yourself` 类候选没有写入正文。
- V3 的高语速候选和两模型在约 219 秒附近的低置信度术语候选均只进入复核，没有为了提高命中率放宽安全门槛。
- 没有新增已知中文误替换、长循环、翻译式改写、替换字符或虚构术语。

矩阵、完整结果和术语对照位于 `build\batch29-validation`。
