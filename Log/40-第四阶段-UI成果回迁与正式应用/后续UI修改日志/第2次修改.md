## 3. 根因与正式映射

正式链路为：

`PerformanceStrip.tsx` → Tauri `worker_metrics` → Desktop IPC v1 `system.metrics` → Python `collect_performance_sample()` → NVML。

`performance.py` 通过 `importlib.import_module("pynvml")` 动态导入 NVML 绑定；原 `packaging/worker.spec` 只复制了 `nvidia-ml-py` 元数据，没有把动态导入模块 `pynvml` 声明为 PyInstaller hidden import。冻结版 Worker 因而无法导入该模块，并按既有容错逻辑把 GPU、显存和设备名保持为 `None`。前端据此正确显示 `— / 等待 NVML 采样`。

同一 Python 环境直接调用 NVML 能识别 `NVIDIA GeForce RTX 5070 Ti`，因此问题不是显卡、驱动、任务是否运行或 React 渲染错误，而是冻结 Worker 的打包遗漏。
