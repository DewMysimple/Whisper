## 2. 交互实现与 Windows 边界

Windows 标准文件对话框的文件模式与文件夹模式彼此独立：文件模式中的“打开”会进入文件夹，文件夹模式中的“打开”才会返回该文件夹。因此不能通过 Tauri 标准对话框把两种选择伪装成同一个系统模式。

正式实现采用一个常驻入口和两个短暂模式：

1. 输入区只显示一个 58×58px 的中心“+”交互卡片；原两个常驻按钮和输入帮助问号已移除。
2. 点击“+”后短暂展开“媒体文件 / 文件夹”来源模式，不改变输入卡片的常驻布局。
3. “媒体文件”调用现有 `selectFiles()`，Windows 对话框允许单选或多选，并保留媒体扩展名过滤。
4. “文件夹”调用现有 `selectDirectory()`，Windows 对话框限制单文件夹；点击“打开”即选中当前文件夹。
5. 点击外部或按 Escape 会关闭短暂模式；键盘焦点和可访问名称完整保留。
6. Tauri `onDragDropEvent` 仍接收文件和文件夹路径，经既有 `inspect_inputs` 真实检查后加入队列；新增拖入高亮状态不改变数据路径。
