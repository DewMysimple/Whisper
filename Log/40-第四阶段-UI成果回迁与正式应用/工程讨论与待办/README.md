## 归档规则

- 工程结构、构建产物、桌面入口、窗口行为等讨论可以记录在本目录。
- 只提出但尚未授权执行的 UI、功能和桌面外壳设想记录在本目录。
- 已明确取消的方案保留原因和恢复结果，避免未来误执行。
- 单纯答疑且没有形成长期约束、风险或待办时，不要求机械生成文件。
- 已经执行的 UI 修改不能只写在本目录，必须进入 `后续UI修改日志/第n次修改.md`。
- 某项待办以后获得实施授权时，保留原讨论文件，并在其中补充对应 `第n次修改.md` 的链接和最终状态。
- 讨论记录本身不占用 UI 修改编号。
