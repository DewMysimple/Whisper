## 1. 目标

在正式软件内提供受控的“开发者模式”，让用户不依赖 AI 也能在一定范围内：

- 调整 UI 与日志字体；
- 调整已登记组件的尺寸、内边距、间距、最小高度和分栏比例；
- 在真实工作台中点选组件并实时预览；
- 保存多个命名 UI 方案，并指定启动默认方案；
- 撤销、重做和恢复官方默认；
- 自动记录每次完成的调整，并导出 Markdown 日志；
- 导入、导出可移植的 UI 方案 JSON。

该模式只产生运行时 UI 配置，不允许正式软件直接修改 React、CSS 或其他工程源码。

## 3. 产品入口与交互

- 偏好设置新增“启用开发者模式”，默认关闭。
- 开启后侧栏显示独立“开发者模式”工作台。
- 首次启用时复制当前字体设置创建“我的方案 1”，避免界面突然变化。
- 关闭时退出检查模式，并恢复启用前保存的普通外观配置。
- 不新增全局快捷键；Escape 只负责退出当前组件选择或关闭确认状态。

开发者工作台包含：

- 方案管理；
- 全局字体与布局控制；
- “在界面中选择组件”；
- 当前组件检查器；
- 撤销、重做、保存、设为启动默认、恢复官方默认；
- 调整历史与 Markdown 导出。

检查模式在真实工作台中运行：

- 悬停注册组件时显示克制的橙色边界与组件名称；
- 选中后显示实际宽高及该组件允许调整的属性；
- 检查模式拦截组件内部操作，避免误启动任务或改变功能状态；
- 侧栏导航仍可使用，以便跨工作台选择组件；
- 遵守键盘焦点、减少动态效果和响应式规则。

## 5. 可调整属性与安全范围

全局属性：

- UI 字体与字号继续使用现有安全范围；
- 日志字体与字号继续使用现有安全范围；
- 页面内边距：`12–40px`；
- 网格间距：`8–32px`；
- 卡片圆角：`6–24px`；
- 侧栏宽度：`280–420px`；
- 内容最大宽度：`1100–1800px`。

组件属性：

- 字体缩放：`0.85–1.25`；
- 内边距：`8–40px`；
- 内部间距：`4–32px`；
- 最小高度：自动或 `80–960px`；
- 支持分栏的组件可使用 `0.6–2.4` 的列权重。

每个组件只显示注册表允许的属性。不开放：

- 隐藏关键组件；
- 拖拽重排；
- 任意 CSS；
- 任意 DOM 选择器；
- 修改功能状态或模拟 Worker 数据；
- 修改源码。

## 6. 方案模型

新增内部类型：

- `DeveloperUiProfile`
- `DeveloperUiTokenSet`
- `DeveloperComponentOverride`
- `DeveloperComponentDescriptor`
- `DeveloperChangeEntry`

规则：

- 提供不可修改的“官方默认”；
- 最多保存 20 个命名方案；
- 方案名称为 1–40 个字符且不可重复；
- 支持创建、复制、重命名、删除、导入和导出；
- 支持指定一个已保存方案为启动默认；
- 方案只管理字体与布局，不包含主题和强调色；
- 橙色继续由现有偏好设置作为默认强调色；
- 切换方案或离开未保存草稿时，使用主题化“保存／放弃／取消”确认框；
- 撤销与重做保留最近 50 个已完成操作。

导入配置使用独立 `schemaVersion: 1`，严格校验组件 ID、属性白名单与数值范围；不得覆盖内置官方默认。

## 7. 持久化与修改日志

开发者方案使用独立存储键：

`whisper-subtitle.developer-ui.v1`

这不是 Desktop Worker IPC v1 的变更。

Desktop Bridge 与 Rust Host 增加最小的开发者日志能力：

- 追加一条 UI 修改日志；
- 读取最近日志；
- 导出 Markdown；
- 返回日志写入状态。

日志通过 Tauri 应用数据目录保存为 UTF-8 JSONL。每条记录包含：

- ISO 8601 时间；
- 会话 ID；
- 方案 ID 与名称；
- 工作台与组件 ID；
- 属性名称；
- 调整前值与调整后值；
- 操作来源。

按钮调整每次记录；滑杆在松手或键盘操作结束时合并为一条。撤销、重做、保存、恢复、导入和方案切换也需要记录。

日志不得记录媒体路径、任务正文、模型文件路径或用户转录内容。

日志规则：

- 当前文件达到 5 MiB 时轮换；
- 最多保留 3 个历史文件；
- 工作台显示最近 500 条；
- 写入失败时保留本地待写队列并显示状态；
- 启动及后续操作自动重试，不得静默丢失；
- Markdown 默认文件名为 `WhisperSubtitle-DeveloperUI-YYYYMMDD-HHmmss.md`；
- 取消另存不报错。
