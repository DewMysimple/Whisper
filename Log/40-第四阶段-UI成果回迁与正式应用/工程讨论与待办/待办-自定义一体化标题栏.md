## 2. 当前代码事实

- `apps/desktop/src-tauri/tauri.conf.json` 当前使用 `"decorations": true`，所以 Windows 负责绘制原生标题栏。
- 正式 React 顶栏位于 `apps/web/src/App.tsx` 的 `.topbar`。
- 正式 `apps/web/src/styles.css` 中 `.topbar` 最终规则包含约 `116px` 最小高度、粘性定位、半透明背景、底部分隔和轻微阴影。
- 第三阶段 `C:\Users\Administrator\Desktop\WhisperUI\src\components\topbar.html` 与相关 CSS 只设计了应用内部顶栏，没有包含真实 Windows 非客户区。
- 因此正式程序中形成“Windows 原生标题栏 + React 顶栏”上下叠加。这是浏览器原型与桌面窗口外壳的上下文差异，不是第三阶段 HTML 文件识别错误。

## 3. 暂定设计方向

以后若用户批准，优先评估自定义一体化标题栏：

- 使用约 `36–40px` 的应用自绘标题栏替代当前默认 Windows 标题栏。
- 标题栏横跨整个窗口；左侧延续侧栏背景，右侧延续主画布或顶栏材质。
- 提供明确的可拖动区域。
- 右侧保留符合 Windows 使用习惯的最小化、最大化/还原和关闭按钮。
- 标题栏与 React 页面顶栏之间不叠加多余阴影或重复边界。
- 页面标题、状态、搜索和主题操作仍属于应用顶栏，不与窗口控制按钮争夺层级。

这只是当前建议方向，不是已经冻结的设计方案。最终视觉仍应以用户届时明确指定的第三阶段代码或桌面外壳设计为准，不能根据本记录直接实施。
