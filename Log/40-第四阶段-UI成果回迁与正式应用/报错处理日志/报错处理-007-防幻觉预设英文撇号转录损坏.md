# 报错处理 007：防幻觉预设英文撇号转录损坏

日期：2026-07-24。

状态：已修复；四 Preset 输出回归、UI→Host→Worker Preset 身份测试、真实 CUDA 双防幻觉预设验收、正式 Worker 字节码审计及启动烟测均已通过。

## 1. 用户可见现象

转录内容包含英文缩写或所有格时，ASCII 撇号及其后续字母被改写成代码状文本。例如：

```text
don't
```

会变成：

```text
don,
        "'": t
```

用户提供了以下两个错误示例：

- `C:\Users\Administrator\Desktop\有误文本1\错误示例1.md`
- `C:\Users\Administrator\Desktop\有误文本1\错误示例2.md`

用户确认问题需要同时按“中文防幻觉 `cn2`”和“英文防幻觉 `en_v2`”的验收范围处理。两个示例只作为回归证据，本轮没有扫描、覆盖或修复任何既有转录文件。

## 2. 根因与影响边界

`src\whisper_subtitle\domain\postprocess\chinese.py` 的中文标点替换表包含一条从旧 Core 抽取时保留的错误兼容规则：

```python
"'": ",\n        \"'\": "
```

它会无条件替换所有 ASCII 单引号，因此 `don't`、`couldn't`、`it's`、`I'll` 和 `John's` 都会稳定损坏。正式 Worker 的 PyInstaller `PYZ.pyz` 字节码中也确认存在同一常量，排除了“只改了源码、正式 Worker 没有包含”的可能。

当前注册表及正式 Worker 字节码显示：

- `cn2` 绑定 `chinese_anti_hallucination`；
- `en_v2` 绑定 `english_anti_hallucination`。

保留的本地任务快照中，原 Bilibili 视频任务记录为 `cn2`；用户同时确认错误示例来自 `en_v2`。鉴于运行证据与用户复现描述存在差异，本轮没有只按静态注册表缩小范围，而是增加了 UI、Rust Host、Worker 及真实输出的完整身份链路测试，并分别真实验收 `cn2` 和 `en_v2`。

本问题属于确定性的文本后处理错误，不是 faster-whisper 识别、模型、CTranslate2、CUDA、智能分行或防幻觉参数错误。

## 3. 修复

### 3.1 删除错误替换

从中文标点替换表中删除上述 `'` 映射：

- ASCII 撇号 `'` 原样保留；
- 弯撇号 `’` 原样保留；
- 两者不自动互换；
- 其余中文逗号、句号、问号、括号等既有规范化保持不变；
- 中文与英文防幻觉重复清理保持不变。

### 3.2 冻结 Preset 身份回归

新增三层回归门禁：

- 前端选择 `en_v2` 后，提交草稿的 `basePresetId` 必须仍为 `en_v2`；
- Rust Host 生成 Worker 请求时必须原样传递 `base_preset_id=en_v2`；
- Worker 分别以 `cn2`、`en_v2` 执行相同缩写文本，真实推理语言参数必须分别为 `zh`、`en`，输出不得包含错误固定串。

没有扩展 Desktop IPC v1，也没有新增运行时字段。
