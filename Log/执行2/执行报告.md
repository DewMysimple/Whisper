# 执行2 修改与验证报告

## 执行结论

`Requirement/执行2.md` 中四批任务已全部完成。项目现已收敛为标准 `src` 布局的 Python 包，统一 CLI、模块入口、结构化日志、Qt 文件对话框和设置持久化均可用；新建虚拟环境在 RTX 5070 Ti 上完成了真实音频回归，转录结果与修改前逐字节一致。

## 完成内容

### 1. Python 包结构

- 新增 setuptools `pyproject.toml`，项目名为 `whisper_subtitle`。
- 源码迁移至 `src/whisper_subtitle/`，包含 `core`、`gui`、`utils` 三个子包及各级 `__init__.py`。
- 删除旧的 `src/core`、`src/gui`、`src/utils` 源目录。
- 移除 `sys.path.insert` / `sys.path.append`，包内改用相对导入。
- `launch.vbs` 已改为模块方式运行环境检查和 GUI。
- `python -m whisper_subtitle` 可正常启动 GUI。

### 2. 统一 CLI 与日志

- 新增 console script：`whisper-subtitle`。
- 支持以下入口：
  - `whisper-subtitle transcribe <input> [-o OUTPUT] [--preset {cn,cn2,en,en2}]`
  - `whisper-subtitle gui`
  - `whisper-subtitle check`
- 四个原有 Core `main()` 保留，由 CLI 按 preset 分发。
- 包初始化时配置标准 `logging`。
- 已清除静默异常处理；AST 检查确认单一 `pass` 异常处理器数量为 0。
- Windows 控制台遇到无法编码的 Unicode 字符时不再因 `UnicodeEncodeError` 崩溃。

### 3. GUI 收敛

- 所有 tkinter 文件/目录选择框已替换为 Qt `QFileDialog`。
- `QSettings` 会持久化并恢复：
  - 输入路径；
  - 输出路径；
  - GUI preset；
  - 窗口位置和大小。
- 保留执行1中的异步停止、超时强制终止和关闭生命周期修复。

### 4. 依赖与环境

- `requirements.txt` 已从 freeze 快照改为顶层声明式依赖。
- 已移除未使用的 `funasr`、`ttkbootstrap` 及间接依赖固定项。
- 因源码直接导入，保留并显式声明 `psutil`、`nvidia-ml-py`。
- 使用 PyTorch 官方 cu128 索引，GPU 依赖设置了当前 Python 3.14 可用组合的兼容上限。
- setuptools 是项目直接构建工具；Torch 2.11 要求 `<82`，因此声明为 `setuptools>=68,<82`。
