## 实现内容

### 1. 库无关的推理端口

- 新增 `domain/transcription.py`。
- 定义运行时可检查的 `TranscriptionEngine` 协议，只暴露 `transcribe(media_path, **options)`。
- 四套 Core 的 `process_video()` 改为依赖该协议，不再使用 `WhisperModel` 类型。

### 2. 结构化硬件探测

- 新增 `infrastructure/hardware.py`。
- `HardwareDetector` 延迟导入 Torch，返回不可变 `HardwareInfo`。
- 保留原设备策略：
  - CPU：`device=cpu`、`compute_type=int8`、`cpu_threads=4`。
  - CUDA：`device=cuda`、`compute_type=float16`、`cpu_threads=0`。

### 3. faster-whisper 适配器

- 新增 `infrastructure/whisper_engine.py`。
- `ModelLocation`/`resolve_model_location()` 统一工程内 Hugging Face 缓存定位。
- `FasterWhisperEngine.load()` 延迟导入 faster-whisper，并保留：
  - 模型 `large-v3-turbo`；
  - `device`/`compute_type` 来自硬件探测；
  - CPU 线程策略不变；
  - `num_workers=1` 不变。
- `transcribe()` 原样透传 preset 参数与底层返回值。

### 4. 显式 bootstrap 与 fake engine 注入

- 新增 `bootstrap.py`，只有开始真实转录时才显式设置 `HF_HOME` 和 warning 策略。
- 四套 Core 的 `main(engine=None)` 支持直接注入 fake engine；注入后完全绕过 bootstrap、Torch、CUDA 探测和真实模型加载。
- 未注入时的日志顺序、硬件选择、模型加载和批处理行为保持原样。
