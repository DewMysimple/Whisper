# 批次 06：统一转录应用服务

## 目标

建立唯一的转录应用主流程，使四个旧 Core 文件只负责选择 preset 和转发调用；保持现有输出、参数、CLI 文案与兼容入口不变。

## 阶段

- [complete] 1. 冻结批次 5 基线并梳理现有四套流程与契约
- [complete] 2. 设计应用服务、请求/结果与进度事件契约
- [complete] 3. 先补应用服务及兼容入口测试
- [complete] 4. 实现统一应用服务和 CLI 事件格式化
- [complete] 5. 将四个 Core 缩减为薄兼容入口
- [complete] 6. 执行完整回归、golden、benchmark 与入口检查
- [complete] 7. 清理临时产物并输出执行报告

## 边界

- 不删除四个 `WhisperProject*.py`。
- 不拆分 GUI。
- 不改变输出算法、preset 参数、模型参数或文件命名规则。
- 不自动暂存或提交 Git。
- 不删除或修改 `.workbuddy`。

## 验收

- 四个 Core 不再各自维护主流程。
- CLI 与四个兼容入口行为及 golden 一致。
- 单文件失败产生结构化结果，批处理继续。
- 成功、部分失败、全部失败具备统一退出码。
- benchmark 不超过既定 20% 回退阈值。

## 错误记录

| 错误 | 次数 | 处理 |
