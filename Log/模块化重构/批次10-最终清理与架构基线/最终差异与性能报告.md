# 模块化重构最终差异与性能报告

## 对照范围

- 起点：批次 0，HEAD `9261d97d9c76ca6655a02fdc2035c14e29aa4a8d`。
- 终点：批次 10 当前工作区；批次 0–10 尚未自动提交。
- 行为基准：四份 golden、固定中英文音频、`tests/benchmark/baseline.json`。

## 结构差异

| 项目 | 批次 0 | 批次 10 |
| --- | --- | --- |
| 主流程 | 四个 Core 脚本各自承担入口/逻辑 | 单一 `TranscriptionService` |
| preset | 字典与物理脚本绑定 | 类型化注册表，仅含业务参数/策略 |
| 后处理 | 分散在脚本 | `domain/postprocess` 纯函数与策略链 |
| 引擎/硬件 | Core 内直接使用 | infrastructure 适配器 |
| 文件输出 | 脚本内路径和写入 | media/output adapters + 原子写入 |
| GUI | `WhisperPyQtGUI.py` 约 1189 行单体 | window/controller/runner/settings/widgets |
| CLI/GUI 协议 | GUI 启动物理 Core 脚本 | `python -m whisper_subtitle transcribe --progress jsonl` |
| 路径 | 固定源码树/`whisper_env` 假设 | `AppPaths` 安装/便携解析 |
| GPU 依赖 | Torch + torchaudio + torchvision | CTranslate2 + NVIDIA cuBLAS wheel |
| 公开旧入口 | 五个大写兼容模块 | 经用户确认后移入回收站 |

最终生产包包含 37 个 Python 文件、3635 行；按“相对路径 + NUL + 文件字节”排序聚合的 SHA256 为 `FB8DB15F9F8CE597B656842FE99AA01D0B57CCE31E57931110A7E409D0126808`。批次 0 的 13 个业务文件聚合 SHA256 为 `4E2A68A4F2A15A9FF3492D296C63ED46F2A14487A5873D7FEE35A02F7CCD5D2B`（两者算法口径见各自报告，不用于判断内容相等）。

## 测试与行为差异

- pytest：批次 0 为 71 项；最终为 176 项。
- 兼容层删除前曾达到 246 项；减少的 70 项主要是同一 canonical 行为对四个旧 Core 薄壳的重复参数化，不代表业务门禁减少。
- 新增 domain、application、infrastructure、GUI 协议、安装路径、CUDA 运行时和 architecture 门禁。
- 四 preset 推理参数与批次 0 benchmark 完全一致。
- en/en2 输出 SHA256 保持 `D6AD4418CE220D3981878CB84FB903B6E483FF2497FCBD6A9D5C65C15463DE78`。
- cn/cn2 benchmark 输出 SHA256 保持 `69D77F85DDD53B7F98F9A0E63F3639D6F8D194F33430278B96CBAAE798E2CD3D`。
- 固定中文真实音频的 cn/cn2 文本与 real golden 完全一致。

## 性能对比

四 preset 分冷进程/暖系统缓存各 3 次，共 24 次。批次 10 当前工作环境仍保留旧 Torch 包，因此同时列出当前工作环境和批次 9 从零精简安装环境。

| 环境 | 总耗时中位数 | 相对批次 0 | 模型加载 | 转写至输出 | 峰值进程内存 | 峰值显存 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 批次 10 当前工作环境 | 3.1519–3.1934 s | 0.878–0.889 | 1.1767–1.1889 s | 0.4652–0.4974 s | 2103–2187 MiB | 2319–2322 MiB |
| 批次 9/10 精简安装形态 | 1.9995–2.0819 s | 0.555–0.580 | 1.1784–1.2069 s | 0.4524–0.5077 s | 1800–1845 MiB | 2318–2320 MiB |

当前工作环境仍会被已安装的 Torch 触发可选导入；发布 wheel 的干净安装不含 Torch，因此应以精简安装形态作为交付性能预期。模型加载、实际转写和显存没有回归，主要收益来自删除 Torch 冷导入和环境体积。

## 安装与体积

- 原环境：4.566 GiB。
- 最终从零安装环境：1.305 GiB，减少约 71.4%。
- 缓存命中时完整依赖安装：23.16 秒。
- 干净 wheel：151,272 字节。
- wheel SHA256：`FCE7796DEA9AA25D20BBB67780075FE9C8E57841FA98C7425074111D676E524C`。
- wheel 共 43 个成员，包含包内 logo，不包含 `whisper_subtitle/core` 或旧 `whisper_subtitle/gui`。

## 结论

模块化重构达到既定基线：主流程唯一、preset 数据唯一、依赖方向可解释、安装/便携路径明确、旧大写入口清除、真实 CUDA 和 GUI 发布形态通过。后续新增 preset 不需要复制主流程；新增引擎或 UI 可通过既有协议和 application service 扩展。
