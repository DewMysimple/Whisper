## 第一批：生成 golden output

```
请执行第三阶段第 1 项和第 4 项（两个测量型任务，可一起做）：

1. 生成回归测试样本：
   - 使用执行2已有的 WAV（Log/执行2/baseline/regression_input.wav）或重新生成一段固定短音频（建议 3-5 秒英文 + 3-5 秒中文）
   - 用 whisper-subtitle transcribe 分别跑四个 preset：en、en2、cn、cn2
   - 将四份输出 TXT 保存到 tests/golden/ 下，文件命名如：
     tests/golden/en_output.txt
     tests/golden/en2_output.txt
     tests/golden/cn_output.txt
     tests/golden/cn2_output.txt
   - 记录每个 preset 的转录参数（模型、语言、阈值等）

4. 记录性能基线：
   - 启动耗时：从 python 启动到模型加载完成前（用 python -X importtime 或 time 命令）
   - 模型加载耗时：model_init() 调用到返回
   - 单段转录耗时：从开始推理到输出写盘完成
   - 峰值显存占用（nvidia-smi 或 pynvml 记录）
   - 峰值内存占用
   - 分别对四个 preset 各跑一次，结果记录到 tests/benchmark/baseline.json

注意：不修改任何业务代码，只生成测试数据和测量记录。
```

## 第二批：写单元测试

```
请执行第三阶段第 2 项和第 3 项（两个测试编写任务）：

2. 为后处理函数写单元测试（使用 pytest）：
   - 四个 core 脚本中重复的后处理函数：
     * txt_to_md：测试纯文本转 Markdown 标题/分段格式
     * ensure_proper_case（英文脚本）：测试首字母大写、专有名词修复
     * ensure_chinese_punctuation（中文脚本）：测试标点转换、句末标点
     * clean_repetition（cn2/en2 脚本）：测试重复去重
     * clean_inner_repetition（cn2 脚本）：测试句内重复清理
   - 测试文件放在 tests/ 下，如 tests/test_postprocess.py
   - 每个函数覆盖常见路径和边界情况（空输入、纯标点、重复内容等）
   - 确认 pytest 能发现并执行所有测试

3. 为 presets.py 写结构测试：
   - 测试文件 tests/test_presets.py
   - 验证 PRESETS 字典包含 cn、cn2、en、en2 四个键
   - 验证每个 preset 包含所有必需字段（name、params、script 等）
   - 验证 params 内的关键参数类型正确（如 temperature 为 float、beam_size 为 int）
   - 验证不同 preset 之间参数差异符合预期（如 cn2 和 cn 的 repetition_penalty 不同）

注意：不修改任何业务代码，只新增测试文件。改完跑 pytest 确认全部通过。
```
