## 概述

**WhisperSubtitle** 是一个面向 Windows 本地的语音转文本桌面工具，目标机器 RTX 5070 Ti / Win11 / CUDA 12.8。模型 `mobiuslabsgmbh/faster-whisper-large-v3-turbo` 内置于 `models/huggingface/`，完全离线运行。

工程当前是**单体原型**：PyQt5 GUI + 三个独立转录脚本 + VBS 启动器。能跑、视觉精致，但架构未分层。本文档记录其架构、优劣势、性能实测，并规划后续三个版本的演进路径。
