工程分四层：

**① 启动层** — `Whisper.lnk` → `launch.vbs`（无控制台黑窗）→ `src/utils/test_env.py` 校验依赖与 CUDA → 通过后用 `pythonw.exe` 启动 GUI。校验失败弹窗并把错误写入 `test_error.txt`。

**② GUI 层** — `src/gui/WhisperPyQtGUI.py`（PyQt5，约 1000 行单类）。它自己不做转录，而是用 `QProcess` 把 core 脚本作为子进程拉起，并通过环境变量 `HF_HOME`（指向工程内模型目录）、`PYTHONIOENCODING=utf-8`、`PYTHONUNBUFFERED=1` 控制运行环境，靠 `readyReadStandardOutput` 把子进程 stdout 实时回显到日志栏。

**③ 转录层** — `src/core/` 三个脚本互斥，由 GUI 的"处理模式"单选决定调哪个：

| 脚本 | 模式 | 关键差异 |
|------|------|----------|
| `WhisperProjectCN.py` | 中文转录 | `language=zh`、开上下文、英文标点→中文标点转换 |
| `WhisperProject.py` | 英文标准版 | `language=en`、开上下文、宽松阈值，追求连贯 |
| `WhisperProject2.py` | 英文防幻觉 | **关上下文**、严格阈值 + `clean_repetition()` 去重 |

三个脚本共用流程：`argparse(input / -o / --desktop)` → 检测 CUDA → 加载 `WhisperModel("large-v3-turbo", float16)` → 递归扫描视频 → `merge_segments_to_sentences` 按标点合并句子 → 后处理（大小写/标点）→ 写 `Text/*.txt`。

**④ 推理与输出** — faster-whisper + CTranslate2 后端，float16 半精度。输出默认到视频同目录的 `Text/` 子文件夹；`-o` 指定目录则额外备份；`--desktop` 另存到桌面。
