## 附录：实测数据汇总

**环境**：RTX 5070 Ti / Win11 / CUDA 12.8 / float16 / large-v3-turbo

**启动耗时**：
- 冷启动 test_env.py = 6.2s（首测）/ 1.34s（热态，优化前）/ 0.11s（优化后）
- 纯解释器 `python -c pass` = 0.08s
- GUI 模块 import = 0.09s
- 各包 import（热态）：torch 1.03s / faster_whisper 0.08s / ctranslate2 0.03s / av 0.04s / PyQt5 <0.01s
- `torch.cuda.is_available()` = 0.02s（CUDA 可用）

**模型加载**：进程启动+import 1.07s + WhisperModel 加载 4.34s = 5.3s/次

**import 顺序坑**：先 import numpy/av 再 import torch → `c10.dll` 初始化失败（OSError WinError 1114）。torch 必须最先 import。
