# 四预设旁白校准（2026-09-26）

## 范围与结论

用户授权调整中文、中文防幻觉、英文、英文防幻觉四个预设。真实推理使用本地 Large V3 Turbo、CUDA float16；未对其余五个模型进行真实音频验收。这里记录的是已测样本的改进，不是适用于所有音频的全局最优参数。

用户提供的配乐旁白长 138.09 秒，人工核对参考文本去除标点、空白并统一英文大小写后为 302 字符。旧中文防幻觉默认值复现了用户原输出的全部正文差异。主要漏识别发生在 VAD 阶段：默认阈值 0.5 只保留 76.832 秒，约 99.4–113.7 秒的一段旁白已在 Whisper 解码前被过滤；原始模型片段同样缺失，排除后处理删句。

| 配置 | 替换 | 删除 | 插入 | 字符错误率 CER |
| --- | ---: | ---: | ---: | ---: |
| 原中文防幻觉 | 6 | 32 | 0 | 12.58% |
| 关闭 VAD 的候选 | 8 | 0 | 0 | 2.65% |
| 最终四预设，分别实测 | 6 | 0 | 1 | 2.32% |

最终配置保留 123.992 秒，恢复全部 32 个遗漏字符。源码推理与正式冻结 Worker 四次任务的完整输出一致。仍有同音词、虚词及一个多余字；没有将人工参考文本放入 prompt 或后处理词表，也没有手工修饰验收输出。

## 默认值

| 选项 | 旧值 | 当前四预设 |
| --- | --- | --- |
| `vad_filter` | true | true |
| `vad_threshold` | 引擎默认 0.5 | 0.05 |
| `min_silence_duration_ms` | 普通 300／防幻觉 500 | 2000 |
| `speech_pad_ms` | 引擎默认 400 | 600 |
| `condition_on_previous_text` | 普通 true／防幻觉 false | false |
| `chunk_length` | 省略，初始有效值 30 | 显式 30 |

阈值降低使轻声旁白更容易被保留；较长静音等待和边缘补齐减少断句，关闭前文续写降低跨窗口重复。保留 beam 5、既有模型语言校准、温度回退和四种后处理。beam 10／20 增加开销但无法找回 VAD 已过滤的语音；提示词及词级幻觉过滤候选没有改善最终 CER，因此未采用。

`chunk_length` 显式传入是任务隔离修复：faster-whisper 1.2.1 的共享 FeatureExtractor 会保留上一次显式窗口长度。用户先设 20 秒、后恢复默认时，必须主动重置为 30 秒。新增测试使用真实 FeatureExtractor 验证四个预设的 20→默认任务顺序。

用户显式 overrides 继续优先，更新程序不会清空个人设置；在工作台对相应模型／预设恢复默认后才能使用整组新值。

## 回归证据与限制

- 中文固定夹具及其配乐混合版本：中文两预设均维持零正文字符错误。
- 英文 38.8 秒合成语音及其配乐混合版本：英文两预设均维持零正文字符错误；它们只能作为有限回归样本。
- 四预设处理 40 秒数字静音均为空。纯音乐片段在旧、新设置下都可能产生短语幻觉，当前参数不保证纯音乐零输出。
- 四 CLI 各三次冷进程、三次暖系统缓存，共 24 次真实 GPU benchmark；“暖”仍启动新进程和新模型，不表示 Worker 常驻缓存。冻结 Worker 另验证多任务只加载模型一次。
- `tests/fixtures/english_short.wav` 是原 benchmark 归档音频的字节级副本，修复原脚本已失效的输入路径。旧 golden 与当前排版存在既有漂移；分别运行旧、新推理参数确认当前格式化文本相同后，才更新四份 golden。中文真实夹具 golden 不变。
- benchmark 参数快照记录 `derive_preset(..., model_id="large-v3-turbo")` 的有效值，避免把基础中文语言／提示词误报为实际自动语言／空提示词。Windows CRLF 与仓库 LF 以解码后的完整文本比较，识别内容、空格、标点与分行仍严格验证。

当前机器的实验 JSON、原始片段、VAD 时间段、输出和正式版验证记录保存在被 Git 忽略的 `build/analysis-20260926/`；个人媒体与全文参考未进入版本控制。可复用的 benchmark、固定夹具和回归测试在仓库中保留。
