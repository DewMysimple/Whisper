# WhisperSubtitle 中文使用说明

## 启动

双击同目录中的 `WhisperSubtitle.exe` 即可启动。软件是本地离线应用，不会启动浏览器或本地网站。

请保留整个 `WhisperSubtitle` 文件夹，不要只复制 EXE。`_internal` 中包含转录 Worker、CUDA 用户态依赖、离线模型和发布校验资料，缺少任何一部分都可能导致软件无法启动或无法转录。

## 系统要求

- Windows 11 x64
- 兼容的 NVIDIA GPU 与已安装的 NVIDIA 驱动
- Windows WebView2 Evergreen Runtime（Windows 11 通常已安装）
- 足够的磁盘空间用于媒体、离线模型和转录输出

## 基本使用

1. 在“转录工作台”中选择一个或多个媒体文件或文件夹。
2. 选择转录预设和需要的 TXT、Markdown、SRT 输出格式。
3. 确认输出位置后开始任务。
4. “跟随”写入媒体所在目录；“文件夹”把 TXT／Markdown 写入媒体旁的 `Text`，字幕写入 `SRT`；“自定义”写入所选目录。

## 模型与参数

在“模型与参数”中切换本地已安装模型，或调整当前模型与识别模式的参数。未安装的模型不可选；软件不会自动联网下载模型。参数修改自动保存，各模型与识别模式独立保存，也可逐项或整组恢复默认。转录工作台的文本识别模式下方可直接进入参数调节。

Qwen3-ASR 提供 1.7B 和 0.6B 两档；1.7B 适合优先考虑识别质量，0.6B 适合减少资源占用。两档共用一个时间戳对齐模型，完整安装后才可选择。原有 Whisper 模型继续可用，默认仍为 Large V3 Turbo。

参数页面只显示当前模型支持的设置。Qwen 支持自动语言、背景提示、术语、音频窗口和语音活动检测等设置。其 SRT 对齐支持中、英、粤、法、德、意、日、韩、葡、俄、西班牙语；其他支持的识别语言可输出 TXT／Markdown。

## 硬件优化

“硬件优化”提供自动选择、GPU 加速、节省显存、CPU 推理四种方案，还可选择 GPU、计算精度和 CPU 推理线程数。可选设备与精度来自本机检测，不支持的组合不可启用。

默认方案优先使用可用的 NVIDIA CUDA GPU；没有 GPU 时使用 CPU。CPU 线程的“沿用默认”为 CPU 4 线程、GPU 运行时自动；“运行时自动”交给推理引擎决定，也可手动指定线程数。线程数增大并不保证更快，建议结合“性能监控”观察使用率再调节。INT8 混合精度可降低内存或显存需求，识别结果可能略有差异。

Qwen 当前支持 GPU 的 BF16／FP16／FP32 和 CPU 的 FP32，不支持 INT8。若此前为 Whisper 指定了 INT8，切换到 Qwen 后请在硬件页选择“自动选择”或受支持精度。

模型、推理参数与硬件设置都在下一次提交任务时使用，已运行和已排队的任务保留原配置。切换模型或硬件配置时，下一任务可能需要重新加载模型。

## 复制与解压

`WhisperSubtitle.zip` 与同名文件夹内容一致，可复制到其他 Windows 11 x64 电脑后完整解压使用。不要直接在压缩包内运行，也不要让解压工具遗漏 `_internal` 目录。

## 数据与更新

媒体、设置和转录结果都保留在本机。当前版本不自动联网更新；替换版本前请退出软件，用户自己的媒体与输出不应放进应用目录的 `_internal` 中。
