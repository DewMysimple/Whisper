# WhisperSubtitle 项目记忆

这是 WhisperSubtitle 的低冗余、可审计项目记忆。它把当前应相信的事实、已确认的工程决策、稳定知识和历史施工档案分开保存。

## 启动读取

Agent 首先读取 `AGENTS.md`，然后依次读取项目概览、系统架构、当前约束和当前待办四个基线页面；已知问题、active 决策和知识页按任务相关性读取。`历史归档/` 不属于默认启动上下文。

## 目录

- [当前状态](当前状态/项目概览.md)：当前目标、架构、约束、待办和已知问题。
- [决策](决策/README.md)：会影响后续工作的架构与边界决策。
- [知识](知识/README.md)：模块、流程、规范和运维知识。
- [日志](日志/README.md)：新的任务日志和唯一工作日志索引。
- [历史归档](历史归档/)：旧 `Log` 的完整历史，保留用于审计，不默认读取。
- 工具：`工具/memory_lint.py`，用于检查 frontmatter、链接、active topic 和日志索引。

## 核心规则

1. 当前代码、配置和测试优先于历史描述。
2. 记忆保存结论、边界和来源，不复制完整代码或执行报告。
3. 未确认的方案不进入 active 当前状态或 active 决策。
4. 新结论替代旧结论时保留旧页面并标记状态，不删除历史。
5. 当前未提交工作只能记录为开发中事实，不能写成已验收结论。
6. 实质任务完成后必须新增日志、同步受影响的 active 页面、重建索引并通过记忆体检。

## 检查

```powershell
python wiki-memory/工具/memory_lint.py index
python wiki-memory/工具/memory_lint.py check
```

本次迁移前目录名为 `Log`；迁移映射和完整旧文件位于 [历史归档](历史归档/)。
