# ADR-003：UI 跨阶段同步门禁

## 决策

第三阶段 `WhisperUI` 是视觉设计事实来源，正式工程代码、协议、Worker、Preset、输出规则和测试是功能事实来源。第三阶段的修改不会自动同步到正式应用；只有用户明确授权并指定快照或差异，才执行一次正式 UI 修改。

## 门禁

- 页面和组件结构必须来自源码，不根据截图猜尺寸或语义。
- 演示 Worker、模型、任务、路径和文件操作不能进入正式状态。
- 每轮 UI 修改必须记录授权、实际变更、保护边界、测试、构建、EXE 验收和遗留问题。
- 当前未提交 UI 代码只记录为开发中事实，不代表已验收。
- 模式、输出格式和执行完成操作等选择卡片统一使用同一按下/选中/焦点交互契约；单选控件保留 `aria-pressed`，多选格式保留 checkbox 语义。
- 已退役的 mixed_zh_en／zh_detail_review 增强识别选项不得从新建、重试或续传路径发起；旧偏好归一化为 `stable_primary`，但历史任务、诊断、Desktop IPC 和 Worker 兼容解析继续保留。
- 模型切换与推理参数已于 2026-09-20 按新用户授权重新设计，见 [[决策/ADR-004-模型与参数工作台]]；硬件优化及人工设备／精度仍不恢复。开发态验收不能替代正式产物配套构建。

## 当前基线

`UI-2026-07-28-R03` 仅是已记录的历史反向同步快照；其中的模型与硬件工作台已分别在 2026-09-16、2026-09-17 按用户新授权退役，不能再作为当前页面基线。后续 UI 变化继续按独立验证、提交和推送处理。
