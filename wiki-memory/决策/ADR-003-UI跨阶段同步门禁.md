# ADR-003：UI 跨阶段同步门禁

## 决策

第三阶段 `WhisperUI` 是视觉设计事实来源，正式工程代码、协议、Worker、Preset、输出规则和测试是功能事实来源。第三阶段的修改不会自动同步到正式应用；只有用户明确授权并指定快照或差异，才执行一次正式 UI 修改。

## 门禁

- 页面和组件结构必须来自源码，不根据截图猜尺寸或语义。
- 演示 Worker、模型、任务、路径和文件操作不能进入正式状态。
- 每轮 UI 修改必须记录授权、实际变更、保护边界、测试、构建、EXE 验收和遗留问题。
- 当前未提交 UI 代码只记录为开发中事实，不代表已验收。

## 当前基线

`UI-2026-07-28-R03` 是已记录的反向同步快照；第 33 次正式 UI 修改的前 3 项已按用户要求分别完成并通过桌面验收，后续第 4 项仍按独立验证、提交和推送处理。
