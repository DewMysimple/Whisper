# ADR-004：模型与参数工作台

用户于 2026-09-20 明确要求重新新增包含模型切换与参数调节的工作台，并尽可能开放底层参数。本设计取代模型／推理参数工作台的退役限制；硬件执行设置随后由同日新授权的 [[决策/ADR-005-硬件执行设置与工作台]] 单独扩展；联网模型下载和旧增强识别模式继续保持原约束。

## 产品与状态边界

- 主导航新增“模型与参数”，内含模型切换、参数调节两项功能。转录页文本识别模式下方复用路径入口卡片，直接进入参数调节。
- 模型目录来自 typed bridge 的本地检查；所有已注册模型均展示，未安装或检查失败时不可选择。选择只决定后续任务，加载仍由任务启动触发，不新增手动加载／卸载协议调用。
- 用户修改按模型 ID 与 preset ID 二维隔离保存；恢复默认只影响当前组合或指定字段。运行／排队任务持有独立快照。
- 浏览器预览与真实桌面使用不同 localStorage key，预览配置可跨刷新保留，演示任务不进入桌面存储。

## 参数事实源与协议

- `domain/parameters.py` 定义 36 项公开选项、类型、范围、可空含义、VAD 映射和显示用引擎默认值。`domain/presets.py` 保留四 preset 与模型校准，只有显式 override 才改变任务选项。
- `generate_preset_catalog.py` 生成 Web 类型、校验规则、模型／preset 参数投影及 IPC v1 的 `ParameterOverrides` 定义。Python 协议与 preset 派生共用同一归一化；Rust Host 从内嵌 schema 定义校验字段，另检查温度递增和翻译能力。
- 此次为已授权 v1 参数能力扩展，命令、事件和生命周期不变。旧版本 Host／冻结 Worker 不理解新增字段；新版前端的这些控件需要配套本轮源码 Host／Worker，不能把本次开发态代码视为旧便携版支持新参数。最初交付限定开发态；后续用户已在 ADR-005 对应任务中授权配套重建正式产物，完成情况以最新任务日志为准。
- 参数覆盖包含语言／任务、搜索与温度回退、提示词与 token 抑制、VAD 与窗口、时间戳与标点。允许部分阈值显式关闭；省略字段表示继承，`null` 表示对应自动／关闭含义，二者不能混用。旧空提示词继续解释为继承。
- 温度可为固定数值或最多十级严格递增回退序列。继承值展示真实模型回退序列，固定 0 必须保持显式覆盖。SRT 输出强制词级对齐，页面说明与任务快照一致。
- 硬件执行设置属于 ADR-005 的独立运行时契约，不混入推理参数覆盖；模型目录和进程参数继续属于运行时责任；`log_progress` 属于日志通道、`without_timestamps` 与应用进度／SRT 时间轴约束冲突、`clip_timestamps` 涉及媒体裁剪与进度／输出计划，因此不作为本轮推理参数公开。现有六项 SRT 排版控制仍由字幕面板维护。

## 验收与维护

UI 字段覆盖、持久化、模型／preset 隔离、恢复默认、冻结提交由组件／状态及浏览器测试验证；协议非法值、完整 36 项传递和已安装 faster-whisper 签名由 Python 测试验证，Rust 保留独立边界测试。真实 GPU 验证记录在关联日志。当前四个 CLI preset 的 golden 不变。
