- Python、TOML、Markdown、JSON、TXT、YAML 使用 LF。
- `.gitignore`、`.gitattributes`、`.editorconfig` 显式使用 LF。

- Python 使用 4 空格。
- TOML/JSON/YAML 使用 2 空格。
- Markdown 允许有意义的行尾空格。
- VBS 使用 CRLF 和 4 空格。
- 二进制文件禁用文本尾部规则。
