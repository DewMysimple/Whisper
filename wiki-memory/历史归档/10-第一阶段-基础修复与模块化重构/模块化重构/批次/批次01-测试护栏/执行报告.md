## 变更内容

### CLI 与 preset 契约

- 四个 CLI 别名到旧 Core 模块的解析与输入/输出参数转发。
- CLI 别名到内部 preset ID、参数快照和后处理策略的一致性。
- 旧 Core 返回码传播、无返回值归零、异常路径 `sys.argv` 恢复。
- `check`/`gui` 返回码、无子命令帮助和非法 preset 的 argparse 退出码。

### 批处理与失败路径

- 四个旧 Core 的输入不存在、不支持格式、空目录均在模型加载前失败。
- 文件夹递归扫描、混合大小写扩展名、忽略非媒体文件和稳定排序。
- 强制输出目录自动创建与传递。
- 损坏媒体的逐文件错误、批次失败退出码和成功数汇总。
- 模型缺失与输出目录权限异常当前向上抛出的行为。

模型缺失和输出权限错误尚未形成统一错误对象；本批次按“不改业务代码”要求固定现状，计划在批次 6 的统一应用服务中收敛。

### benchmark v2

- runner 不再自动覆盖 golden，输出不同会直接失败。
- 模型解析强制离线，避免 Hugging Face 网络状态污染本地性能基线。
- 每个 preset 分为 `cold_process` 与 `warm_system_cache` 两阶段，每阶段 3 次、合计 6 次。
- 每个数值指标记录原始 samples、median、min、max 与 range。
- `warm_system_cache` 表示系统/文件缓存已预热后的全新 CLI 进程，不表示同一进程复用已加载模型。
