## 核心调整

- 新增集中 `AppPaths`，统一解释器、工作目录、便携根目录、用户缓存、模型和 package resource。
- GUI QProcess 默认使用 `sys.executable`，不再硬编码便携 venv。
- 模型路径优先级：显式 `--model-dir` → `WHISPER_SUBTITLE_MODEL_DIR` → `HF_HOME` → 便携模型 → 用户缓存。
- 支持直接 CTranslate2 模型目录和 Hugging Face snapshot；缺失错误包含已检查路径与配置方式。
- logo 作为 package data 通过 `importlib.resources` 读取，保留旧 assets fallback。
- 环境检查改为验证运行依赖、当前解释器和本地模型，不检查源码/Core 文件。
- `launch.vbs` 使用解释器发现与模块入口，支持环境变量、便携 venv 候选和 PATH fallback。
- 历史 `script_path()` 改为模块 spec 定位，不再拼接 `src`。
