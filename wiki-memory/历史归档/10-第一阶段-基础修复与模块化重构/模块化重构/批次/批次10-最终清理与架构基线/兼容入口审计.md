# 公开兼容入口审计与删除建议

## 已迁移的调用方

- `launch.vbs`：使用 `python -m whisper_subtitle check/gui`。
- GUI 子进程：使用 `whisper-subtitle transcribe --preset ...`。
- CLI GUI：直接导入 `presentation.gui.main_window.main`。
- CLI/GUI 环境检查：直接使用 `infrastructure.environment_check`。
- 实际转录：统一进入 `application.TranscriptionService`。

## 建议删除（需要用户确认）

| 公开路径 | 当前职责 | 内部运行时引用 | 建议 |
| --- | --- | ---: | --- |
| `whisper_subtitle.core.WhisperProject` | 英文标准旧脚本/API 薄壳 | 0 | 删除 |
| `whisper_subtitle.core.WhisperProject2` | 英文防幻觉旧脚本/API 薄壳 | 0 | 删除 |
| `whisper_subtitle.core.WhisperProjectCN` | 中文标准旧脚本/API 薄壳 | 0 | 删除 |
| `whisper_subtitle.core.WhisperProjectCN2` | 中文防幻觉旧脚本/API 薄壳 | 0 | 删除 |
| `whisper_subtitle.gui.WhisperPyQtGUI` | 旧 GUI 模块路径薄壳 | 0 | 删除 |

删除后，直接执行这些 Python 文件、导入旧模块或调用旧模块内的后处理函数将不再受支持。替代入口：

- 转录：`whisper-subtitle transcribe INPUT --preset {cn,cn2,en,en2}`
- GUI：`whisper-subtitle gui` 或 `python -m whisper_subtitle gui`
- 环境检查：`whisper-subtitle check` 或 `python -m whisper_subtitle check`
- 后处理：`whisper_subtitle.domain.postprocess`
- 应用服务：`whisper_subtitle.application.TranscriptionService`

## 建议同步清理

- `whisper_subtitle.core.presets` 的旧字典视图。
- `whisper_subtitle.cli.PRESET_MODULES`。
- `Preset.module`、`Preset.script` 和 golden/benchmark 中只表示旧物理脚本的字段。
- 只验证上述旧 API 的测试；行为测试迁移到 domain/application/canonical CLI。
- 空的 `core/`、`gui/` 兼容包。

## 建议保留

- `whisper_subtitle.utils.test_env`：保留为 `infrastructure.environment_check` 的弃用转发层。该文件已符合 snake_case，且旧启动/排错文档曾公开引用，保留成本很低。
- `PROJECT_ROOT`：暂保留只读兼容值，后续主版本再移除。
- `Requirement/`、`Log/` 和旧架构资料：作为需求与审计记录保留，不把历史描述当成当前文档。

## 推荐决策

确认删除五个大写兼容入口及其专属元数据。它们已无内部运行时调用，继续保留会让 preset 注册表绑定物理脚本、阻碍 snake_case 统一，并使旧文档看起来仍是推荐用法。
