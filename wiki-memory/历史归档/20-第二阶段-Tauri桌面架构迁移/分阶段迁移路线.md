## 全局保护规则

- 不在 UI 重构期间修改转录参数和后处理算法。
- 现有 Python CLI 始终保持可运行。
- PyQt5 GUI 在新 UI 达到功能等价前保留。
- 涉及删除时移动到 Windows 回收站。
- `.workbuddy` 不修改、不删除。
- 每批结束输出报告到 `Log/` 并记录验证结果。
- 协议、前端和 Python 测试必须随实现同步增加。
- 涉及 CUDA、依赖或打包时必须从零环境验证。
