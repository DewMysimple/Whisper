## 实现范围

### Rust 桌面 Host

- 使用固定可执行文件与固定 `-m whisper_subtitle worker` 参数直接创建受控子进程，不经过 shell。
- 开发态按显式环境变量或工程 `whisper_env` 解析 Python；同时预留批次 6 的同目录 `worker/whisper-subtitle-worker.exe` 解析位置。
- 监管 stdin、stdout、stderr、进程代次、待处理请求、显式重启和退出清理。
- stdout 每行在转发前按 Desktop IPC v1 严格校验；错误 JSON、未知字段、未知 code/stage 和非法 envelope 会使 Host 终止受污染 Worker。
- stderr 与协议通道分离，保留最近 200 行并以独立桌面事件发送。
- 前端只可调用白名单 Tauri command；没有通用 shell 权限。
- 原生文件/文件夹/输出目录选择使用 Tauri dialog；“定位输出”只调用 Rust 固定的 `explorer.exe` 行为并先验证路径存在，不暴露任意命令执行。
- 应用正常退出时先发送 `worker.shutdown`，超时后才强制终止。

### React WebView 表现层

- Tauri 运行时绑定真实 `TauriDesktopBridge`；普通浏览器测试环境继续使用 mock bridge。
- 接入原生文件多选、文件夹选择、WebView 拖放、逐行粘贴完整 Windows 路径和输出目录选择。
- 带空格或首尾双引号的路径始终作为结构化字符串传给 Rust，不进行 shell 拆词；无效路径保留在列表中并阻止任务启动。
- 接入 Host/Worker 状态、环境检查、模型状态、任务排队/进度/完成/失败/取消、stderr 日志、Worker 重启和输出定位。
- UI 状态只依据机器字段、event/code/stage 和 task ID，不解析中文 `message` 决定状态。
- 实机模式不伪造 GPU/显存/速度指标；高级实时性能采集属于批次 5。

### Python 边界

- 沿用批次 2 的 `python -m whisper_subtitle worker`、Desktop IPC v1、模型缓存、任务队列和现有 `TranscriptionService`。
- 本批次没有修改转录算法、四个 preset 的默认参数、后处理规则、文件命名或输出文本语义。
- PyQt5 GUI 与 canonical CLI 均保留。
