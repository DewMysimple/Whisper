## 实现范围

### 任务与设置

- WebView 本地状态使用带版本号的 `whisper-subtitle.desktop-state.v1` 存储，最多保留 100 条任务。
- 排队或运行中的任务在桌面会话异常结束后恢复为 `host.session_interrupted` 失败状态，不伪称仍在运行。
- 任务历史支持状态筛选、文本搜索、详情、参数与输入快照、输出定位、清理终态历史和失败重试。
- 重试前重新检查输入路径；路径失效时拒绝启动，成功时使用原任务冻结的 preset、参数和输出策略。
- 主题、preset、参数覆盖和输出策略可持久化，并可通过 `schemaVersion: 1` JSON 导入/导出；任务、日志和历史不会写入配置导出。

### 性能与诊断

- Desktop IPC v1 以兼容性方式增加只读 `system.metrics` command，不改变既有消息 envelope。
- Python Worker 使用 psutil/NVML 返回 CPU、系统内存、GPU、显存和 GPU 名称；NVML 暂时不可用时只把 GPU 字段置空，不影响转录任务。
- Tauri bridge 每 2 秒串行采样一次，避免请求重叠；React 保存最近 60 个样本并用轻量 SVG sparkline 展示趋势。
- 性能面板不伪造“实时速度”或 GPU 数据；mock 数据只用于浏览器自动化测试和预览。

### 输出预览与桌面安全边界

- Rust Host 新增白名单 `read_output_preview`，只读取已经存在的 `.txt` 或 `.md` 文件。
- 读取前规范化路径，最多返回前 128 KiB，并明确报告是否截断；不开放任意二进制读取或通用文件系统接口。
- production 继续保持 `connect-src 'none'`，没有 HTTP/WebSocket 客户端、localhost 服务或通用 shell 权限。

### 界面与可用性

- 增加任务详情抽屉、真实任务视图、设置视图、空状态、全局错误和参数风险提示。
- 支持深色、浅色和跟随系统主题，补齐高 DPI、窄窗口和 `prefers-reduced-motion` 样式。
- 支持 `Ctrl/Cmd+O` 选择文件、`Ctrl/Cmd+Enter` 开始、`Ctrl/Cmd+1/2/3` 切换视图和 `Escape` 关闭详情。
- 任务列表使用独立语义按钮，详情使用可访问 dialog，补齐键盘焦点、标签和状态文本。

### 自动化测试

- 新增持久化/导入校验、真实 bridge 指标映射、性能采样和 Worker metrics 测试。
- Playwright 使用系统 Edge、单 worker 和固定 1440×900 viewport，覆盖完整建任务、键盘/主题/配置以及任务详情/输出预览三条路径。
- Playwright 的 `127.0.0.1:4173` 仅在测试命令期间由 Vite preview 临时提供静态资源；production Tauri 不使用该地址，也不启动任何本地服务。
