- 安装介质采用 setup + 相邻模型包；预安装钩子拒绝缺失模型的介质，安装后复制模型，卸载前移除安装目录内的外置模型。

## 关键打包决策

首次把 Worker、WebView2 和 1.51 GiB 模型全部压入单个 NSIS EXE 时，makensis 报 `Internal compiler error #12345: error mmapping datablock`。因此最终介质改为两部分完全离线布局：约 694 MiB setup 包含桌面程序、Worker 与 WebView2 离线安装器，模型目录与 setup 相邻。安装不访问网络；复制整个 `WhisperSubtitle-offline-installer/` 即得到完整介质。

模型使用直接 Hugging Face 快照布局，而不是复制旧虚拟环境或依赖旧电脑的绝对路径。便携目录约 2.47 GiB，离线安装介质约 2.19 GiB。
