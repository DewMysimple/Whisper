## Turbo 翻译判定

第一次按原计划让 Turbo 执行 `task=translate` 时，真实输出仍为中文。该行为与 [OpenAI 官方说明](https://github.com/openai/whisper/blob/main/README.md)一致：Turbo 没有用翻译任务训练，即使指定 translate 也会返回原语言。

验收结论不是“Turbo 翻译通过”，而是：

- 正式 UI 不再开放 Turbo 翻译。
- 状态层、Host、Worker/IPC 与 Preset 均拒绝绕过。
- 不自动换成 V3，不伪造英语输出。
- 用户需要翻译时必须明确选择 Large V3。
