## 2. 全局外观与字体系统

- 五个工作台、侧栏和顶栏统一由 `--ui-font-family` 与 `--ui-font-size` 驱动；
- UI 字号改为 12–18px、步长 1px，默认 14px；
- Worker 日志与等宽数据使用独立 `--log-font-size`，范围 10–16px、步长 1px，默认 12px；
- UI 字体提供系统默认、Segoe UI Variable、Microsoft YaHei UI、Noto Sans SC 和 DengXian；
- 等宽字体提供 Cascadia Mono、Cascadia Code 和 Consolas；
