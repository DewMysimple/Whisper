## 实际修改

### V3/Turbo 模型感知参数

- Worker 根据冻结的 `model_id + preset_id` 派生任务参数；小模型继续使用旧参数。
- 两套 V3 模型固定使用 `task=transcribe`，Preset 的“中文／英文”只决定断句、标点和排版，不再直接指定识别语言。
- 使用 5 个检测窗口、阈值 `1.0` 的稳定主语言投票；这是对真实样本逐窗多语言模式会误选英文/韩语后的实测整改。
- Large‑V3 温度回退为 `0.0–1.0` 完整阶梯；Turbo 为避免复杂环境高温捏造，将回退上限限制为 `0.6`。
- 防幻觉版本把 `log_prob_threshold` 校准为 `-1.0`、`no_speech_threshold` 校准为 `0.6`，使异常检测可以配合温度阶梯真实重解码。
- 用户手动修改 Temperature 时，该任务使用单一冻结温度，不再偷偷叠加自动阶梯。

### 文本后处理

- 引入正式 OpenCC `t2s`，四个 Preset 的 TXT、Markdown、SRT 后处理统一转换为简体中文。
- 删除 `U+FFFD` 和非法控制字符。
- 标点宽度根据附近文字脚本决定：中文上下文用全角标点，英文上下文保留 ASCII 标点和撇号。
- 清理 `，。`、`,.` 等错误组合。
- 防幻觉链路增加三次以上精确长短语循环折叠；普通两次强调不删除。
- SRT 仍使用原有真实词级时间轴，未改变字幕时间语义。

### UI

- Preset 卡说明改为“自动识别主语言 + 中文／英文排版”。
- 增加明确提示：Worker 不调用翻译任务；短时中英切换的保留能力仍受模型本身限制。
- 模型说明区分 V3 完整温度回退与 Turbo 0.6 上限。
- Temperature 帮助说明手动值会替代自动回退阶梯。

## 真实校准结论

真实样本否定了最初直接使用 `multilingual=True` 的方案：faster-whisper 1.2.1 会为每个 30 秒窗口选择一个语言令牌，混合窗口曾把中文整体改成英文并误跳韩语。该失败方案和第二轮结果均保留在 `build\batch26-validation`，最终采用稳定主语言自动检测。

完整 429 秒媒体最终 `cn2`：

- Large‑V3：68.332 秒，2064 字符，42 行。
- Large‑V3‑Turbo：16.668 秒，2141 字符，46 行。
- 两者均无 `�`、繁体标记、`，。`、报告中的长循环签名。
- Turbo 保留了 `Are you busy?`、`I'm free`；V3 对短英语对白仍倾向中文改写，这是模型限制，不记为已经完全修复。
