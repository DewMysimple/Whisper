## 温度与 Hotwords 决策

完整证据见[功能测试 014](../功能测试/功能测试-014-复杂场景识别诊断与V3温度校准.md)。

- Large V3 固定 `0` 的中文字符 CER 从 `10.6024%` 降到 `7.5301%`，但约 56–67 秒出现压缩率 `7.6596` 的长重复并漏掉整段，不能作为稳定改善。
- Large V3 最高 `0.6` 阶梯也在同一区域产生低平均概率内容，未形成可靠胜出。
- Turbo 最高 `0.4` 与固定 `0` 输出完全一致，CER 从 `11.5663%` 降到 `10.6024%`，但已知“谢谢你和的 Tofu”幻觉仍存在，并删除了部分真实或争议语句。
- Hotwords 对 V3 的取证术语命中由 2 提升到 4，但同时触发 13 段回退并产生明显长重复；Turbo 的命中反而由 3 降到 2。

因此两个 `模型 × cn2` 组合均没有候选稳定满足“减少幻觉/重复、CER 不恶化、英文和术语不退步”的共同门槛，正式默认温度按计划保留现状。该结论避免用单一 CER 数字掩盖漏识别和重复风险。
