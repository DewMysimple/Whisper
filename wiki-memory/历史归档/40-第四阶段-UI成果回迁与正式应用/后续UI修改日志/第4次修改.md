## 2. 设计判断

原详情区的主要问题：

- 四种资源都重复“计算设备、采样来源、当前会话、最新采样、Worker PID”，信息价值低。
- CPU 详情会显示 NVIDIA GPU 为“计算设备”，语义不准确。
- 没有汇总最近 15 秒的平均、峰值、低点和变化，用户只能看到瞬时值。
- 没有显存/内存剩余容量，也没有当前指标与关联资源的同一时刻读数。

本次采用本地性能仪表的阅读顺序：先看“现在多少”，再看“是否异常”，随后看 15 秒统计、余量和关联资源。视觉上的唯一突出元素是“负载轨”，同时标示当前填充、平均标记和峰值标记；其他区域保持克制，避免继续堆叠六张同质卡片。

## 3. 新详情区内容

所有数据均来自现有 `PerformanceSample` 和最近 15 秒真实历史，不新增或伪造字段：

- 当前使用率。
- 自动判断：等待采样、资源余量充足、运行区间正常、负载波动明显、持续高负载或出现高压力。
- 15 秒平均、15 秒峰值、15 秒低点和窗口首尾变化。
- 当前/平均/峰值负载轨。
- GPU：剩余负载余量、同一时刻显存使用量。
- 显存：可用 GiB、总容量、同一时刻 GPU 负载。
- CPU：总体空闲余量、同一时刻系统内存使用量。
- 内存：可用 GiB、总容量、同一时刻 CPU 负载。
- 底部证据行保留采样来源、有效样本数、采样时间、推理速度和 Worker PID，但不再占用主要指标卡。

温度、频率、功耗、风扇、CPU 型号、磁盘和网络等现有 Desktop IPC v1 未提供的数据没有显示，也没有用静态值伪装。
