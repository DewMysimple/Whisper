状态：正式 React 实现、持久化、配置导入导出、自动测试、Tauri Release 构建和真实桌面烟测已完成；等待用户目视验收。

## 1. 用户授权与精确语义

用户要求在“偏好设置”工作区增加一个可调节四个工作区主内容区字体大小的偏好，档位为：

- `小`：保持当前字号。
- `平衡`：所有受管主内容字号相对“小”增加 2px。
- `大`：在“平衡”基础上再增加 2px，即相对“小”增加 4px。

当前 R01/R02 内容字体模块已对原始规格统一增加 2px，因此实现中 `--content-font-bump` 三档分别为 2px / 4px / 6px；这与用户所说的相对小档 0 / +2 / +4px 完全一致。

受管的四个主内容区：

1. 转录工作台。
2. 任务记录。
3. 性能监控。
4. 偏好设置。

明确不随档位变化：

- 侧边栏。
