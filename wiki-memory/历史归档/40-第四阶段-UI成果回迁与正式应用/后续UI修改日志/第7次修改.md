# 第 7 次修改：字号档位与卡片面积联动

执行日期：2026-07-18。  
状态：正式 CSS 实现、精确几何测试、大档实图复核、Tauri Release 构建和真实桌面烟测已完成；等待用户目视验收。

## 1. 用户授权与问题

用户指出第 6 次修改只增大了字号，卡片面积没有同步扩大，导致“模式与参数”中的参数标签、输入框和帮助文字在平衡/大档下显得拥挤。用户要求字号每增加 2px 时，卡片整体也扩大到适合的面积。

本次是正式 UI 的第 7 次修改，仅修改 `F:\WhisperSubtitle`。第三阶段仍保持 `UI-2026-07-18-R02`，没有自动同步。

## 2. 自适应面积 Token

第 6 次的 `contentFontSize` 语义不变，本次为每档增加卡片几何 Token：

| 档位 | 相对小档字号 | 卡片内边距增量 | 关键卡片高度增量 | 参数行距 | 控件高度增量 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 小 | 0 | 0 | 0 | 10px | 0 |
| 平衡 | +2px | +4px | +12px | 16px | +4px |
| 大 | +4px | +8px | +24px | 22px | +8px |

“小”档原有几何完全保持；平衡和大档通过 `--content-space-bump`、`--content-card-bump`、`--content-control-bump` 和 `--content-row-gap` 统一调整，没有在每张卡片写入相互无关的数值。

## 3. 覆盖的卡片与控件

- 全局主内容卡片：面板内边距、标题与内容间距、卡片间距。
- 转录工作台：拖放区高度、路径文本框高度、输出路径/格式卡内边距、Preset 卡高度和内边距、参数行列间距、参数控件高度、帮助文字预留高度、上下文开关行、媒体队列和启动区。
- 任务记录：摘要卡内边距和列间距、任务行内边距。
- 性能监控：趋势卡标题区、指标选择器、诊断区、统计/关联卡、实时遥测卡高度与内边距。
- 偏好设置：设置卡内边距、字号三段控件高度、配置文本框高度。

侧边栏、顶栏、个人主页、Windows 标题栏和独立任务详情仍不受字号/卡片档位影响。

## 4. 字号感知响应式布局

实图检查发现，在窄窗口中只扩大右列会把左侧参数卡压得更窄。因此加入字号感知断点：

- 大档在窗口宽度 `<= 1600px` 时，工作台改为输入来源→输出策略→模式与参数→媒体队列/启动区的单列流。
- 平衡档在窗口宽度 `<= 1400px` 时使用同样的单列流。
- 更宽窗口继续使用双列；平衡右列最小 380px，大档右列最小 430px。
- 单列时明确给深色媒体队列/启动卡设置 432/444px 最小高度，避免原 `contain:size` 在失去同行等高参照后折叠。
