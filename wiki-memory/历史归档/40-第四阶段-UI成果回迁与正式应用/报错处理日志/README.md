# 报错处理日志

建立日期：2026-07-19。

本目录专门记录正式 Tauri/React 桌面软件在实际使用中出现的报错，以及对应的定位、修复和验收结果。这里与“后续 UI 修改日志”分开管理：

- 报错修复使用 `报错处理-NNN-主题.md` 连续编号；
- 不占用“第 n 次 UI 修改”的编号；
- 每份记录必须包含用户可见现象、复现条件、根因、影响边界、代码修复、回归测试、正式 EXE 信息和遗留风险；
- 不得把前端桥接错误误记成 Python Worker、Whisper 模型、CUDA 或转录算法错误；
- 未实际执行的测试不得写成已通过；
- 修复不得静默改变 Desktop IPC v1、Preset、输出规则或 Python 转录算法。
