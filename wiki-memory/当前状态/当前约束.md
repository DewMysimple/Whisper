# 当前约束

## 产品与平台

- 正式支持范围为 Windows 11 x64；不扩展到 Windows 10 或其他平台。
- 正式产品是本地离线 Windows EXE，不引入浏览器入口、localhost 服务、任意 shell 或网络权限；开发期允许仅绑定 `127.0.0.1` 的 Vite/HMR 服务，且不得把 `devUrl` 当作正式运行依赖。
- Python CLI 保留 `transcribe`、`check`、`worker`；PyQt5 GUI 和旧 VBS 入口已退役。

## 功能契约

- Desktop IPC 保持 v1；修改 schema、消息、错误码或生命周期必须单独评审。
- `model.load`、`model.unload` 是现有冻结 Worker 仍会声明的 v1 兼容能力；在协议升级和产物兼容方案落地前不得从 Host/Worker 白名单直接删除，但不能重新携带人工硬件偏好。
- 四个 CLI preset `cn`、`cn2`、`en`、`en2` 的身份、参数和后处理不能被 UI 复制或静默改写。
- 输出规则、SRT 时间轴、TXT/Markdown 排版和任务级模型/硬件冻结属于功能事实，UI 修改不得破坏。
- Golden、benchmark、协议和架构测试不能因整理记忆而重写。
- Python preset 注册表是参数事实源；Web preset 选择和任务快照使用生成投影，修改 preset 后必须运行 `python tools/codegen/generate_preset_catalog.py` 或 `corepack pnpm check:preset-catalog`。
- Python `domain/models.py` 是模型身份与能力事实源；修改后必须运行 `python tools/codegen/generate_model_catalog.py`，禁止在 Worker、Web 或 Rust 另建手工列表。

## UI 与工作树

- 正式 UI 修改必须有用户明确授权，并完成对应测试、构建和 EXE 验收记录。
- 模型与参数工作台已按 2026-09-20 用户新授权实现，契约见 [[决策/ADR-004-模型与参数工作台]]；同日硬件工作台新授权见 [[决策/ADR-005-硬件执行设置与工作台]]；旧硬件字段和旧增强识别模式继续退役。本地模型校验、实际能力探测、硬件记录、模型缓存与任务冻结必须保持。新参数／execution 需要配套 Host／Worker，不能向旧冻结产物假设兼容。本轮完整 dist 构建已获用户授权，须完成正式 EXE 与冻结 Worker 验收后才能宣布交付。
- 当前工作树中的 UI 修改在完成提交与推送前只能作为开发中状态，不能写成已提交或已封版结论。
- 不修改模型、虚拟环境、发布产物或用户输出；`models/`、`whisper_env/`、非本任务拥有的 `build/`、Rust `target/` 和 `dist/` 资料即使体积较大也不得在定期维护中自动删除。获得用户明确授权后，可先运行 `workspace:clean` 预览，再用 `workspace:clean:apply` 清除白名单内的可再生产物；该入口不得触及 `dist/`、模型、环境、依赖、源码或用户输出。发布脚本只可替换其明确拥有的 `build/release/`、`dist/WhisperSubtitle*` 与 `dist/installer/`。
- `.lnk` 等机器相关入口不得进入版本控制；Python 依赖只在 `pyproject.toml` 维护，`requirements.txt` 仅作为兼容委托入口。

## 提交与推送约定

- 硬性约定：每完成一次仓库修改任务，验证通过后必须创建独立 Git 提交并推送到当前分支的远程；未完成提交和推送，不得宣称任务完成。
- 推送失败时必须如实报告阻塞原因，保留本地提交并等待后续处理；禁止通过强推或改写历史来绕过阻塞。
- 提交前必须确认没有把范围外的用户改动混入提交；范围外改动需保留并单独处理。

## 记忆约束

- 旧历史只用于追溯，不覆盖当前代码事实。
- 不能把未经确认的讨论方案写入 active 页面。
- 生产代码和历史归档不因记忆压缩而删除。

## 维护边界

- 结构重构只能保持公开入口、IPC v1、输出规则和 UI 行为不变；改变这些契约必须单独评审。
- Cargo `target/release` 只属于开发编译输出；正式完整版必须从 `dist/WhisperSubtitle/WhisperSubtitle.exe` 启动并连同 `_internal/` 整体交付。
- 桌面启动烟测必须确认受控 Worker 子进程持续运行并完成 IPC 握手；仅确认桌面 EXE 进程存活不能作为通过证据。
- 新功能应优先修改职责最窄的模块，不再把 Worker 缓存、桥接解码、识别复核或 Host 校验重新塞回总编排文件。
