# 系统架构

## 分层关系

```text
React/TypeScript WebView
        ↓ typed DesktopBridge
Tauri 2 / Rust Host
        ↓ validated stdin/stdout JSONL
常驻 Python Worker
        ↓
application → domain → infrastructure
```

- `domain/` 保存契约、模型与 Preset 注册表、转录接口、后处理和字幕布局规则。
- `application/` 编排单文件或批量转录。
- `infrastructure/` 负责 faster-whisper、CUDA、硬件、媒体发现、性能和输出文件。
- `worker/` 负责常驻进程、串行任务、取消、媒体输入展开、模型缓存和 IPC 适配。
- Tauri Host 是 WebView 与 Worker 的唯一运行时边界，负责权限、生命周期、协议校验和受限文件预览。

## 当前内部职责边界

- Web `workspace.ts` 保留状态与动作组合；事件归并位于 `state/workspaceEvents.ts`，任务状态纯函数位于 `state/workspaceTaskState.ts`，草稿/持久化/外观/性能纯逻辑分别位于 `workspaceDraft.ts`、`workspacePersistence.ts`、`appearancePreferences.ts`、`performanceMetrics.ts`。
- 共用 `Button`／`IconButton` 集中文字和图标动作的原生语义、主题配色、焦点及危险确认样式，启动、确认弹窗、详情、历史操作与日志工具栏复用同一入口。共享按钮样式位于 `components/button.css`，页面负责布局；Button 的可选 `motion` 只动画内部内容与表面，不改变原生按钮命中区域，桌面外观预览复用该入口。`CardButton` 提供位置固定的键盘、焦点与按下反馈，动作卡不保存选中态；`SegmentedCard` 在其上统一监控／历史导航与状态筛选。`useTimedConfirmation` 集中历史删除与日志清空的四秒超时、Esc、外部点击取消规则。
- `SummaryText` 集中监控来源／输出和 Worker 状态的标签、值与可选说明，页面只处理图标、容器和动作；摘要按当前工作台字号计算，避免根节点字阶固化。`diagnostic-text.css` 统一日志正文与外观预览的字体、独立字号、换行与文本选取。Worker 日志布局、主题和断点只在 `components/worker-logs.css` 维护，并纳入样式归属门禁；监控清除、终止和目录动作已复用公共 Button。
- 任务工作台以 `components/tasks/TasksView.tsx` 为唯一页面入口；监控、逐媒体列表、处理链路、历史容器、历史卡片、日期筛选和配置恢复分别由同目录组件负责。筛选与计数规则位于 `state/taskHistory.ts`，四个任务 CSS 文件有固定归属并由 `check:styles` 检查；修改定位见该目录 `README.md`。
- Web 外观偏好由 `appearancePreferences.ts` 统一定义并由版本 1 workspace 配置持久化；桌面框架字号、工作台内容字号、日志字号、展开导航宽度、工作台最大宽度、顶栏高度和顶栏收纳状态是彼此独立的展示字段，不进入 Desktop IPC。导航右边界与顶栏下边界的直接拖拽都只更新对应的同一持久化字段，不建立组件本地尺寸事实源。
- `state/taskFiles.ts` 根据逐媒体实际输出关联决定资源管理器定位目标；任务级预览／定位都通过 `taskOutputPaths` 合并任务与逐媒体输出，不另推导输出命名。
- Web 当前输入预览位于 `state/inputTaskPreview.ts`；目录保持输入汇总，不编造子文件名或均分时长。`state/taskMonitor.ts` 统一监控页与性能页的媒体选择规则，处理链路读取前端保留的 Worker 原始 `stageCode`，不解析中文展示文案。`state/taskTiming.ts` 统一耗时转换，`useTaskTiming.ts` 分别维护任务与媒体计时锚点。
- `tauriDesktopBridge.ts` 保留 Tauri 调用、订阅、轮询与生命周期；Worker 消息字段解码位于 `bridge/tauriWorkerDecoder.ts`，事件到任务状态的归并位于 `bridge/tauriWorkerEvents.ts`。
- `application/transcribe.py` 保留转录流程编排；混合语言/中文细节复核位于 `application/recognition_passes.py`。
- `worker/runtime.py` 保留常驻 Worker 生命周期；共享运行时类型位于 `worker/runtime_types.py`，模型缓存和任务数据分别位于 `worker/model_cache.py`、`worker/task.py`。
- Rust `worker_host.rs` 保留进程监管与命令发送；模型、媒体、日志和启动参数校验分别位于 `worker_host/models.rs`、`worker_host/media.rs`、`worker_host/logs.rs`、`worker_host/validation.rs`。
- Python `protocol/desktop_ipc.py` 保留协议对象与生命周期；通用字段/事件校验和质量诊断校验分别位于 `desktop_ipc_validation.py`、`desktop_ipc_quality.py`。Rust 对应的质量诊断校验位于 `protocol_quality.rs`，两端共享 schema 约束但不互相调用。
- Python `worker/runtime.py` 保留常驻生命周期与队列分发；单任务执行位于 `worker/task_execution.py`，模型缓存和共享运行时类型继续独立维护。
- Python `domain/models.py` 是模型身份、能力和仓库映射的唯一事实源；`tools/codegen/generate_model_catalog.py` 生成 Web 与 Rust 投影并检查 IPC schema 枚举。
- Web 不再提供独立模型切换、推理参数或硬件优化工作台；`selectedModelId`、参数快照和本地模型清单只服务任务恢复、持久化兼容与提交校验，不形成隐藏页面。旧硬件偏好会在持久化迁移时丢弃。
- Worker 路径归一化、输入展开和媒体时长探测位于 `worker/media.py`；`runtime.py` 只负责编排。
- React 原生通知也通过 typed `DesktopBridge`；eslint 禁止 `src/bridge/` 之外直接导入 `@tauri-apps/*`。

这些模块拆分不构成新的运行时层，也不改变已有公开入口；后续功能修改应优先落在对应职责文件中。

## 数据流

`CLI 或 Desktop IPC → TranscriptionRequest → preset → 媒体发现 → 硬件/模型 → 转录 → 后处理 → 原子输出 → 进度与结果事件`。

Worker 通过单 dispatcher 串行执行任务，在启动时自动解析硬件并按任务冻结实际模型、Preset、硬件和输出计划；模型可以在任务之间复用，并在空闲超时后释放。IPC 不再接受人工硬件偏好；`model.load`、`model.unload` 仅作为 v1 兼容命令保留，当前桌面 UI/bridge 不调用。

## 关键边界

- `contracts/desktop_ipc/v1/desktop_ipc.schema.json` 是跨语言协议事实来源。
- Worker stdout 只输出协议，普通日志写 stderr/日志通道。
- `apps/web` 不直接启动进程、执行 shell、访问 Python 或越过 bridge 调用 Tauri；组件只依赖 typed `DesktopBridge`。
- 开发态 `apps/web` 由固定 loopback Vite 服务提供 HMR，Tauri 通过 `devUrl` 加载；正式构建只嵌入 `apps/web/dist/`。开发服务器不会进入 Release，也不改变 Desktop IPC 或 Worker 边界。
- Rust 不实现转录算法、Preset 或后处理。
- 默认输出写入媒体旁的 `Text`、`Markdown`、`SRT` 目录；自定义输出目录有独立覆盖/跳过规则。
- `build/release/` 是可再生发布中间态；最终便携目录与同内容 ZIP 固定为 `dist/WhisperSubtitle/`、`dist/WhisperSubtitle.zip`。成品根目录只提供 `WhisperSubtitle.exe` 和使用说明，技术运行时统一位于 `_internal/`。
- 可选 NSIS 介质从本地解析并校验微软签名的 WebView2 x64 离线安装器，放入介质 `_internal/distribution/` 后由安装钩子执行；Tauri bundler 不依赖微软短链接下载。
