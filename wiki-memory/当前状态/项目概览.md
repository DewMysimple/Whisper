# 项目概览

## 项目目标

WhisperSubtitle 是面向 Windows 11 x64、NVIDIA GPU 和本地离线使用的字幕转录桌面应用。它提供统一 Python CLI、常驻 Worker、Tauri 2 + React/TypeScript 桌面界面，以及 TXT、Markdown、SRT 输出。

## 当前产品入口

- 完整便携版入口：`dist/WhisperSubtitle/WhisperSubtitle.exe`
- 完整便携版压缩包：`dist/WhisperSubtitle.zip`
- 开发编译产物：`apps/desktop/src-tauri/target/release/whisper-subtitle-desktop.exe`，不能脱离 Worker/模型作为最终交付物
- CLI：`python -m whisper_subtitle transcribe`、`check`、`worker`
- 正式桌面不打开浏览器、不启动 localhost 服务。

最近已验收的便携版基线为 2026-09-23；`dist/WhisperSubtitle/`、`dist/WhisperSubtitle.zip` 与校验资料已配套重建，纳入截至当日的偏好设置、模型／参数、硬件及参数页布局整改。目录 manifest、ZIP 全量 CRC、SHA256、冻结 Worker 协议和真实 EXE 的 packaged-sidecar 生命周期均通过；识别输出行为继续沿用 2026-09-20 已完成的 CUDA／CPU 与真实媒体验收基线。

## 当前工作状态

截至 2026-09-20，开发源码按新授权恢复“模型与参数”工作台，提供本地模型选择和 36 项推理参数控制；文本识别模式下方增加同路径卡片风格的快捷入口。模型／preset 配置分别保存，下一任务启动时应用，运行任务保持冻结。详情见 [[决策/ADR-004-模型与参数工作台]]。同日后续授权新增“硬件优化”工作台，提供设备、GPU 编号、精度和 CPU 推理线程，以及四个基于实际能力的快捷方案；见 [[决策/ADR-005-硬件执行设置与工作台]]。`model.load`、`model.unload` 继续仅作 v1 兼容命令。模型／参数页面统一为任务／性能工作台的面板、连续分段导航与紧凑标题，模型卡按等宽网格与等高行排列。

UI 开发期通过固定的 `http://127.0.0.1:1420` Vite/HMR 服务迭代；`corepack pnpm desktop:dev` 会自动启动该服务并连接真实 Tauri bridge。正式构建仍嵌入 `apps/web/dist/`，不启动 localhost。

转录工作台的启动卡片现为一体化“执行前清单”：任务开始前集中核对版本、模型、媒体数量与时长、输出和执行策略。输出格式用间隔点分隔，同名规则只显示“覆盖／跳过／重命名”，实际执行前确认行为不变。清单与“文本识别模式”的 2×2 内卡片共用行高和行距；四张清单卡片是无选中态、无页面滚动副作用的配置快捷入口。“当前输出”“选择以启用”和执行前清单徽标共用高度与图文中心线，文本模式未启用继续使用文件图标，SRT 未启用继续使用字幕图标，“待补充”继续使用警告图标；待补充徽标、需要补充的清单卡片和 SRT“选择以启用”使用同一柔和强调色通道，当前输出仍保留绿色。“查看媒体文件进度”直接进入任务监控的逐文件进度；当前输入通过非持久化预览在 Mock 与 Tauri 页面中实时同步（目录仅展示真实路径、媒体数量与汇总时长，提交后才展示 Worker 展开的文件清单），执行前清单和任务监控都能清空选择且不会删除源文件。没有新输入时继续显示上一轮监控任务，正式 Tauri/Worker 状态不受影响。

当前分支的文件输出试验版按保存位置、文件格式、同名文件和完成动作分为四个连续分区，以细分隔线组织；保存策略使用连体按钮，格式使用带勾选标记的选项，同名与完成动作横向排列。未选择格式时，说明文字位于格式标题下方、选项上方；选中格式后隐藏文字但保留占位，避免格式选项及下方设置纵向跳动。2026-09-24 开发态保存位置提供“跟随／文件夹／自定义”：跟随直接写媒体目录；文件夹把 TXT／MD 放入媒体旁 Text、SRT 放入媒体旁 SRT，按所选格式组合；自定义点击即打开系统文件夹选择器，所选路径在原说明行单行省略显示，不添加路径框或副本区域。三个按钮与同名规则共用尺寸、圆角和主题反馈；取消选目录保持原策略和路径。窄于等于 1400px 的工作台同时切换单列轨道和区域，避免长路径挤压来源卡。本轮排版试验通过独立工作树的 `127.0.0.1:1421` 预览；原 1420 服务保留。上述改动尚未更新完整 dist。

“任务监控与记录”把监控／历史两项入口融入当前内容面板顶部，与历史四张筛选卡共用连续分段卡片外观和交互。实时监控保留四列任务元信息、同轴双进度、来源／输出及逐媒体清单；媒体卡不显示路径，成功项只保留勾、百分比和计时，去掉“已完成”；点击或键盘激活通过 typed bridge 定位文件：未完成／失败／跳过时定位源媒体，成功后优先定位该媒体实际记录的 TXT、MD，只有 SRT 时定位 SRT。旧批量历史缺少输出关联时保守定位源文件，不能按同名文件猜测映射。处理链路的图标与标题在同一行居中，完成项只显示勾，不再重复“完成”。

历史管理仍保留搜索、日历、四类筛选和二次点击清除，计数与筛选共用规则；归档卡在宽桌面下四列，并按 3／2／1 列响应窄窗口。卡片标题使用正文字阶，与状态图标在首行居中对齐，过长名称保留开头与后缀，并去除扩展名前的展示空白；创建时间不带时钟图标，独占下一行，与卡片内容左边缘对齐。状态／百分比／细进度轨道位于标题与时间下方。六格事实区是有内缩留白、独立圆角闭合边框的 3×2 表格；底部仅保留模型名称，去掉“模型”标签，与删除、重试、定位、详情操作在宽卡内同排居中；操作共用无独立浮起边框的图标按钮，统一点击区域和图标尺寸。卡片本身不超过 270px 时自动分为模型行与操作行，适配字号、侧栏及窗口变化。详情抽屉使用更宽的自适应版面、中文状态和两列概要；输入、输出路径和预览优先显示，参数、诊断在后，底部操作随滚动可见。预览跟随主题，长路径和参数可换行。

Worker 日志工作台将 Worker、进程、模型和缓冲区联结为同一圆角状态条的四个分段；四张卡可点击／键盘激活定位对应最近日志（缓冲区定位最新行），无持久选中态，不改变原始日志，并保留“运行就绪”的绿色图标和绿色底线；四段底线贴满各自宽度，在内部竖向分隔处不再留空白断口。下方继续使用统一诊断控制台。空会话会说明 Worker 启动、模型加载和任务执行三个采集阶段；有效日志按行号、日期/时间、来源和正文分列展示，复制与导出仍读取原始缓冲区。控制台在浅色主题下使用浅色诊断表面，在深色主题下使用深色表面，新配置的默认日志字号为 13px，正文按该字号显示，统一使用界面字体并保留换行与文本选取；时间和来源标识使用带中文回退的等宽字体。监控的输入／输出摘要与 Worker 状态共用公共文字组件，内容字号与日志字号互相独立。偏好设置分别持久化桌面框架字号、工作台内容字号、Worker 日志字号、展开导航宽度、工作台最大宽度和顶栏高度；顶栏高度默认 116px，可在 96–168px 范围内独立调节，也可直接拖动顶栏底边，使用方向键调节或双击恢复默认值。顶栏还可直接收起／展开，折叠偏好独立持久化，不丢失展开高度；设置页外观预览中的“开始本地转录”可返回转录工作台，复用公共 Button 的可选内部动效，提供柔和渐亮、轻抬与按压回弹，点击区域保持固定；系统减弱动画时保留静态状态反馈。框架与内容字号不共用缩放变量，旧版本 1 配置会迁移缺失字段。主题与强调色提供八组兼容浅色／深色界面的工作台调色板；自定义取色器支持二维饱和度／明度、色相与 RGB 精确输入，强调色不透明度固定为 100%，成功、警告和错误语义色不随强调色改变。主题卡只保留预览和名称；展开导航宽度可以在侧栏边界直接拖拽，三组工作区尺寸和三组字号均可在设置页输入精确整数。两类数值使用协调的等宽字形，并比对应说明字阶高 2px；工作区尺寸值按右侧单位之前的白色数值区居中，三组字号值按各自数值框居中，宽度值保留强调色。`px` 固定在右侧独立单元，焦点仅绘制完整控件外框，不显示原生数字控件或内部假边框。

任务监控与记录已集中到 `components/tasks/`，组件与样式有固定修改入口和覆盖检查；任务页宽度跟随工作台偏好，日历可跨管理卡完整显示，自动跟随只滚动媒体列表。已有并发提交、断连终态、迟到事件、历史输出检查与预览竞态门禁继续保留，并增加原样式规则生效、筛选计数一致和详情确认状态隔离的回归。具体状态约束见 [[知识/模块/Tauri与React桌面层]]。

2026-09-20 后续交互整改已移除全局按钮按下缩放与开始按钮悬停位移，公共动作卡只用颜色／阴影反馈，连续卡片的边缘不再因按下收缩露空；开始按钮悬停保留渐变层。通用按钮、图标按钮及卡片样式有独立职责和防回归检查。

本轮按用户追加授权完成正式前端、Host、冻结 Worker 与 dist 配套构建，真实 EXE 已验证设置保存、模型卡尺寸、带自定义推理／硬件配置的任务及 Worker 持续监管；详见 [[日志/2026-09-20-硬件优化与工作台统一及便携版更新]]。

2026-09-23 将“偏好设置”字体菜单抽为公共 `RoundedSelect`，模型与参数、硬件优化的选择器全部复用；两页的分组标题、配置状态及硬件摘要使用当前主题强调色，弹层可跨卡片边界展开。这些变更已在同日纳入最新完整便携版。

同日“整体界面大小”面板位于“字体与字号”下方，三张卡均分面板全宽，不在右侧留白。偏小、平衡、偏大分别将框架／工作台／日志字号设为 12／12／11、14／14／13、16／16／15 px，同时将工作台内容宽度设为 1360、1540、1720 px；默认平衡。主题卡和大小卡共用 `PreferenceChoiceCard`。四项仍可分别微调与持久化；卡片状态按四个实际数值判断，微调后不虚报预设选中。

“模型与参数”的本地模型卡继续使用等宽等高网格，但改为紧凑的名称／能力／状态／容量结构；模型选择与转录工作台清单共用 `CardButton`，稳定悬停时不使用大面积内阴影。路径只通过独立文件夹图标进入；已安装模型定位真实目录，未安装模型打开存放根目录并提示放入以注册 ID 命名的子文件夹。浏览器 Mock 仅演示入口，真实资源管理器动作由 Tauri Host 执行。

同日后续移除模型／参数页重复的说明与返回条；参数分组卡平时裁切内层网格以保留圆角，下拉菜单展开时允许跨卡片显示且保留末行圆角。根页面预留稳定滚动条槽，长参数页与短模型页切换时工作台不再左右偏移。上述整改已进入 2026-09-23 正式便携版。
