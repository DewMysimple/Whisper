# WhisperSubtitle 架构瘦身实施

## 目标

落实维护性评估中确认的低风险重构：减少跨语言重复事实，拆分大模块内部职责，不改变 Python、React、Rust、IPC、输出和测试行为。

## 已实施

- Python `domain/presets.py` 作为 preset 与模型校准参数来源；新增 `scripts/generate_preset_catalog.py` 生成 Web 参数投影，并由 `pnpm check:preset-catalog` 检查漂移。
- React 将 workspace 事件处理、任务纯函数和 Tauri Worker 消息解码移出主 store/bridge；组件仍只依赖 typed `DesktopBridge`。
- Python 将 `TranscriptionService` 的识别阶段编排、Worker 模型缓存、共享运行时类型和任务数据对象拆为独立模块；公开入口和任务生命周期保持不变，并消除了 runtime 与 model cache 的循环导入。
- Rust 将 Worker Host 的模型目录和启动 draft 校验拆为子模块；Host 仍是 WebView 与 Worker 的唯一运行时边界。
- 新模块只做职责拆分，未修改 IPC v1、preset 身份、输出规则、模型加载策略或 UI 交互授权边界。

## 验证

- `corepack pnpm check`：通过；20 个前端测试文件、87 个测试通过。
- `corepack pnpm --filter @whisper-subtitle/web build`：通过。
- `cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml`：通过。
- `python -m compileall -q src/whisper_subtitle scripts`：通过。
- 架构与 IPC 测试 64 个通过；preset/registry 测试 51 个通过。
- 转录与 Worker 功能测试中剩余失败均受当前环境缺少 `opencc` 影响；未发现本次拆分导致的导入或名称错误。
- `python -m whisper_subtitle check` 仍因当前环境缺少 `psutil`、`faster_whisper`、`ctranslate2`、`opencc` 和本地模型而失败；未执行 Tauri 构建、CUDA 重测或 UI 行为验收。

## 当前状态与遗留

本轮代码仍处于未提交的开发中状态；不能视为已封版。后续若把本轮 UI 结构变更纳入正式版本，仍需按 UI 门禁执行 Tauri Release 构建和 EXE 烟测。

预设参数已经有 Python → TypeScript 的生成链，但 Rust、Python 协议和 TypeScript contract 的跨语言模型 ID 仍有各自声明；若未来扩展模型目录，应把跨语言目录生成/校验作为单独任务，不在本轮扩大范围。
