# WhisperSubtitle 架构瘦身收口

## 目标

继续完成用户要求的维护性瘦身：把剩余的跨边界大模块拆成职责明确的辅助模块，保持现有 UI、IPC、输出规则和公开入口不变，并补齐当前架构记忆。

## 本轮变更

- React 外观偏好从 `state/persistence.ts` 拆到 `state/appearancePreferences.ts`，保留旧模块的兼容导出。
- Tauri Worker 事件到任务快照/进度/错误事件的归并从 `bridge/tauriDesktopBridge.ts` 拆到 `bridge/tauriWorkerEvents.ts`；正式 bridge 只保留原生调用、订阅、轮询和生命周期。
- Rust Desktop IPC 的质量诊断校验从 `protocol.rs` 拆到 `protocol_quality.rs`；通用信封与字段校验继续由 `protocol.rs` 负责。
- 更新 `docs/architecture/current_architecture.md`、`wiki-memory/当前状态/系统架构.md` 和当前待办，记录新的维护边界。

## 已确认的维护规则

- `domain/presets.py` 仍是 preset 业务参数事实源，TypeScript catalog 是生成投影。
- `TauriDesktopBridge`、Rust Host、Python Worker 依次构成 WebView 到本地推理的唯一运行边界；组件不直接调用 Tauri 或 Python。
- 跨语言协议字段仍以 `contracts/desktop_ipc/v1/desktop_ipc.schema.json` 和对应测试为准；Python/Rust 的质量校验只实现各自边界，不复制业务流程。
- 未提交的 UI/结构变更仍属于开发中事实，不代表 Release/EXE 已验收。
