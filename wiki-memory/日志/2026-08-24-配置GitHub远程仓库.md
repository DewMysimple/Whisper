# 配置 GitHub 远程仓库

## 目标

将本地 WhisperSubtitle Git 仓库连接到用户提供的 GitHub 远程仓库。

## 变更

- 将 `https://github.com/DewMysimple/WhisperSubtitle.git` 配置为远程 `origin` 的 fetch/push 地址。
- 未修改生产代码、测试、模型或用户工作区数据。
- 未执行 `git push`，未改变本地 `master` 分支或提交历史。

## 验证

- `git remote -v` 显示 `origin` 的 fetch/push 地址正确。
- `git ls-remote --heads origin` 可访问远程，并确认远程存在 `main` 分支。

## 遗留问题

- 本地分支为 `master`，远程默认分支为 `main`，当前未设置上游分支。
- 本地工作树仍有未提交改动；如需推送，应先确认分支合并/命名策略并处理这些改动。
