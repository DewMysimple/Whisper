# 第 32 次修改：修复 SRT 切换碎片与参数入口

## 目标与授权

用户明确授权在正式 React/Tauri 工程中处理两个转录工作台 UI 问题：

1. 从“文本识别模式”切换到 SRT 后，文本识别卡底部出现异常残留/碎片区域。
2. 将“查看并修改模型参数”改为类似“粘贴 Windows 路径”的整块可点击 UI，取消内嵌的独立按钮，并将默认提示居中显示为“查看并修改当前模型与模式使用正式默认参数”。

截图仅作为视觉差异参考；页面结构和正式行为依据当前源码。未修改第三阶段 UI、Python Worker、Desktop IPC v1、Preset 参数语义、模型、输出规则或任务契约。

## 变更

- `apps/web/src/styles.css`：移除 SRT 状态下给文本识别卡和启动/队列卡额外增加的 3px 底部增量，避免模式切换时网格行出现残留空间。
- `apps/web/src/components/PresetPanel.tsx`：将参数入口从“展示容器 + 内嵌按钮”改为单一整块 `<button>`，整块区域可点击并跳转到模型参数页；提示文字居中，默认文案为“查看并修改当前模型与模式使用正式默认参数”。
- `apps/web/src/styles.css`：为整块参数入口补齐与剪贴板路径入口一致的 hover、focus、active 和减少动态效果处理。
- `apps/web/src/App.test.tsx`、`apps/web/e2e/desktop-workspace.spec.ts`：更新入口文案断言，并增加无嵌套按钮、居中样式及文本/SRT 模式切换后卡片高度稳定的回归断言。
