# 删除参数配置增强模式

## 目标

按用户授权，从参数配置中删除“复杂中英混合”和“中文细节增强”两个识别策略选项及其说明，不再让新任务从 UI 选择这两个模式。

## 变更

- `InferenceParameterEditor` 移除识别策略选择区、说明文案和对应的废弃样式；参数配置只保留现有模型参数与温度策略。
- 启动摘要不再显示已退役策略；新建、重试、续传任务统一使用 `stable_primary`。
- 旧偏好配置中的增强策略会归一化为稳定主语言并清空策略配置；旧任务快照、诊断展示和 Desktop IPC/Worker 兼容解析保留，确保历史记录可读且不改写历史事实。
- 补充参数配置、偏好导入、续传归一化和桌面 E2E 覆盖；测试之间显式重置关键工作区状态，避免共享 Zustand 状态影响确认流程。

## 验证

- `corepack pnpm check`：20 个测试文件、87 个测试通过。
- `corepack pnpm exec playwright test --config=playwright.alt.config.ts`：12 个桌面 E2E 通过；因 4173/4174 被其他 Node 服务占用，使用临时 4180 端口配置，验证后已删除临时文件。
- `corepack pnpm desktop:build`：Tauri Release 构建成功。
- Release EXE 启动冒烟：进程存活且窗口句柄有效，测试进程已安全关闭。
- `git diff --check` 和记忆索引/体检在提交前执行。

## 遗留与边界

本次不删除 Python 识别实现、`RecognitionStrategy` 协议值或历史任务中的策略标签；如未来重新开放增强策略，需基于真实媒体证据建立新的功能测试并获得单独授权。
