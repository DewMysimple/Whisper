# 删除模型切换工作台

## 目标

按用户明确授权，从正式软件删除“模型切换”工作台及相关冗余代码，暂不设计替代页面，同时保证其他工作台与转录运行链路不受影响。

## 实际变更

- 从侧栏、顶栏页面映射和应用渲染树中删除“模型切换”入口与 `ModelSwitchView`。
- 删除工作台内的模型卡片、推理参数编辑器、转录 preset 参数入口及全部专属样式；SRT 排版参数编辑器继续保留。
- 删除只服务该工作台的 tab、模型选择、待切换、模型清单加载状态，以及 Web/Rust 的“打开模型目录”命令。
- 删除模型目录中的 `visible` 展示属性和 TypeScript `VISIBLE_MODEL_IDS` 投影；模型 ID、默认模型、能力组和仓库映射继续由 Python domain 统一生成。
- 将硬件优化共用的加载标志改名为 `modelReloading`，明确它表示硬件配置触发的模型重载，不是已删除的模型选择流程。
- 更新单元测试、Playwright、正式文档和 active 记忆，新增“工作台不得从历史基线自动恢复”的门禁。

## 保留边界

- 保留任务级 `selectedModelId`、草稿/历史快照、旧偏好和导入配置兼容，避免破坏现有任务恢复。
- 保留任务启动与续接前的本地模型完整性校验，以及硬件优化调用的模型重载。
- 保留 Desktop IPC v1、Worker 模型缓存、Preset、输出规则和其他工作台；未修改或删除本地 `models/`、虚拟环境、构建缓存和用户输出。
- 未来若重做模型工作台，需要新的产品设计和用户授权，不能直接恢复历史页面。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、生成目录、格式、lint、typecheck 和 Web 单测统一门禁通过。
- `whisper_env\\Scripts\\python.exe -m pytest -q`：363 passed。
- Web Vitest：20 files、85 tests passed；TypeScript typecheck、ESLint 和 Prettier 检查通过。
- Playwright：12 passed，覆盖工作台入口不存在，以及转录、硬件、性能、历史、SRT、日志等其余工作台路径。因本机另一个范围外 Vite 服务占用 4173，验收时临时使用 4174，完成后已还原配置且未终止范围外进程。
- Rust：`cargo fmt --check`、`cargo test --locked`（33 passed、2 ignored）和 `cargo clippy --locked --all-targets -- -D warnings` 通过。
- 模型/Preset 生成一致性、仓库卫生和 `git diff --check` 通过。
- `corepack pnpm desktop:build` 通过；Release EXE 隐藏启动后持续运行 5 秒，随后仅结束本次烟测进程。
- 构建仍只有既有的 JavaScript chunk size 与 MSVC linker 信息性警告，不构成本次阻塞。

## 遗留事项

- 本次没有设计替代模型工作台。底层历史兼容路径继续存在，但不构成隐藏 UI。
- Large V3（非 Turbo）的真实完整验收仍按已知问题保留，不把本次 UI 删除扩大为模型推理验收。
