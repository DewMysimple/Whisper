# 删除硬件优化工作台

## 目标

按用户明确授权，从正式工程删除“硬件优化”工作台及人工设备、精度和 CPU 线程配置，并检查删除过程中遗留的冗余代码；保留转录所需的自动硬件探测、任务级实际硬件记录和性能监控。

## 实际变更

- 删除侧栏入口、页面组件、样式、Zustand 状态与动作、持久化偏好、草稿字段和 bridge 能力展示；旧 localStorage 与历史草稿中的硬件偏好会在读取时被忽略并丢弃。
- 删除 Web、Rust Host、Desktop IPC schema 和 Python Worker 中的人工硬件偏好字段、校验、能力清单及转换代码。
- Worker 在任务启动时自动选择 CUDA 设备 0 的 FP16，必要时回退 FP32；无 CUDA 时使用 CPU INT8/4 线程。解析结果仍冻结到任务并通过 `task.queued` 回传。
- 删除此前只由模型/硬件工作台使用、已无调用方的显式 `model.load` 与 `model.unload` 命令；自动任务加载仍保留 `model.loading`、`model.ready` 和加载失败事件。
- 保留任务模型快照、本地模型完整性校验、模型缓存与空闲释放、实际硬件元数据、任务详情和性能监控。
- 增加旧偏好/旧草稿迁移测试、工作台不存在的 UI/E2E 断言，以及自动精度选择和不支持精度时显式失败的回归测试。

## 边界说明

- 本次对 Desktop IPC v1 命令与字段的收窄来自用户对硬件优化功能及冗余代码删除的明确授权；协议版本号不变，现有任务生命周期与实际硬件结果结构不变。
- 未修改 Preset、识别策略、输出规则、SRT 时间轴、本地模型目录、虚拟环境、构建缓存或用户输出。
- 历史归档保持只读，旧硬件工作台与显式模型命令的记录仅用于追溯，不代表当前能力。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、模型/Preset 生成一致性、Prettier、ESLint、TypeScript 与 Web 单测通过。
- Web Vitest：20 files、81 tests passed；Playwright：12 passed。
- `whisper_env\\Scripts\\python.exe -m pytest -q`：355 passed。
- Rust：`cargo fmt --check`、`cargo test --locked`（32 passed、2 ignored）和 `cargo clippy --locked --all-targets -- -D warnings` 通过。
- `corepack pnpm desktop:build` 通过；Release EXE 隐藏启动后持续运行 5 秒，随后只结束本次烟测进程。
- 源码检索、`git diff --check`、记忆索引和记忆体检通过；只剩自动模型加载事件、实际硬件展示和迁移测试中的预期词项。
- 构建仍只有既有的 JavaScript chunk size 与 MSVC linker 信息性警告，不构成本次阻塞。

## 遗留事项

- 本次没有设计替代硬件配置页面；未来若重新开放人工设备或精度选择，需要新的产品设计、协议评审和真实 GPU 验收。
- 真实 GPU 推理结果未因本次删除重新 benchmark；本轮通过能力单测、跨语言契约测试、完整回归与正式 EXE 烟测证明自动路径保持可用。
