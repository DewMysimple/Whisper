# 对齐执行清单与识别模式卡片

## 目标

继续精调执行前清单：使右侧四张内卡片等高等宽，并与左侧“文本识别模式”四张卡片在顶边、第一行底边和整体底边上对齐。同时固定输出与执行说明的分行，统一启动文案与快捷键字号，并删除键盘图标。

## 变更

- 工作区为左右两个 2×2 卡片网格定义同一组行高和行距；默认字号下每行 `160px`，字号增大时按 `--ui-font-size` 同步增高。
- 左侧四张预设卡片和右侧四张清单卡片均填满共享行轨，从而保证同行上下边与两组网格整体上下边一致。
- “跟随每个媒体文件 / 同名时执行前确认覆盖”与“完成后无操作 / 本地 Worker 已就绪”改为明确的两行 DOM 结构，不依赖宽度碰巧换行。
- `CTRL + ENTER` 继承启动按钮字体和字号，与“开始本地转录”等大；删除键盘图标，保留同一按钮内的快捷键提示。

## 验证边界

- 几何回归直接比较左右两组卡片的顶边、底边、行高、行距和右侧卡片宽高差。
- 默认 14px 字号下实测两组八张卡片均为 `160px` 高；两段说明均为两个独立视觉行；按钮两段文字均为 `14px`，快捷键内不再有 SVG。
- 大字号工作区截图需确认内卡片文字不溢出。
- 产品代码变更仅限 `apps/web`；不改变 Tauri、Worker、Desktop IPC、Preset 或输出行为。
