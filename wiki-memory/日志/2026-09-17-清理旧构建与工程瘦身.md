# 清理旧构建与工程瘦身

## 目标

在保留当前完整源码和唯一最新正式发布套件的前提下，删除长期累积的旧版本、旧构建和缓存，缓解工程所在磁盘压力，并建立可重复的安全清理入口。

## 审计结论

- `apps/desktop/src-tauri/target/` 约 19 GiB，只是 Rust/Tauri 开发编译输出，不是完整交付物。
- `build/` 混有 batch15 至 batch30 的多代 Worker、验证输出、内部 checkpoint、旧 EXE 和当前发布 staging；均可由当前源码和锁文件重建。
- `dist/` 只包含 2026-09-17 生成的 `WhisperSubtitle/`、同内容 ZIP 和 SHA-256 文件。清理前已逐项验证 ZIP、桌面 EXE 和 release manifest 的校验值一致。
- `models/`、`whisper_env/` 和 Node 依赖是当前本地运行/开发资料，不属于旧构建；本期保留。

## 实际清理

- 永久删除 `build/`、`apps/desktop/src-tauri/target/` 和 `apps/desktop/src-tauri/gen/`。
- 删除 Web `dist/`、Playwright 测试结果、Vite 缓存、pytest 缓存、egg-info、Python 字节码缓存及旧的无追踪运行日志。
- 未删除源码、Git 历史、当前 `dist/WhisperSubtitle*`、模型、虚拟环境、Node 依赖和本机快捷方式。
- F 盘可用空间由 88.48 GiB 增至 141.29 GiB，共释放约 52.81 GiB。

## 防复发措施

- 新增 `tools/maintenance/clean_workspace.ps1`，使用固定白名单并验证 Git 根目录与每个删除目标。
- `corepack pnpm workspace:clean` 默认只预览；只有 `corepack pnpm workspace:clean:apply` 才永久删除列出的可再生产物。
- 清理入口明确排除当前正式发布套件、模型、虚拟环境、Node 依赖、源码、Git 历史和用户输出。

## 验证

- 清理后的目标路径逐项确认为不存在，`apps/` 总占用约 4.5 MiB。
- 工程外未发现遗留 EXE、ZIP、MSI、7z、tar 或 gzip 旧产物；保留的归档文档合计不足 3 MiB，属于版本化审计资料而非构建副本。
- 最新正式发布套件三项 SHA-256 校验均通过。
- `corepack pnpm check` 通过，Web 20 个测试文件、82 项测试全部通过；仓库卫生、模型/Preset 投影、格式、lint、类型检查和记忆检查均包含在内。
- 完整 Python 测试为 363 项通过；其中新增 2 项清理门禁测试，覆盖白名单删除、保护目录保留和已跟踪内容拒绝删除。
- 记忆索引与检查通过，共 50 个受管理 Markdown 页面。
- 完整门禁后再次运行 `workspace:clean:apply`，删除验证过程重新产生的缓存，最终预览无待清理目标。
- 本期未修改 Rust/Tauri 源码；为避免重新生成约 19 GiB 的 `target/`，没有重复运行 Rust 编译门禁或 Release 构建，保留的正式版改用既有 SHA-256 文件完成完整性验证。
