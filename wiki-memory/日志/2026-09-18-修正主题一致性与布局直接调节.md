# 修正主题一致性与布局直接调节

## 目标

- 让 Worker 日志面板真正服从浅色/深色主题，并修正字号数值的垂直对齐。
- 补全三种主题模式说明，协调 AUTO 标记位置，消除非橙色强调色中的固定橙色混合。
- 把字体与自定义颜色的原生方角弹层替换为应用内圆角控件。
- 支持在侧栏边界直接拖拽导航宽度，并允许直接输入任意合法整数宽度。

## 实际变更

- Worker 日志控制台使用主题化诊断色板：浅色主题使用浅灰白控制台，深色主题保留深色诊断表面；日志文字、行号、悬停、空态和阶段标签随主题变量切换。
- 字号步进器将数值与 `px` 放在同一垂直中心线上；端到端测试以实际元素中心线验证误差不超过 1px。
- “跟随 Windows”“浅色”“深色”三张主题卡均提供行为说明；AUTO 标记移到跟随系统预览的左侧栏区域。
- 品牌标记、主操作按钮和启动卡的渐变全部由当前 `--accent` 推导，不再混入固定橙色端点；自定义强调色的悬停和柔和色会根据当前浅色/深色主题分别计算。
- UI 字体与等宽字体改用具备选中态、焦点态和圆角浮层的应用内列表；自定义颜色改用常用色、RGB 通道和十六进制输入组成的圆角编辑器，不再调用系统方角颜色弹窗。
- 侧栏右边界新增可聚焦拖拽分隔条，支持鼠标拖拽、方向键、Home/End 和双击恢复默认；设置页仍保留滑杆与加减按钮，同时工作台、导航宽度都支持直接输入任意范围内整数。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、生成目录、格式、ESLint、TypeScript 与 91 项 Vitest 全部通过。
- `corepack pnpm e2e`：14 项 Playwright 全部通过，覆盖浅/深日志表面、三种非橙色强调色、字号中心线、AUTO 位置、圆角字体/颜色弹层、侧栏真实拖拽和宽度数字输入。
- `corepack pnpm desktop:build`：Web 生产构建与 Tauri Release 构建通过。
- Release EXE 烟测：窗口正常响应，受控 Python Worker 持续响应，关闭主窗口后 Desktop 与 Worker 均无残留进程。

## 边界

- 没有改变外观配置 schema、Desktop IPC v1、Worker 日志来源、任务处理或输出行为。
- 侧栏收起状态仍沿用原有独立本机偏好；拖拽与展开宽度只作用于展开状态。
