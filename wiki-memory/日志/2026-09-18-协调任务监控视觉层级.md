# 协调任务监控视觉层级

## 目标

- 修复历史概览选中底色被网格间距截断的问题。
- 从任务阶段展示中删除“GPU”字样，同时兼容已有本机历史快照。
- 放大日期筛选器，并统一实时任务监控的标题、状态、元信息和说明文字层级。

## 实际变更

- 提高历史概览组合选择器的最终样式优先级，使四张概览卡保持零间距并以边框连续分隔，选中底色不再露出白色断层。
- 新任务和 Worker 阶段映射统一使用“转录中”“等待执行”；新增共享展示归一化，对旧快照中的“GPU 转录中”“等待本地 GPU”同样隐藏退役措辞。历史卡、实时监控、性能页任务条和任务详情共用该规则。
- 日期触发器与日历弹层扩大图标、面板、导航按钮、日期格和说明文字，保留日期范围选择及仅允许选择真实任务日期的行为。
- 任务监控页统一使用全局字号变量，放大工作区切换器、任务标题、状态操作、元信息胶囊、进度卡、媒体清单与处理链路的字号和点击面积；全局 UI 字号设置仍可同步缩放。
- Playwright 增加概览卡无间隙、任务阶段无旧措辞、元信息最小字号和日历稳定尺寸断言。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、目录生成检查、Prettier、ESLint、TypeScript 与 90 项 Vitest 全部通过。
- `corepack pnpm e2e`：Web 构建成功，13 项 Playwright 全部通过；全屏截图复核了历史页、实时监控与日期弹层。
- `corepack pnpm desktop:build`：Tauri Release 构建成功。
- Release EXE 启动烟测确认主窗口就绪、受控 Python Worker 以 `-m whisper_subtitle worker` 启动并在结束后完整清理。

## 保留项

- 性能监控中的 GPU 负载、温度和显存等硬件指标继续使用准确名称；本次仅移除任务执行阶段中多余的 GPU 措辞。
- Desktop IPC v1、任务历史 schema、输出规则和真实硬件记录保持不变。
