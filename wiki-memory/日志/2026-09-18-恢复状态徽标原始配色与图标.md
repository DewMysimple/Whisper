# 恢复状态徽标原始配色与图标

## 目标

- 按用户澄清恢复工作台状态徽标原有的配色和图标，不把描述中的“红橙”理解为新的统一视觉规范。
- 保留上一轮对徽标高度、图文中心线和响应式布局有帮助的适配，不回退其他已经验收的日志、历史和设置改进。

## 实际变更

- 以 Git 中状态统一改动之前的实现为基准，恢复文本模式未启用时的 `FileText`、SRT 模式未启用时的 `Captions`；启用态继续使用 `Check`，自定义态继续使用 `Sparkles`，不再用 `CirclePlus` 替换原图标。
- 删除后加的活动／非活动状态类和强制强调色、描边规则；“当前输出”、两种“选择以启用”和“待补充”重新使用原有绿色、模式强调色及赭黄色提醒语义。
- 执行前清单中需要补充的内卡片与图标恢复原有赭黄色提示，不再被工作台强调色覆盖。
- 只保留不改变视觉身份的几何适配：徽标最小高度、弹性收缩、图文居中和标题区顶部对齐；不覆盖 Lucide 图标自身的尺寸或描边。
- 回归测试固定检查原图标类别、13px 未启用模式图标、无新增描边、提醒徽标保留独立背景以及三类徽标的图文中心线。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、生成目录、格式、ESLint、TypeScript 与 94 项 Vitest 全部通过。
- `corepack pnpm e2e`：14 项 Playwright 全部通过；覆盖文本与 SRT 状态切换后的原图标、原描边关系、独立提醒配色和几何对齐。
- 全屏截图复核：SRT“选择以启用”恢复为原浅色底与字幕图标，文本输出启用态和执行前清单布局未回退。
- `corepack pnpm desktop:build`：Web 生产构建与 Tauri Release 构建通过。
- Release EXE 烟测：主窗口与受控 Worker 正常就绪；桌面退出码为 0，Worker 无残留进程。

## 边界

- 没有改变 Desktop IPC v1、Preset、任务、输出、外观配置或其他工作台功能。
- 上一轮的 Worker 日志、历史记录、主题卡和尺寸输入改进全部保留。
