# 校准任务网格分隔与顶部标签

## 目标

- 让实时任务监控和历史卡片统计带的列线使用完整、规则的网格边界，不再出现悬空短线或主卡两侧断口。
- 将 TXT、MD、SRT 放到历史卡片状态右侧，并统一状态与格式标签的尺寸和视觉规格。
- 删除归档区标题右侧的“任务数 · 四列”说明，不改变全屏四列布局本身。

## 实际变更

- 实时监控四列元信息取消上下内缩，列线从行顶贯通到行底；监控信息面扩展到主卡左右边界，元信息、进度和输入／输出各行的横线完整连接主卡两侧，中心列线继续共用同一坐标。
- 历史卡三项统计带取消单元格外层的上下留白，两个竖向分隔从统计行上边界贯通到下边界。
- 历史卡顶部将状态和输出格式收进同一状态组；格式只保留这一处，并位于状态右侧。状态与格式标签统一为相同高度、胶囊圆角、边框、字号、字重和字体，语义色仍按运行、完成、失败状态保留。
- 针对全屏四列的窄卡宽度压缩顶部间距，保证“运行中 / TXT / MD / 进度”同时完整显示；图标、任务状态配色和四列布局未改。
- 删除归档标题右侧的“2 个任务 · 四列”等动态说明。

## 验证

- React 组件测试覆盖状态组归属、格式标签唯一位置和归档列数说明删除。
- Playwright 几何断言覆盖标签位于状态右侧、全部格式可见、三类标签样式一致、历史统计列线贯通、监控元信息列线贯通、中心列线同轴以及横线连接主卡左右边界。
- 全量工程检查、E2E、Tauri Release 构建与 EXE 启动烟测均通过。

## 保留项

- 输出格式、任务进度、状态和历史筛选仍由原有任务快照派生；本次不修改任务数据、Desktop IPC v1 或输出行为。
- 全屏历史归档仍为四列，并继续按既有断点响应为三列、两列和一列。
