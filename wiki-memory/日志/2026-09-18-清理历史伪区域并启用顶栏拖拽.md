# 清理历史伪区域并启用顶栏拖拽

## 目标

- 去掉历史管理卡与任务卡之间由旧外层容器造成的“伪区域”，让两个区域通过真实画布留白分开。
- 补满 Worker 四段状态条底线在分隔处的缩进断口。
- 让顶栏高度可直接拖拽，同时保留设置页精确调节。
- 删除历史任务卡配置摘要中的重复状态文字，但保留卡片顶部状态徽标。

## 实际变更

- 历史管理卡继续保存标题、查找、维护操作和四项状态筛选；下方任务列表改为无边框、无背景、无阴影、无内边距的布局层。旧 `.task-panel` 外壳也在历史展开态取消视觉表面，因此上下区域之间保留 24px 真实画布间距，不再由大白色底板或窄框相连。
- 历史任务卡中的摘要由“转录版本 · 执行状态 · 输出格式”改为“转录版本 · 输出格式”，标题相应改为“转录配置”；卡片顶部的状态图标、状态文字和右上角百分比不变。
- Worker 状态条四段底部标记延伸到各自左右边界，消除三处分隔处的空白断口；首段就绪状态继续使用原有绿色图标与绿色底线，其余分段保持既有强调色。
- 顶栏底边新增可聚焦的横向分隔手柄：指针拖拽实时更新持久化 `topbarHeight`，上下方向键按既有步长调节，Home／End 到达范围边界，双击恢复 116px 默认值。设置页仍与该字段共享同一事实源。
- 不改变主题配色、既有图标、任务状态语义、历史操作或 Desktop IPC v1。

## 验证

- `corepack pnpm check` 通过：仓库卫生、66 篇记忆页、模型／Preset 生成投影、Prettier、ESLint、TypeScript 与测试全部通过。
- 24 个 Vitest 文件中的 95 项测试通过；任务卡测试同时约束“顶部状态保留”和“配置摘要不含状态”。
- 15 项 Playwright 测试通过；新增断言覆盖历史两层旧外壳均为透明布局、上下间距 24px、Worker 底线左右贴边，以及顶栏真实指针拖拽从 116px 调到 136px。
- 全屏浅色截图人工检查通过：历史管理卡和任务卡之间露出画布留白，Worker 底线连续，顶栏底边显示安静的横向拖拽手柄。
- Tauri Release `--no-bundle` 构建通过；实际启动 Release EXE 后窗口标题为 `WhisperSubtitle`、进程响应正常、受控 Python Worker 持续运行，正常关闭退出码为 0 且无残留子进程。

## 保留项

- 历史任务状态仍只由任务快照决定；本次仅去除卡片内部的重复展示，不改筛选或数据。
- 顶栏高度合法范围继续是 96–168px，拖拽不会影响导航宽度、工作台宽度或三组字号。
