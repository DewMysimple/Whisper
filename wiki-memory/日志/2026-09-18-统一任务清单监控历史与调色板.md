# 统一任务清单监控历史与调色板

## 目标

- 让执行前任务清单与任务监控共享当前媒体事实，并在两个入口都能清空已选媒体。
- 深化实时任务监控的信息层级，补齐只保存旧任务摘要时的逐媒体展示。
- 把本机任务历史的查找工具和状态筛选收束为一个完整外壳，移除“查找与筛选”的额外内框。
- 为偏好设置提供适配既有浅色、深色界面的工作台强调色调色板与完整自定义取色器，不改变语义状态色。

## 实际变更

- 当前选中的文件或目录会生成非持久化输入任务预览，在 Mock 与 Tauri 页面中均可供任务监控实时读取；它不进入 Desktop IPC，也不写入历史。执行前清单与任务监控分别提供“清除任务清单”入口，均只清空选择而不删除源文件。
- “查看媒体文件进度”会切换到“任务监控与记录／任务监控”；历史任务缺少逐媒体事件时，监控页会从任务媒体路径和当前序号推导安全的逐文件回退列表。
- 实时监控以标题、四列任务元信息、整体进度、当前媒体、输入／输出摘要、逐媒体列表和处理链路形成稳定层级；逐媒体行显示父目录、短状态、耗时和百分比，避免重复长路径与文件名。
- 本机历史的标题、查找工具、维护操作和底部四项状态筛选合并到同一圆角管理外壳；“查找与筛选”不再拥有背景、边框、阴影或额外内边距，各个输入与按钮仍保留自身控件边界。
- 主题与强调色新增八组经过浅色／深色适配的工作台调色板；自定义入口升级为应用内圆角取色器，提供二维饱和度／明度面板、色相轨道、RGB 数值和实时色值预览。强调色不透明度固定为 100%，避免全局文字、焦点与操作控件失去必要对比度；成功、警告、错误等语义色保持固定。

## 验证

- Web TypeScript、ESLint 与 24 个测试文件中的 95 项 Vitest 全部通过。
- Web 生产构建通过；仅保留既有的大于 500 kB chunk 提示。
- 15 项 Playwright 桌面工作区测试全部通过，覆盖双入口清空、监控跳转、逐媒体回退、历史外壳几何、无筛选内框、八组调色板、自定义二维取色器以及全屏布局。
- 已人工检查全屏历史、任务监控与偏好设置截图；历史工具区无独立套框，逐媒体列表显示两条媒体，调色板在既有配色体系内保持一致。
- Tauri Release `--no-bundle` 构建通过；实际启动 Release EXE 后，主窗口响应正常且受控 Python Worker 已运行，正常关闭后 Desktop 与 Worker 均无残留进程。

## 保留项

- 不改变 Desktop IPC v1、Worker 任务事件、任务历史持久化格式或源媒体文件。
- 当前输入预览只用于提交前核对；真正任务启动后仍以 Worker 事件为正式进度事实源。
