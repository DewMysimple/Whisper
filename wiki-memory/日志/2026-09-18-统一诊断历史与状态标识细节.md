# 统一诊断历史与状态标识细节

## 目标

- 收紧偏好设置中的主题卡片和尺寸输入，消除说明冗余与数值后缀溢出。
- 让 Worker 日志成为可扫描的结构化诊断界面，并把新安装或缺失字段时的默认日志字号调整为 13px。
- 修复历史任务长名称截断，融合历史概览与管理区，并统一工作台状态徽标。

## 实际变更

- 主题卡片只保留预览和主题名称，不再重复显示行为说明；工作台与导航宽度的整数输入把数值和 `px` 保持在同一圆角边界内，并在全屏双栏和窄屏布局中阻止横向溢出。
- Worker 日志将 Host 的原始时间戳、来源和正文解析为“行号、日期/时间、来源、正文”四个稳定视觉列；Worker、Model、Task 和错误来源使用可区分标签，未匹配行仍保留完整原文。复制和导出继续使用原始日志缓冲区。
- `logFontSize` 的默认值由 12px 调整为 13px；已有配置中显式保存的字号不被迁移覆盖。
- 历史概览和历史管理面板进入同一个外壳，取消中间空隙并共用边框、圆角和阴影；长任务名称在可用宽度末尾显示省略号，完整名称仍保留在 `title` 属性中。
- “当前输出”“选择以启用”和执行前清单状态统一高度、内边距、图标尺寸和文字中心线；可执行状态保留绿色，待选择、派生自定义和“待补充”统一使用当前红橙强调色。
- 浏览器 Mock bridge 只为开发态诊断页面提供三条代表性日志，便于全屏视觉回归；正式 Tauri bridge 和 Worker 日志来源未改变。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、生成目录、格式、ESLint、TypeScript 与 94 项 Vitest 全部通过。
- `corepack pnpm e2e`：14 项 Playwright 全部通过，覆盖徽标图文中心线、历史区域融合、长标题省略、结构化日志、13px 默认值和尺寸输入无溢出。
- 全屏截图人工复核：设置、Worker 日志、历史记录和转录工作台的相关状态均符合目标布局。
- `corepack pnpm desktop:build`：Web 生产构建与 Tauri Release 构建通过。
- Release EXE 烟测：主窗口和托管 Python Worker 正常启动；关闭主窗口后 Desktop 以退出码 0 结束，Worker 无残留进程。

## 边界

- 没有改变 Desktop IPC v1、外观配置 schema 版本、Worker 原始日志、任务处理或输出语义。
- 本次只改变缺失字段时的日志字号默认值；用户已保存的合法字号继续原样生效。
