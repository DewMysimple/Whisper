# 联结 Worker 状态并拆分历史区块

## 目标

- 在工作区尺寸中增加独立顶栏高度调节。
- 将 Worker 日志上方四项概览联结为一个整体，同时保留“运行就绪”的绿色语义。
- 将历史管理与具体任务历史拆成两个独立区块，并避免任务卡紧贴外框。

## 实际变更

- 新增 `topbarHeight` 外观偏好，默认 116px、范围 96–168px、步长 4px；设置页提供滑杆、加减按钮和精确数值输入，实时预览同步显示。该字段继续使用版本 1 workspace 配置持久化，旧配置缺失时迁移到默认值，恢复默认与配置导入导出均覆盖该字段。
- Worker、进程、模型和日志缓冲区共用一个圆角外壳，分段之间仅保留内部边界；“运行就绪”继续使用原有绿色图标、绿色柔和背景和绿色底线，其余状态维持既有强调色。
- 历史标题、查找、维护操作和状态筛选保留在上方管理外壳，具体任务卡移入下方独立归档外壳；两块间距为 24px，任务卡距归档外框为 20px，窄屏内边距收敛为 12px。
- 不改变 Worker 日志内容、任务历史行为、筛选语义、卡片操作或 Desktop IPC v1。

## 验证

- `corepack pnpm check` 通过：仓库卫生、记忆、生成目录、格式、ESLint、TypeScript 与 24 个测试文件中的 95 项 Vitest 全部通过。
- `corepack pnpm e2e` 的 15 项 Playwright 测试全部通过；新增断言覆盖顶栏实际高度、Worker 四段无缝联结，以及历史两块间距和任务卡内边距。
- 全屏截图人工检查通过：Worker 状态条保持绿色就绪语义，历史记录形成清晰双区块，设置页新增顶栏高度并保持既有配色与图标体系。
- Tauri Release `--no-bundle` 构建通过；实际启动 Release EXE 后窗口标题正确、进程响应正常、受控 Python Worker 持续运行，正常关闭退出码为 0 且无残留子进程。

## 保留项

- 顶栏调节只改变标题区纵向尺寸，不与框架字号、工作台内容字号、导航宽度或工作台最大宽度联动。
- 本次没有修改主题色、状态色、图标样式或任务数据契约。
