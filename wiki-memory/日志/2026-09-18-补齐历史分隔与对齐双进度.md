# 补齐历史分隔与对齐双进度

## 目标

- 补齐历史任务卡片横向分隔线，消除卡片两侧断口。
- 放大并疏朗输出格式标签；状态由原有图标表达，不再重复显示“运行中”“已完成”等文字标签。
- 解释原先含糊的“自定义”，并对齐实时监控的整体进度与当前媒体进度轨道。
- 按后续顺序将“总时长”改为“媒体时长”，长文件名保留开头与扩展名、中间省略。

## 实际变更

- 历史事实区使用与主内容内边距相反的外扩，并把文字内缩移到各行，因此横线连接卡片内容面的左右边界，文字仍保持原有安全距离；三项统计列线继续贯通整行。
- 历史卡只保留原状态图标，图标继续提供可访问名称和悬停说明；TXT、MD、SRT 标签改为 28px 高、较大字号与 6px 间距，不改变既有配色和图标。
- `isCustom` 的展示从“自定义”改为“参数已调整”，悬停说明为相对预设调整过转录参数；Mock 历史同步补上与该状态一致的参数覆盖数据。
- 两个实时进度卡使用相同的说明区最小高度，因此标题、轨道和底部信息逐行对齐；进度值及 Worker 事实来源不变。
- 历史统计第三列改名为“媒体时长”。较长文件名拆分为可省略的名称主体和固定扩展名，呈现为“名称开头….后缀”，完整名称继续通过标题属性保留。

## 验证

- React 组件测试覆盖状态文字标签移除、状态图标可访问名称、参数调整说明、媒体时长文案和长名称扩展名保留。
- Playwright 几何断言覆盖历史横线连接两端、格式标签尺寸／间距／可读字号、双进度轨道同轴以及长名称扩展名可见；完整 E2E 15 项通过。
- `corepack pnpm check` 通过：仓库卫生、69 页记忆体检、模型／Preset 投影、Prettier、ESLint、TypeScript 与 24 个测试文件共 97 项测试全部通过。
- `corepack pnpm desktop:build` 通过，Tauri Release 无 bundle 构建成功；启动生成的桌面 EXE 后窗口可响应，标题为 `WhisperSubtitle`，并持续观察到受控 WebView2 与 Python Worker 子进程。

## 保留项

- 本次不修改任务状态、进度计算、输出格式、Preset、Desktop IPC v1 或 Worker 行为。
- 强调色、成功／失败语义色和状态图标均沿用原设计。
