# 重排历史归档与任务监控信息

## 目标

- 把历史任务卡收纳到明确的 UI 区域，并在全屏基准下维持四列对齐。
- 将 TXT、MD、SRT 从配置摘要中移到卡片顶部，作为相互独立的高亮标签。
- 把“转录配置”改为“转录模式”，并让模式、统计和模型使用一致的行式层级。
- 将媒体数、耗时和总时长整合在同一横向统计带。
- 将实时任务监控的元信息、进度和输入／输出信息整合为连续信息面，同时保留原有列线，并把任务状态与终止操作固定到右上角。

## 实际变更

- 历史管理卡与任务归档区继续通过 24px 真实画布间距分开；新增的归档区提供单一表面和标题，内部网格全屏四列，并在同一网格行内拉伸卡片等高。
- 每张历史卡顶部先显示任务状态和百分比，再以独立标签展示各输出格式；卡内不再重复输出格式。“转录模式”只显示 Preset 名称，媒体数、耗时和总时长改为同一行的三个等宽单元，模型继续使用相同行式间距。
- 实时监控移除四列元信息、两块进度和输入／输出项各自的圆角小卡外观，由主卡承载一个连续信息面；四列元信息、两块进度和输入／输出之间的竖向列线全部保留，窄屏换行时自动转换为横线。
- “正在执行”和“终止任务”使用主卡标题网格的右列对齐；已有当前媒体时，主进度区不再重复显示“转录中 · 第 N / M 个”，逐媒体列表仍保留必要的状态与进度。
- 不改变任务快照、历史筛选、删除／重试／定位操作、任务取消逻辑、配色、图标或 Desktop IPC v1。

## 验证

- `corepack pnpm check` 通过：仓库卫生、记忆、模型／Preset 生成投影、Prettier、ESLint、TypeScript 与 24 个 Vitest 文件中的 96 项测试均通过。
- `corepack pnpm e2e` 的 15 项 Playwright 测试全部通过；断言覆盖归档区归属、四列与等高对齐、顶部独立格式标签、同排统计、连续监控面、保留列线、右侧操作以及删除当前媒体重复文案。
- 全屏浅色截图人工检查通过：两张历史卡在归档区中保持相同高度，TXT／MD 标签完整可见；监控元信息、进度和输入／输出之间仍有列线，右上角状态与终止操作对齐。
- Tauri Release `--no-bundle` 构建通过；实际启动 Release EXE 后窗口标题为 `WhisperSubtitle`、窗口响应正常，并观察到受控 WebView 与 Python Worker 子进程。正常关闭退出码为 0，子进程无残留。

## 保留项

- 输出格式事实仍来自任务草稿或输出路径回退推导；本次只改变显示位置和视觉层级。
- 当前媒体的状态与序号仍保留在逐媒体列表中，主监控只删除重复摘要。
