# 重排历史格式与参数列

## 目标

- 将历史卡顶部的 TXT、MD、SRT 从标题行移入用户指定的第二列。
- 在第三列明确显示“默认参数”或“自定义参数”。

## 实际变更

- 历史事实区首行改为三列配置摘要：第一列转录模式、第二列文本格式、第三列参数配置。
- 文本格式继续使用既有强调色标签；双格式在宽卡中同排，在窄四列卡片中只在第二列内部换行，不越过列线。
- 参数状态不再出现在日期行；所有任务都在第三列明确显示“默认参数”或“自定义参数”。
- 配置摘要三列与下方媒体、耗时、媒体时长三列使用相同等分网格，竖向分隔保持同轴；模式和参数文字在大字号下仍完整显示。

## 验证

- React 组件测试覆盖文本格式位于第二列、默认／自定义参数位于第三列。
- Playwright 几何断言覆盖三列顺序、配置与统计列线同轴、格式标签不越界且互不重叠，以及模式和参数文字完整可见；完整 E2E 15 项通过。
- `corepack pnpm check` 通过：仓库卫生、70 页记忆体检、模型／Preset 投影、Prettier、ESLint、TypeScript 与 24 个测试文件共 97 项测试全部通过。
- `corepack pnpm desktop:build` 通过；生成的 Release EXE 启动后窗口可响应、标题正确，并持续观察到受控 WebView2 与 Python Worker 子进程。

## 保留项

- 状态图标、任务进度、输出格式、参数事实来源、配色和四列历史布局均保持不变。
- 本次不修改 Preset、Desktop IPC v1 或 Worker 行为。
