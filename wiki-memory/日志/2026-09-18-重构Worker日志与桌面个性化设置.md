# 重构 Worker 日志与桌面个性化设置

## 目标

- 全面整理 Worker 日志工作台，消除单一状态条和大块灰色空面板造成的割裂感。
- 重组偏好设置的信息层级，提供可视化的工作台宽度与左侧导航宽度调节。
- 把桌面框架字号、工作台内容字号和 Worker 日志字号拆成互不干扰的设置。

## 实际变更

- Worker 日志改为四张运行概览卡、带实时状态和成组操作的诊断控制台，以及说明日志采集阶段的正式空态；浅色和深色均使用一致的层级、图标容器和状态色。
- 偏好设置改为桌面外观预览、主题与强调色、工作区尺寸、字体与字号、本地运行环境和便携配置六个明确区块；全屏宽度下主题与布局并列，字体区单独占满一行。
- 外观状态新增 `workspaceFontSize`、`sidebarWidth` 和 `workspaceWidth`。默认导航宽度为 304px，工作台最大宽度为 1540px；宽度设置即时作用于实际应用框架并进入版本 1 便携配置。
- `uiFontSize` 只控制侧栏、顶栏和桌面框架；`workspaceFontSize` 只控制正式工作台中的卡片、说明、数据和操作项；`logFontSize` 只控制实时诊断代码行。
- 旧配置没有新字段时会继承旧 UI 字号作为初始工作台内容字号，古早 `contentFontSize` 继续迁移到新的内容字号；新增宽度字段采用当前默认值。
- 工作台宽度滑杆使用 20px 步长，确保 1540px 默认值不会被浏览器吸附成相邻刻度。

## 验证

- `corepack pnpm check`：仓库卫生、记忆、生成目录、格式、ESLint、TypeScript 和 91 项 Vitest 全部通过。
- `corepack pnpm e2e`：14 项 Playwright 全部通过；新增 1728px 全屏布局、三组字号隔离、两项宽度设置及 Worker 日志浅色/深色验收。
- `corepack pnpm desktop:build`：Web 生产构建与 Tauri Release 构建通过。
- Release EXE 启动烟测：主窗口响应、受控 Python Worker 持续运行，关闭主窗口后 Desktop 与 Worker 均无残留进程。

## 保留项

- 不改变 Desktop IPC v1、Worker 日志来源、任务、模型或输出行为。
- 侧栏收起状态仍使用原有独立本机偏好；新增导航宽度只控制展开状态。
