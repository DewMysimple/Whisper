# 重构任务监控与历史记录

## 目标

- 重新设计“任务监控与记录”工作台的信息层级。
- 将历史记录从横向行列表改为独立卡片归档，保留明确的进度信息但移除历史卡片进度条。
- 重做历史检索、日期、状态筛选和记录维护区域。
- 优化实时任务监控的主状态区域。

## 变更

- 历史记录使用全屏四列卡片网格，并按 3／2／1 列适配中小窗口；卡片高度由内容决定，不再拉伸成横向长行。
- 每张历史卡片按状态、标题、日期、进度、当前阶段、媒体与耗时、总时长、模型、Preset 和操作分层；进度百分比移动到卡片右上角，卡内不再绘制进度条。
- “自定义”标记移动到日期副行，避免与长文件名争夺标题宽度；完整任务名仍可通过标题悬停查看。
- 历史控制区拆分为“查找与筛选”和“记录维护”两层，搜索、日期、状态筛选及两阶段清理确认的功能语义保持不变。
- 实时监控主卡改为“整体进度、当前媒体”两张主信息卡和“输入来源、输出结果”两张摘要卡；终止任务、打开输出目录及逐媒体监控行为保持不变。

## 验证

- `corepack pnpm check` 通过：格式、ESLint、TypeScript、仓库卫生、模型/Preset 生成检查及 22 个测试文件中的 87 项 Vitest 测试均通过。
- Playwright 13 个桌面工作区场景通过；明确检查全屏四列、1000px 窗口三列、历史卡片无进度条、18px 圆角卡片以及实时监控两张主进度卡。
- Web 生产构建通过，仅保留既有的大于 500 kB chunk 提示。
- Tauri Release `--no-bundle` 构建通过；启动生成的桌面 EXE 后，主窗口和受控 Python Worker 均成功就绪，随后已清理烟测进程。
