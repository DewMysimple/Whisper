# 重构历史状态筛选与阶段信息

## 目标

- 让历史页顶部四张概览卡承担状态筛选，不再保留下方重复状态栏。
- 将历史清理操作并入搜索工具行，缩短名称并保持原有安全确认。
- 精简历史卡片进度与版本信息，使当前阶段同时表达转录版本、执行阶段和输出格式。

## 实际变更

- “全部任务”“正在运行”“已完成”“需要处理”改为带选中态的按钮；四种视图分别匹配全部、排队或运行、输出可用的已完成、失败任务。“需要处理”不再混入取消或输出缺失记录。
- 删除历史面板内重复的五段状态筛选与其遗留样式。搜索、日期、“清除历史”和“清除异常”改为同一自适应工具行；两项清理仍需在四秒内再次点击，且不删除输出文件。
- 历史卡片右上角移除“进度”字样，只显示与状态徽标垂直对齐的百分比；“当前阶段”统一显示“转录版本 · 执行阶段 · 输出格式”，终态使用“已完成”“执行失败”“已取消”等稳定文案。
- 历史卡片、任务详情和载入原配置对话框不再展示已经退出产品界面的“稳定主语言”等识别策略文案；Desktop IPC v1 和旧任务解析所需兼容字段保持不变。

## 验证

- React 组件测试覆盖概览筛选、失败任务隔离、双击清理、阶段组合文案和无进度条展示。
- Playwright 覆盖顶部筛选交互、同排工具栏、状态与百分比对齐、四列响应式历史卡片和实际截图。
- 通用工程检查、Web 构建、完整浏览器回归、Tauri Release 构建与桌面 Worker 启动烟测均通过。

## 保留项

- “清除历史”继续只清理输出可用的已完成本机记录；失败、取消和输出缺失记录由“清除异常”处理。
- 识别策略字段仍属于冻结协议和旧历史兼容数据，不重新作为 UI 配置或版本特性展示。
