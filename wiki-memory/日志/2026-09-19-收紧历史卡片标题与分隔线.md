# 收紧历史卡片标题与分隔线

## 目标

- 补齐历史事实区配置行未接到上下横线的列线。
- 将 TXT、MD、SRT 从强调标签改为普通文字。
- 把任务名称和日期移到状态图标右侧，并保证长名称不会挤动右侧进度。
- 删除历史管理卡中冗余的“查找与筛选”说明、图标和两组结果计数。

## 实际变更

- 移除配置行外层的上下留白，让两条内部列线完整连接相邻横线；配置行与统计行继续使用同一三等分网格。
- 文本格式保留在第二列，但取消背景、边框、圆角和强调色，字号、字重与相邻配置值一致。
- 卡片标题固定为状态图标、名称信息、进度三列；名称主体可压缩并显示省略号，扩展名保持可见，完整名称继续通过 `title` 提供。
- 历史管理卡只保留标题、搜索、日期和清理操作；删除说明性图标、标题、副说明、“显示 N / N”和“N 条结果”。

## 验证

- `TaskList` 与 `App` 定向组件测试共 19 项通过。
- Playwright 几何断言覆盖列线连接整行、格式普通文字样式、标题信息位于图标右侧、名称列不侵占进度列、扩展名可见以及冗余文案缺失；完整 E2E 15 项通过。
- `corepack pnpm check` 通过：仓库卫生、71 页记忆体检、模型／Preset 投影、Prettier、ESLint、TypeScript 与 24 个测试文件共 98 项测试全部通过。
- `corepack pnpm desktop:build` 通过；Release EXE 启动后窗口持续响应、标题为 `WhisperSubtitle`，并观察到由桌面 Host 直接监管的 `python -m whisper_subtitle worker` 和 WebView2 子进程。烟测结束后已清理本轮进程。

## 保留项

- 搜索、日期筛选、状态筛选、历史清理和任务操作语义保持不变。
- 原有主题与强调色、状态图标、四列全屏布局、Preset、Desktop IPC v1 和 Worker 行为均未修改。
