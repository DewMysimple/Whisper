# 新清单开发态交互与布局整改

## 授权与范围

用户授权结合《新清单》及六张 Obsidian 附图实施整改，并明确本次以开发服务器为目标，暂不构建新应用。已逐一读取清单和六张引用图；启动时工作树干净。本次修改 React、前端状态与浏览器验证，不改变 Desktop IPC v1、Python Worker、模型、Preset、转录参数或文件生成规则。

## 实际修改

- 执行前输出清单以间隔点分隔格式；同名策略压缩为“覆盖／跳过／重命名”，原确认语义保留。
- 监控／历史入口融入当前管理面板顶部，与四个筛选卡共用连续分段样式。
- 媒体卡隐藏路径但可用鼠标、Enter 或 Space 定位源媒体；成功后依据实际关联优先定位 TXT、MD，只有 SRT 时定位 SRT。失败、跳过和旧批量记录无关联输出时定位源文件，避免猜测改名或同名批量输出。
- 处理链路图标与标题对齐；完成项移除冗余文字。
- 历史卡使用内缩圆角闭合的六格事实区；模型与操作按钮同排；标题去除扩展名前展示空白，百分比和细轨道移至标题下方。
- 详情抽屉增加可读宽度与两列概要，结果／预览前置，参数／诊断留在后方；长内容换行，底部操作随滚动可见，输出预览适配主题。
- Worker 四张状态卡可定位对应最近日志，无选中态，不改变原始日志；沿用自动跟随暂停规则。
- 设置页预览按钮跳转转录工作台，移除阻断鼠标点击的旧 CSS；顶栏可收起／展开，折叠偏好持久化且保留展开高度。
- 共用 `CardButton`、`SegmentedCard` 和 `useTimedConfirmation`，集中交互反馈、分段选择外观与原位二次确认取消规则。
- 修复代码与旧记忆不一致处：`revealTaskOutput`、`selectTask` 原本仍只读任务级输出，现真正共用 `taskOutputPaths`，兼容仅逐媒体记录输出的历史。
- 测试预览端口支持 `WHISPER_E2E_PORT`，避免占用其他已运行的预览服务。

## 验证

- `corepack pnpm check` 通过：仓库卫生、记忆、模型／Preset 投影、CSS 归属与级联、Prettier、ESLint、TypeScript 和 134 项前端单元测试全部通过。
- `corepack pnpm e2e` 通过 20 项浏览器端到端测试。由于默认 4173 已有本地预览服务，测试使用 `WHISPER_E2E_PORT=14174` 的独立预览，保留已有服务。此命令仅构建测试用 Web 静态资源，不构建桌面应用。
- 已在固定 1420 Vite/HMR 服务上实际查看历史、详情、监控和日志页；浏览器验证覆盖浅／深主题、4／3／2／1 列布局、日历命中、公共卡片交互、顶栏收纳／恢复高度和设置预览按钮真实点击。
- 增加源媒体／成功输出／SRT 回退／旧批量无关联／资源管理器定位失败、仅逐媒体输出预览与定位、日志卡键盘激活及无选中态、折叠偏好保存／迁移等回归。已有历史二次确认、自动跟随、输出审计和预览竞态测试继续通过。
- `memory_lint.py index`、`memory_lint.py check` 通过；`git diff --check` 通过。

## 交付边界

本次不构建 Tauri Release、不打包 EXE、不替换便携版，不把浏览器 Mock 定位测试当作 Windows 资源管理器实机验收。开发 Vite 入口仍固定为 `127.0.0.1:1420`，原生定位继续由现有 Tauri Host 执行。
