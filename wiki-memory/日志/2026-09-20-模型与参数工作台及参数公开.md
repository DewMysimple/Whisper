# 模型与参数工作台及参数公开

## 授权与范围

用户要求移除媒体进度成功项的“已完成”、历史创建时间前的时钟图标，新增包含模型切换与参数调节的工作台，在文本识别模式下方增加同路径区域风格的跳转入口，并尽量公开底层可配置参数。沿用开发服务器迭代、不构建新应用的要求；起始工作树干净。

## 实现

- 主导航与 `ConfigurationView` 提供模型切换／参数调节；本地检查来自 DesktopBridge，缺失模型禁用，真实模型在下一任务启动加载。原有任务模型／硬件冻结、输出确认和 Worker 串行调度保留。
- `WorkspaceEntryCard` 统一路径读取与参数入口；旧路径专属 27 个选择器项移除，共享外观和卡片交互由独立 CSS 维护，避免再复制页面样式。新工作台和公共入口纳入重复样式门禁。
- 36 项推理控制分为语言与任务、解码与采样、上下文与提示词、语音检测与分段、时间戳与标点。支持范围校验、可空开关、温度序列、逐项／当前组合复位。六项 SRT 排版参数继续使用已有入口。
- `domain/parameters.py` 统一公开字段；代码生成更新 TS 类型、规则、实际默认投影和 IPC 参数定义。Python domain／protocol 共用归一化，Host 从 schema 校验。没有修改四个 canonical preset 的参数与后处理。
- 参数覆盖扩展为所有注册模型与四 preset 的二维保存，翻译仍受模型能力和英文模式限制。旧完整快照只用于有效性检查，当前值由默认与显式 overrides 重建，避免旧固定温度 0 掩盖真实回退序列。提示词在保存时规范换行与首尾空白；SRT 快照记录实际词级对齐。
- 开发浏览器原先不持久化；新增独立 preview 存储 key，通过刷新保存模型和参数，避免演示状态污染同一开发 URL 下的真实桌面。正式桌面原 key 保持不变。
- 媒体成功项去掉冗余状态文字，保留百分比、勾和计时；历史创建时间去掉前置时钟，时间值和任务状态功能保留。

## 验证

- `corepack pnpm check` 通过（34 个文件、140 项 Web 单测）；Python pytest 378 项通过；Rust test 35 项通过、2 项预先标注的环境烟测忽略，fmt／clippy 通过。样式检查器新增配置归属回归，9 项通过。
- `WHISPER_E2E_PORT=14176 corepack pnpm e2e` 全量 30 项通过；最后的提示词规范化与预览／桌面存储隔离由定向配置 E2E 复核。
- 浏览器覆盖路径风格入口、模型不可用与切换、参数编辑及非法值、模型隔离、刷新保留、任务快照、浅深主题和 760／1080／1728px 宽度。开发截图人工检查入口、模型卡、参数页，36 项字段完整且面板无水平溢出。
- 首轮 E2E 暴露预览不保存配置，修复隔离存储后通过；旧模型隐藏／强制 Turbo 迁移的断言按新授权更新。生成器增加 UTF-8 子进程编码，并对无序集合排序，避免中文标点编码错误和生成文件不稳定。
- 原 GPU benchmark 硬编码旧 `Text` 子目录，实际 custom 输出直接位于指定根目录；改为使用 Worker 的 authoritative outputs，并检查 success／failure count。中文 cn／cn2 默认真实 CUDA 输出与既有 golden 一致，单 Worker 只加载模型一次，正常退出。
- 36 项自定义控制通过协议、冻结、派生与引擎适配器单测；本地 Large V3 Turbo 分别以 cn／cn2／en_v1／en_v2 执行真实 CUDA 任务，用全部 36 项覆盖生成非空 TXT、Markdown、有效时间戳 SRT，queued 事件保留指定温度、VAD 和显式关闭阈值。全部四项 success_count 为 1、failure_count 为 0。
- 仅本地 Turbo 有真实模型可供验证；其他注册模型的选择、隔离与不可用行为由 bridge／状态测试验证，没有下载模型。没有构建 Tauri Release／替换便携版；Web E2E 静态资源和 Rust 测试二进制不构成新发布应用。
