# 硬件优化与工作台统一及便携版更新

## 授权与范围

用户要求新增关于 GPU／CPU 设置的“硬件优化”工作台，让模型／参数页面参照“任务监控与记录”和“性能监控”调整，并确保每张模型切换卡片等高等宽。最初沿用开发服务器范围，随后用户明确要求构建并更新 `dist`，因此本轮包含配套正式便携版构建。起始工作树干净；不下载模型、不删除虚拟环境或用户输出。

## 实现

- 新导航与 `HardwareView` 提供四种快捷方案、设备／GPU 编号／精度／CPU 线程控制、能力刷新、当前驻留配置、恢复默认和性能监控入口。
- 新 `executionOptions` 独立持久化，旧硬件字段继续丢弃。设置进入任务 draft 的 `execution`，提交与重试使用冻结快照；正在运行和已排队任务不受后续编辑影响。
- IPC v1 增加可选 ExecutionSettings，Web／Host 复用 schema 校验，Python 使用 domain 归一化。既有 system.environment 增加实际设备能力；失败时返回硬件错误说明，不损坏原环境结果。
- Worker 解析 CTranslate2 支持设备与精度；显式选择不支持时清楚失败。省略设置保留 CUDA float16／float32、CPU int8 和原线程默认。CPU 线程显式 0 与省略保持区别。
- 缓存继续以模型和实际 HardwareInfo 决定复用；真实构造器收到 device、device_index、compute_type、cpu_threads，任务保持串行。没有恢复旧硬件偏好命令或调整操作系统设置。
- 模型／参数页改为连续分段导航与统一内容面板，参数分组复用性能页视觉层级；模型网格等宽等高，长模型路径在卡片内部换行。相关 CSS 保持独立归属。
- 更新便携版使用说明源 `tools/release/user_guide.zh-CN.md`，增加新工作台、保存生效时机及线程／精度说明。

- `corepack pnpm check` 全量通过，146 项 Web 单测；样式检查器扩展为 10 项，包含硬件页样式归属。浏览器完整 33 项通过，覆盖硬件保存／恢复／冻结、错误范围及浅深主题；模型卡六张等高等宽，并验证与任务／性能页实际样式一致。最终审查修复原生 Host 对象错误显示为 `[object Object]` 的问题，新增明确错误文案回归，并重打正式包。
- Python 全量 408 项通过。新增覆盖 execution 字段范围、schema 一致性、显式零线程、CPU／GPU 能力、不支持选择、输入冻结、队列冻结、构造器实参和模型复用。
- Rust 单测 38 项通过、2 项环境烟测默认忽略；fmt、clippy 通过。额外单独执行真实 Rust Host→源码 Worker 的 CUDA int8_float16／4 线程烟测，验证硬件能力、queued 四字段及 TXT／Markdown 输出，正常停止 Worker。
- 同一个源码 Worker 顺序执行 cn／cn2／en_v1／en_v2 自动 CUDA，cn／cn2 与现有 golden 完全一致；随后执行 CUDA int8_float16／4 线程及 CPU int8／2 线程，两项都生成非空 TXT、Markdown 和有效时间戳 SRT。六项均 success_count=1、failure_count=0；四项自动任务复用一次加载，切换两种显式配置后总计三次加载。
- 模型与 preset 代码生成检查通过。真实模型只使用已有 Large V3 Turbo，未下载其他模型。
