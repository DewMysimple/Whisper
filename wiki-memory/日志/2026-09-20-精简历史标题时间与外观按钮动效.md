# 精简历史标题时间与外观按钮动效

## 授权与范围

用户提供两张截图，要求移除历史卡底部“模型”文字、改善标题与时间排版，并为桌面外观预览中的“开始本地转录”加入悬停和点击动画。延续仅在开发服务器迭代、不构建新应用的约束。启动时工作树干净；本轮只改变前端展示与交互反馈，不改变任务业务、输出、Preset、IPC 或 Worker。

## 实现

- 历史卡底栏只显示模型名称，删除冗余标签与相关宽窄样式。模型值、动作布局与业务回调保持原有来源。
- 标题以正文字阶与状态图标在首行居中对齐，文件名主体及扩展名统一继承标题字号，保留长名截断和后缀可见规则。时间不再挤在标题下的小区域，而是配时钟图标独占下一行，左边缘与卡片内容对齐，保留完整本地日期与时分以及原生 time 语义。
- 外观预览入口原来使用无状态样式的独立按钮，现复用公共 Button，增加播放与方向图标、渐变和柔和阴影。Button 新增可选 motion：悬停时表面渐亮、内部内容轻抬，按下时内部内容轻压并在释放后恢复；原生按钮本身的位置和尺寸固定。系统减弱动画时禁用内容位移与过渡，保留静态颜色／阴影反馈。动作仍然返回转录工作台。
- 动效集中在 button.css，并纳入既有共享样式归属门禁；设置页只负责尺寸。更新公共组件和任务组件维护说明。

## 验证

- `corepack pnpm check` 通过：工程卫生、模型与 Preset 投影、样式、格式、ESLint、TypeScript，以及 33 个文件的 134 项单元测试通过；样式检查器 7 项测试通过。
- `WHISPER_E2E_PORT=14174 corepack pnpm e2e` 最终 26 项通过。新增外观预览的浅／深主题、正常／减弱动画、真实动画帧变化、边缘悬停命中区域、鼠标点击返回工作台、Tab 焦点与 Space 激活验证；扩展历史卡在 620–1920px 窗口与 12／18px 内容字号下的标题字号层级、图标对齐、时间独立行和文件后缀可见验证。
- 首轮新增键盘测试使用鼠标操作后的程序 focus，未进入浏览器 focus-visible 模态；改为实际 Tab 导航后全量通过，未为测试修改产品焦点行为。
- 开发服务器真实浏览器采样确认按钮外框在空闲、悬停与按下均保持一致，内部内容存在连续动画。人工检查浅深主题、1920／1180／620px 历史截图及默认／窄窗口大字号外观预览；底部无“模型”标签，标题和时间层级清晰，按钮内容无内部溢出。

- E2E 只构建 Web 静态测试资源，未构建 Tauri Release／新 EXE，未替换便携版；证据属于开发态浏览器验证。
