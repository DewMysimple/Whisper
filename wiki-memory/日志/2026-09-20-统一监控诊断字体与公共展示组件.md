# 统一监控诊断字体与公共展示组件

## 授权与范围

用户指出监控来源／输出和 Worker 日志正文的字体有锯齿感、与周边不协调，并要求继续深入提升可维护性和公共组件复用。沿用仅针对开发服务器、不构建新应用的要求。开始时工作树干净；改造针对这些真实展示责任与重复样式，不改变 IPC、Preset、输出、Worker 或任务执行逻辑。

## 问题证据与实现

- 开发浏览器测得监控来源为界面字体，输出却是等宽字体，均为 13px／700；来源容器还错误引用日志字号。日志正文设置为 13px 时实际被后代选择器缩为 11px，行高只有 15.95px，继承的 `user-select: none` 阻止选择正文。原等宽链缺少明确中文回退。
- 新增纯展示 `SummaryText`，为监控来源／输出与四项 Worker 状态复用标签、值和可选说明。摘要统一界面字体、600 字重、至少 14px 的正文层级和 1.5 行高，允许长值换行。图标、容器、回调与数据格式化继续在页面，组件不读 store、不调用 bridge。
- `.diagnostic-text` 统一真实日志与外观预览：按独立日志字号显示界面字体，1.65 行高，保留换行、缩进及文本选取。日志时间和来源继续使用等宽字体，等宽链补充界面字体回退。设置说明同步明确界面文字与等宽标识的职责。
- 将全部 Worker 日志布局、主题、空状态、响应式规则归入 `worker-logs.css`。从全局移除 150 处旧诊断选择器，删掉失效 div 状态卡规则、旧 `.log-view`、多层主题覆盖和 `!important`。正文列统一起点，长路径在列内换行，窄窗口正文独立一行。共享文字不再受全局 small 强制字号覆盖。
- 监控清除、终止、打开目录接入既有 Button；删除重复颜色、焦点、按下缩放和禁用样式，页面只保留尺寸。终止确认、清除输入和打开目录的业务来源不变。
- 样式门禁覆盖日志和两类公共文字，检查归属、同条件重复选择器／属性、祖先依赖和 `!important`；同步组件维护入口。

- `WHISPER_E2E_PORT=14175 corepack pnpm e2e` 最终 28 项通过。新增浅深主题、620／760／1080／1728px 窗口与 12／14／18px 工作台字号、10／13／16px 日志字号的组合验证；检查正文对齐、可选取、保留空白、长日志不撑破列以及修改原责任规则能直接生效。现有任务流程、按钮、历史、详情和外观测试继续通过。
- 首轮 E2E 27 项通过、1 项揭示共享摘要继承根节点已计算字阶而无法放大；改为组件按当前工作台字号计算后，全量 28 项通过。
- 开发页面计算样式确认默认摘要为 14px／600／21px 行高，正文为 13px／400／21.45px 行高；浏览器平台字体报告确认中英文正文都使用 Microsoft YaHei UI。人工查看浅深主题、窄窗口大字号、长日志和空状态截图。

- 全局 CSS 按选择器／条件／属性审查，非诊断区域的有效声明保持原有事实；必要差异仅为等宽中文回退、外观日志预览复用和公共文字退出旧 small 强制覆盖。
- E2E 仅生成 Web 测试静态资源；没有构建 Tauri Release／新 EXE，也没有替换便携版。开发服务器 HTTP 200，最终记忆、工程卫生和 diff 检查通过。
