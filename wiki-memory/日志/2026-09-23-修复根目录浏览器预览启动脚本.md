# 修复根目录浏览器预览启动脚本

## 目标与范围

用户反馈根目录 `runStart.cmd` 报错，并确认希望它打开浏览器界面预览。原脚本为未跟踪文件，路径写成 `~%dp0`，且从仓库根目录把 Vite 的 `--open` 参数传给 Tauri 开发命令。

## 变更

- 修正脚本目录切换，改为从 Web 工作区启动 Vite 并自动打开浏览器；启动失败时保留窗口与退出码。
- 在根 README 和开发验证知识页记录该入口、模拟桥接边界及真实桌面入口所需的 Cargo 工具链。

## 验证

- 原脚本复现“找不到指定路径”和 Tauri 不支持 `--open` 两个错误。
- 修正后从仓库根目录及 `C:\` 调用均成功启动 Vite，页面在 `127.0.0.1:1420` 返回 HTTP 200，标题为 Whisper Subtitle；验证后已停止测试进程。
- 仓库卫生、记忆、模型与 preset 生成目录、样式归属、lint、TypeScript 类型检查和 Web 单测 147 项通过。
- `corepack pnpm check` 停在 Prettier：其报告 140 个本次未改动的前端文件格式问题，未批量改写范围外文件。
- 本机未安装 Cargo，真实 Tauri 桌面开发入口未进行启动验收。
