# 偏好设置整体界面大小预设

## 目标与范围

用户要求在“偏好设置”的“字体与字号”下增加偏小、平衡、偏大三张整体大小预设卡；当前默认对应平衡。卡片与“主题与强调色”的三张卡风格相似，并复用同一公共卡片模块。本次继续针对开发态，不重建完整便携版；开始时 Git 工作树干净。

## 实现

- `PreferenceChoiceCard` 为两组选择提供同一原生 radio、主题表面、选中态和键盘焦点。主题卡迁入该公共模块，原有主题预览与选择语义保留；大小卡提供三档字号比例预览，平衡卡标记默认。
- 偏小、平衡、偏大分别一次设置框架／工作台／Worker 日志字号为 12／12／11、14／14／13、16／16／15 px。默认外观直接引用平衡预设，避免两份默认数值漂移。
- 预设不增加独立持久化字段；仍保存三组既有字号。卡片选中状态由实际数值推导，手动微调后无卡片选中，再点预设可恢复对应组合。
- 将公共选择卡样式加入样式归属门禁，避免以后把基础规则散落回全局或业务页面。

## 验证

- `corepack pnpm check` 全部通过，Web 单测 148 项；新测试覆盖三档同步、微调退出预设及公共卡片复用。
- `corepack pnpm e2e` 浏览器 34 项通过；新增测试覆盖选择、刷新持久化、实际 CSS 变量和浅／深主题截图。截图人工核对卡片视觉。
- Web 构建仅用于浏览器验收；未重建正式 `dist` 或完整应用。
