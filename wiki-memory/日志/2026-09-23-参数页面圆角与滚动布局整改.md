# 参数页面圆角与滚动布局整改

## 目标与诊断

用户截图指出模型与参数页多余的说明／返回条、参数分组卡片底角露出直角，以及模型／参数页因滚动条出现与消失而左右偏移。开始时 Git 工作树干净。共享 `SegmentedCard`、`CardButton` 本身没有造成这些现象：配置页专属 CSS 为下拉菜单长期设置整卡 `overflow: visible`，让内层矩形网格盖住圆角；根滚动容器未预留滚动条宽度。其他工作台没有采用同一组冲突规则。

## 改动

- 移除配置页额外的说明／返回条；转录工作台仍可通过主导航进入。
- 配置卡平时裁切内层矩形网格，仅在公共 `RoundedSelect` 打开期间允许弹层跨卡片显示；分组末行按 3／2／1 列保留底部圆角，顶部参数工具栏也保留底角。
- 根滚动容器预留稳定滚动条槽，避免长短页面切换改变工作台的水平位置。
- 浏览器回归检查冗余条消失、长短页左边缘一致、闭合圆角、末行菜单可见且可点击；组件维护说明记录新增分组时需核对的布局约束。

## 验证与范围

- `corepack pnpm check` 通过，Web 单测 149 项；完整浏览器 E2E 36 项通过。随后对末行菜单补充命中测试，配置页 E2E 5 项通过，并目视检查参数页常态及展开菜单截图。
- 固定 `127.0.0.1:1420` 开发服务器返回 HTTP 200。Web 构建只用于浏览器测试；没有重建桌面 EXE、冻结 Worker 或正式 `dist`。
