# 整体界面预设补齐宽度与布局

## 目标与范围

用户根据截图要求将整体大小预设移到“字体与字号”设置块下方，在横向占满面板，不在右侧留空；预设除字号外还必须调整“工作台内容宽度”。本轮继续只修改开发态源码，不重建正式便携版。开始时 Git 工作树干净。

## 实现

- “整体界面大小”成为字体设置下方的独立全宽面板，三张公共选择卡均分可用宽度，移除原 900px 上限。
- 偏小、平衡、偏大仍分别设置框架／工作台／Worker 日志字号 12／12／11、14／14／13、16／16／15 px，并同步设置工作台内容宽度 1360、1540、1720 px。平衡仍是默认值。
- 卡片直接展示字号与宽度组合。预设仍不新增长期存储字段；按四个实际字段推导选中状态。单独调整工作台宽度或任一字号即退出预设选中，再点卡片可一次恢复整组数值。
- 主题选择继续复用同一 `PreferenceChoiceCard` 表面与交互；可选说明仅用于大小预设。

## 验证

- `corepack pnpm check` 全部通过，包含仓库卫生、记忆体检、样式归属、格式、lint、类型检查及 Web 单测 148 项。单测覆盖四项同步设置、默认值和手动改宽度退出预设。
- `corepack pnpm e2e` 34 项全部通过。浏览器测试覆盖面板位于字体块下方、卡片横向铺满、CSS 变量与实际工作区宽度变化、刷新持久化、手动微调和窄窗口响应；浅／深色截图人工核对。
- 浏览器测试所需 Web 静态构建不等于桌面正式打包；正式 `dist` 未重建。
