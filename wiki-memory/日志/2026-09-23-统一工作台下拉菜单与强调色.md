# 统一工作台下拉菜单与强调色

## 目标与范围

用户指出“模型与参数”和“硬件优化”仍使用系统原生下拉菜单，和“偏好设置”的字体菜单不一致；两页整体偏灰，要求向其他工作台的强调色风格靠拢。本次只针对开发态 UI，不重建正式 `dist`。开始时 Git 工作树干净。

## 实现

- 将字体菜单移到公共 `RoundedSelect` 及独立样式文件。偏好设置、preset、可空参数模式、任务类型、设备、GPU、精度及 CPU 线程策略共用同一组件；保留原业务值、禁用项与保存动作。
- 菜单统一使用主题变量，并支持键盘方向键、Home／End、Enter、Escape、失焦及外部点击。参数和硬件卡片允许菜单跨边界展开，打开时提高所在卡片层级。
- 模型与参数页增加分组强调色标签、参数数量徽标、选中模型强调色和自定义参数边线；硬件页突出下一任务设备、分组顶线／图标、聚焦字段和性能建议。所有颜色跟随现有主题／调色板变量。
- 扩展样式归属门禁，避免公共菜单基础样式回流到页面或全局 CSS。

## 验证

- `corepack pnpm check` 全部通过，包含仓库／记忆／目录生成／样式／格式／Lint／类型门禁和 Web 单测 147 项；公共菜单测试覆盖键盘、禁用项和关闭行为。
- 浏览器完整 33 项通过。模型参数与硬件配置的保存、恢复、任务冻结保持原行为；浅色／深色及宽窄窗口下菜单选项可见且可点击，截图人工核对通过。
- `corepack pnpm build` 仅生成 Web 开发验收所需的静态预览；固定 1420 Vite 开发服务器已启动，页面和公共组件模块 HTTP 均返回 200。正式 `dist` 保留 2026-09-20 版本。
