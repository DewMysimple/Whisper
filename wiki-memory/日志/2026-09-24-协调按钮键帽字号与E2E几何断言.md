# 协调按钮键帽字号与 E2E 几何断言

## 目标与发现

## 修改

- 将几何检查改为验证快捷键为主按钮标签字号的 0.84 倍。
- 保留快捷键无图标及按钮位置、执行提示布局的既有检查。

## 验证

- 修订后完整浏览器回归 38 项全部通过。
- `corepack pnpm check` 通过，包含仓库／记忆／目录生成／样式、格式、lint、类型及 Web 155 项测试。

## 边界
