# 固定文件格式提示占位避免跳动

## 用户要求与原因

用户指出文件格式提示的显隐导致竖直方向 UI 跳动，要求稳定排版。此前提示采用条件渲染，取消最后一个格式后插入文字行，同时改变选项上间距；重新勾选时整行移除，格式选项及下方分区随之上移。

## 修改

- 提示保持在格式标题下方、格式选项上方，始终参与布局；选中任意当前模式格式后仅隐藏文字，并从可访问性树隐藏。
- 使用原字号和自然行高保留占位，选项上间距统一为 10px；浅／深色、字号适配和现有输出规则继续沿用。
- 扩展现有输出布局浏览器回归，比较取消／重新勾选前后面板高度、所有设置分区及格式列表的相对位置与高度，覆盖文本／字幕模式、浅／深色、默认与 18px 字号。

## 验证与边界

- 开发预览浅／深色截图检查通过；1920px 窗口下格式列表、同名文件与完成动作位置在提示显隐前后一致，位移为 0px。
- `corepack pnpm check` 通过，含仓库／记忆／目录生成／样式／格式／lint／类型检查及 Web 155 项测试；Web 生产构建通过。
- 完整浏览器测试中 36 项直接通过；新增的 2 项几何断言首次因小于 0.0001px 的浏览器浮点误差失败，将坐标按 0.01 CSS px 记录后，浅／深色 2 项复验通过。应用无需追加修正。
- 本轮延续 `127.0.0.1:1421` 开发预览，仅修复展示排版；没有更新桌面 Release 或完整 dist。
