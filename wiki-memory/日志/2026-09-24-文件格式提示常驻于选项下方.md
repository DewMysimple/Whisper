# 文件格式提示常驻于选项下方

## 用户要求

将“至少选择一种需要生成的文件格式。”常驻在“纯文本”格式选项下方，并把解释性文字排在这条提示之后。

## 修改

- 把格式要求从分区标题与选项之间移到格式选项网格之后，始终显示。
- 新增说明行，解释可多选以及转录文本／字幕模式各自支持的文件格式。
- 两行文字保持不同层级，沿用当前主题强调色和说明文字色；选项状态切换时不移除任何一行。
- 更新输出布局 E2E，核对文字顺序、常驻状态、浅／深色外观、窄宽度换行及格式勾选前后分区几何位置。

## 验证

- Web TypeScript／Vite 构建通过。
- 输出位置与格式布局浏览器检查浅色、深色各 1 项通过；首次运行使用了未重建的旧预览，重建后两项均通过。
- Web 预览截图确认说明位于选项下方、文字层级适配浅／深色主题。

## 边界

- 仅更新开发态 Web 排版，未重建 Tauri Release／EXE 或完整便携版。
