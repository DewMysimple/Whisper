# 文件输出三种保存策略与原位路径

## 目标与授权

用户要求在开发服务器整改转录工作台文件输出，提供“跟随／文件夹／自定义”，按所选格式写媒体目录或 Text／SRT 文件夹；自定义只打开资源管理器目录选择，将路径放在原说明位置。追加要求路径超过一行时省略显示。授权包含相应输出行为与 UI 外观适配，不包含重发完整便携版。

## 实际变更

- 新工作区默认跟随：所有启用格式直接写媒体目录。文件夹策略将 TXT／MD 合并到 Text，SRT 放到 SRT；目录按格式组合创建，每个媒体分别解析。
- 自定义点击即调用 typed bridge 的系统目录选择器，选后直接写该目录。路径在原说明行单行省略，保留完整底层值，不新增路径框、恢复按钮或媒体旁副本区域。取消／错误保留之前的选择，再次点击可重新选择。
- 三个策略按钮与同名冲突按钮共用网格、44px 高度、圆角和主题反馈；清单显示保存策略，配置快捷入口聚焦当前选中项。Mock 输出事件同步反映保存策略，浏览器仍使用 Mock 目录，真实系统选择器由桌面 Host 提供。
- 修复 1400px 以下工作台只有轨道切成单列、命名区域仍为两列的问题，消除长路径挤压来源卡；补充主题、长路径、省略、放大字号、键盘及区域不重叠检查。
- IPC v1 schema、Rust Host、Python validator 增加 `source`／`folders` mode；旧 `compatibility`、副本字段和 CLI 路径保持兼容，历史草稿不重写。旧当前配置迁移到 folders，并禁用额外副本。新模式需要配套 Host／Worker。
- 同步架构文档原有“自定义根目录还会建格式子目录”的过时描述，以实际直接写根目录的代码和本次验证为准。

## 验证

- 项目虚拟环境 `python -m pytest -q`：430 项通过。新矩阵覆盖三策略与六种格式组合、跨媒体目录、实际写盘、无多余文件夹、冲突、重命名与跳过。
- Rust `cargo fmt --check`、`cargo test --locked`、`cargo clippy --locked --all-targets -- -D warnings`：39 项通过，2 项原有环境相关测试忽略。
- 浏览器既有 36 项通过；新增浅／深色 2 项通过。单行高度断言最初因浏览器亚像素误差失败，调整为 0.05px 容差后定向复验通过，仍严格检查单行、省略及实际裁切。最后截图已目视核对。
- 真实短中文媒体通过常驻 Worker 在 CUDA 0／float16 下逐一执行三策略，每项生成 TXT、MD、SRT；9 个文件位置正确，无额外副本或格式目录，三份 TXT 均与现有 `cn_real_output.txt` golden 一致。首次验证脚本误将模型根目录设为外层 models，纠正为已有 huggingface 根目录后通过，未修改模型资料。
- Web 正式构建、Tauri Release 构建通过。最终 Release EXE 使用本任务隔离的验收目录与 WebView 配置启动，连接项目 Python Worker；真实窗口显示三种策略和“本地 Worker 就绪”，Worker 持续存活，窗口正常关闭回收进程。target 下既有冻结 sidecar 未用作新模式验证。
- Tauri 开发窗口连接 1420 HMR 服务；通过真实 Windows 目录对话框选择本任务验收目录，验证路径出现在文件输出原说明行；再次打开并取消后路径保持。开发 Worker 就绪和子进程持续运行已核对。
- 通用格式门禁发现 8 个原有文件换行格式不一致，Prettier 归一化后无语义／Git 内容差异，没有额外混入功能变更。
- `git diff --check`、仓库卫生及记忆索引／体检通过。

## 交付边界

本轮交付开发源码、1420 开发服务与桌面开发窗口；完整 `dist` 保留 2026-09-23 版本。Release EXE 与截图、真实媒体输出、原生对话框验证记录只作为本地验收资料，不纳入源码提交。旧冻结 Worker 不能接收新增的输出 mode；后续正式发版须配套重建。
