# 文件输出提示与转录操作区稳定化

## 用户要求

依据开发服务器的文件输出截图收口排版：移除被指出的灰色格式说明文字；合并并保留媒体进度和开始转录操作区，避免媒体状态切换推挤页面；文件输出分隔线延伸至面板完整内沿。

## 修改

- 格式选项下仅保留强调色格式要求提示，并继续固定在选项之后；删除冗余支持格式说明。
- 文件输出三个分区边线扩展至面板内侧边缘，文字和控件的内容内缩不变。
- 媒体进度入口和开始转录按钮统一在圆角操作卡片中。媒体为空时入口保留并禁用；加入或清空媒体不改变操作卡尺寸和位置。
- 将清单状态及清除动作与标题内容分离定位，维持原有紧凑标题间距和预检卡片对齐；缩短装饰标签以免窄列截断；转录／字幕模式下启动卡尺寸保持一致。
- 更新组件说明、单测和浏览器几何／可访问性断言，清理此前已失效的“清空时隐藏入口”和“额外灰色说明常驻”约定。

## 验证

- `corepack pnpm check`：通过；包含仓库卫生、记忆、样式归属、格式、lint、TypeScript 和 Web 155 项单测。
- `corepack pnpm e2e`：38 项通过，覆盖主题、交互、响应式布局、输出区与开始操作区。
- 装饰标签收短后，再跑启动卡几何／交互和文件输出浅深主题 5 项浏览器复测，全部通过。
- `python wiki-memory/工具/memory_lint.py index` 与 `check` 通过，共检查 99 个 Markdown 页面；`git diff --check` 通过。
- 开发预览 `127.0.0.1:1421` 返回 HTTP 200；浏览器核对单一常驻操作区、灰色说明已移除、三条分隔线左右各距面板内沿 1px。开发态变更不更新 Tauri Release、EXE 或完整便携版。

## 边界

- 仅调整 React 开发预览的交互与样式；保存策略、路径选择、转录执行和输出格式行为沿用现有逻辑。
