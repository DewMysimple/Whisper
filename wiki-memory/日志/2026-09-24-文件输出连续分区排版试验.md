# 文件输出连续分区排版试验

## 目标与范围

用户希望在开发服务器尝试文件输出的新排版，并追加要求把“至少选择一种需要生成的文件格式。”移到格式选项上方、适配当前 UI。此轮基于已完成的三种输出策略，在独立分支 `codex/output-panel-layout` 迭代 Web 外观。

## 实际变更

- 四张内卡片改为四个连续分区，以细分隔线组织；保存位置与文件格式在上，同名文件与完成动作改为横向设置行。
- 保存策略、冲突处理与完成动作使用连体按钮，格式选项以文档缩写、名称和勾选标记表示选择；保留原生 checkbox、按钮状态、焦点及减弱动画支持。
- 自定义路径继续在原说明行单行省略显示。没有选择文件格式时，强调色提示放在格式标题下、选项上方；选择任意格式后移除提示。
- 新增 `output-panel.css` 作为外观责任入口，删除旧全局输出样式及过时覆盖；将新样式纳入归属与重复规则门禁，补充组件维护说明。
- 本轮仅改变展示与交互反馈；跟随／文件夹／自定义、原生选目录与取消、格式组合、同名策略及完成动作继续调用既有 store 与 bridge。

## 验证

- 通用 `corepack pnpm check` 通过，包含仓库体检、记忆体检、生成目录核对、样式、格式、lint、类型及 Web 155 项测试。
- 完整浏览器 E2E 38 项通过，覆盖原有工作台交互；提示上移后补充运行输出布局浅／深色 2 项，验证提示位于标题和选项之间、选择后消失、三种策略及长路径省略。
- Web 生产构建通过。浅／深色截图目视检查，并检查 1440／1180 窗口及增大字号下的控件边界、长路径和键盘选择；默认 1440 窗口下格式名称可完整显示。
- 定向 E2E 首次被已占用的 4173 端口阻止启动，改用独立 4174 后通过，未干扰原预览进程。
- 独立工作树预览位于 `http://127.0.0.1:1421`，原 1420 服务继续保留。截图与运行日志在忽略的 `build/validation/output-layout/` 及 `apps/web/test-results/`。

## 交付边界

本轮是开发服务器排版试验，尚待用户选择最终外观；没有执行正式 UI 发布验收、Tauri Release／EXE 重建，也没有更新完整 dist。正式产物仍按 [[当前状态/当前约束]] 管理。
