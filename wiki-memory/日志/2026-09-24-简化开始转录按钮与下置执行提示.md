# 简化开始转录按钮与下置执行提示

## 用户要求

将执行前清单中的条件提示移到“开始转录”下方，并把按钮配色改得干净、简约。继续在当前独立工作树开发预览中整改。

## 变更

- 公共 Button 增加可选的主按钮 `surface="flat"`，开始转录使用纯强调色，无渐变、发光或凹凸投影；禁用时以不透明的中性表面和次要文字表示不可执行，保留原生 disabled。
- 保留播放图标，移除多余的右箭头，动作文字与 Ctrl + Enter 提示左右对齐；悬停／按下只改变纯色表面，保留键盘焦点及减弱动画支持。
- 执行条件提示移到按钮下方，预留两行随字号变化的空间，条件满足时清空文字并从可访问性树隐藏；按钮通过 aria-describedby 关联当前说明。
- 为清单状态徽标预留四个汉字的宽度，避免“待补充／可以执行”切换时挤压标题、改变换行并推动按钮。
- 在原样式责任规则修改提示和按钮布局，删除旧提示布局与不必要的优先级覆盖。执行条件判定、启动动作、快捷键、确认弹窗及 Worker 流程不变。

## 验证

- 开发预览浅／深色的禁用与就绪状态截图核对；1440／1180 窗口下按钮内容无横向溢出。
- 浏览器交互门禁改为验证纯色、无投影、稳定命中区与下置提示；包括浅／深色、普通／减弱动画、提示显隐前后布局及焦点。
- `corepack pnpm check` 通过，含 Web 155 项及仓库、记忆、生成目录、样式、格式、lint 和类型门禁；Web 生产构建通过。
- 全量浏览器 38 个场景首轮 36 项通过，2 项新启动布局断言暴露窄窗徽标变宽导致标题换行。修复后相关工作台／交互复验 20 项通过；其余 2 项将键盘焦点验证改为真实 Tab 导航后通过。
- 1440／1180 窗口、工作台 18px 字号及浅／深色下，按钮与说明无溢出，提示显隐前后按钮位置和卡片高度一致。最终 CSS 修改后样式门禁再次通过。
