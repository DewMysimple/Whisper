# 精致化开始本地转录按钮外观

## 用户要求

用户认为当前“开始本地转录”按钮的框体过于普通，要求继续调整外观，并明确要求先完成文件格式提示布局，再处理按钮。

## 修改

- 按用户指定顺序，先提交并推送格式提示布局，再开始修改本按钮。
- 保留纯色强调色按钮及原生尺寸；用轻描边和圆角加强外框层次。
- 播放图标增加小型半透明边框底框，`CTRL + ENTER` 改为轻质键帽样式。
- 保持按钮命中框固定、常态和悬停无渐变／阴影，禁用态继续使用中性灰。

## 验证

- Web TypeScript／Vite 构建通过。
- 开始按钮浏览器交互检查 2 项通过，覆盖减弱动画、浅／深色、焦点、按压命中区域和执行提示布局。
- 检查截图中的描边与键帽在浅／深色主题下均清晰，样式没有增高按钮或引入文字溢出。

## 边界

- 仅更新开发态 Web 外观；没有重建 Tauri Release／EXE 或完整便携版。
