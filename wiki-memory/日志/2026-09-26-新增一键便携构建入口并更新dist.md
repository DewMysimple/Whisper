# 新增一键便携构建入口并更新 dist

## 目标

提供可双击运行的构建入口，用当前本地源码更新完整便携版 `dist`。

## 变更

- 应用户要求，参考另一个工程的双击构建入口，在仓库根目录新增 `buildStart.cmd`。它从脚本目录调用既有 `tools/release/build.ps1`，传递可选参数，显示成功或失败以及退出码，并在关闭前等待按键。
- 默认构建当前本地源码的完整便携版、ZIP 与 SHA256；不拉取远程提交，也不生成可选安装器。发布说明补充双击用法。
- 本次直接运行该 CMD，更新了忽略版本控制的 `dist/WhisperSubtitle/`、`dist/WhisperSubtitle.zip` 和 `dist/WhisperSubtitle.sha256`。未修改 IPC、Preset、模型目录或识别输出规则。

## 验证

- `cmd.exe /d /c "echo.|buildStart.cmd"` 成功退出；正式 Web、冻结 Worker、Tauri Release 与便携版组装均完成。
- 传入无效参数时 CMD 保留 PowerShell 的非零退出码并显示失败信息，且未触发发布目录替换。
- manifest 包含 930 个受管文件；便携目录与 ZIP 各有 931 个文件，路径和大小一致。ZIP 全量 CRC 与外层 SHA256 均通过。ZIP SHA256 为 `43e481f3337e292459603901d774d97143705742b259415a93493a67d6e4f753`。
- 冻结 Worker 的 `worker.ready → system.health → worker.shutdown` 通过，退出码为 0，stderr 为空；从正式便携 EXE 启动时，配套 `_internal/worker` 子进程持续运行 12 秒，关闭后回收。
- `python -m pytest -q tests/test_packaging.py`：8 项通过；Web lint、类型检查及 155 项单测通过。通用 `corepack pnpm check` 的首次格式检查因 Windows 工作树换行符失败；运行 Prettier 后 7 个文件的 Git 内容哈希均未变化，未纳入提交，复查通过。
