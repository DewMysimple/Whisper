# 开发环境深度瘦身与交付收尾

## 目标与授权

用户要求解释工程 92,284,383,842 字节（85.95 GiB）的来源并深度瘦身，清除旧包，确保每次完整对话及时更新并收尾。后续明确选择只保留最新可运行目录，ZIP 按需生成。该授权已写入根 `AGENTS.md`，不再对同范围的日常收尾重复询问。

## 起始证据

文件扫描跳过符号链接和目录联接，127,001 个文件的总字节与用户报告完全一致：

| 目录 | 字节 | 主要来源 |
| --- | ---: | --- |
| dist | 33,688,739,478 | 当前目录、13 GiB ZIP、旧版目录和 ZIP |
| build | 26,777,348,656 | 发布环境、PyInstaller、重复模型和 Worker stage、旧验收资料 |
| apps | 14,451,374,674 | Rust target 14,429,537,032 字节，含额外 Worker 副本 |
| models | 10,754,605,731 | 三份 Qwen 资产及 Turbo；Turbo cache 同时含独立 blobs 和 snapshot |
| whisper_env | 6,399,497,827 | CUDA Torch、CTranslate2 运行库、退役 GUI 及非依赖链包 |

Node 依赖约 188 MiB；Git、源码、文档和记忆均不是主要占用来源。原发布脚本还会把替换的大目录送入回收站；本次改为有边界的永久清理，不清空用户全局回收站。

## 实际修改

- 删除旧版目录／ZIP／SHA256、当前可再生 ZIP 和空验证发布目录。
- Turbo snapshot 五个文件与当前正式模型逐一比较 SHA256，相同后迁移到受支持的 `models/huggingface/large-v3-turbo`，移除重复 HF blobs；Qwen 权重保留。
- 按项目 dev／qwen 与开发工具的依赖闭包卸载 32 个孤立包，包括 PyQt5、torchvision、torchaudio、librosa、scipy、scikit-learn 和 numba；保留 GPU 推理与开发所需依赖，`pip check` 通过。此操作不成为自动卸载规则。
- 发布默认不生成 ZIP，提供 `release:archive` 和 `release:build:archive`；冻结 Worker 用移动进入 stage，减少一份副本；新目录全量校验后才替换旧版。成功后删除发布中间态和 Cargo 内额外运行库副本，`-KeepBuild` 仅供排障。
- 新增共享路径防护，清理拒绝越界、Git 已跟踪内容、联接及正在使用的目标。`workspace:finish` 校验当前正式版后清理白名单缓存和旧包；`workspace:size` 可复测体积。
- 根约定、当前状态、开发流程和发布文档同步新的保留规则；已封存旧日志保持只读。

- 精简开发环境的真实 GPU Worker 完成 Turbo cn → Qwen 1.7B cn／en → Qwen 0.6B 长音频 → Turbo cn2，TXT／MD／SRT 正常，旧 Turbo golden 一致，52 秒音频的三次重复和后段时间戳通过。
