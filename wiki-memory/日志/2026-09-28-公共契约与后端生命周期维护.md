# 公共契约与后端生命周期维护

## 目标与审查范围

按用户要求审查可读性、可执行性、冗余及公共模块。启动时工作树干净。
阅读 Python 编排、硬件探测、后端适配、缓存、公共契约，Web 任务状态／持久化／公共组件，Rust 模型发现与 Worker 就绪路径，以及发布／清理工具。

| 范围 | 证据与处理 |
| --- | --- |
| 公共硬件契约 | HardwareInfo 原定义在 CTranslate2 探测实现，Torch、Worker 和应用都反向依赖该实现文件；移入 domain/execution.py，生产调用方改用公共契约，原路径保留同一类型的兼容导出。 |
| 后端工厂 | 给硬件探测器补充 capabilities／resolve Protocol 与工厂返回类型；具体精度选择保持后端自身责任，不强行合并不同算法。 |
| Qwen 可读性与资源范围 | 原 _segments 混合生成、截断检查、语言解析、强制对齐与线程恢复；抽出单窗识别、对齐和线程上下文，局部张量随方法结束释放，时间偏移与输出规则保持。 |
| 模型缓存执行性 | Timer.cancel 无法阻止已经等待锁的回调；旧回调会清掉新计时器并可能提前释放重新使用的模型。加入代次失效判断，确定性测试覆盖缓存复用／模型替换。 |
| CUDA 初始化执行性 | 组合检查出现 WinError 127；独立进程复现先 load_torch 再 HardwareDetector 失败。load_torch 与共享解码入口先调用公共 CUDA 初始化后成功；真实验证增加 Qwen 首次加载顺序。 |
| Web 公共组件与状态 | 已有 Button、CardButton、RoundedSelect、任务状态纯函数和 typed bridge 边界。路径显示存在少量局部重复，但路径比较、持久化兼容和展示语义不同，本轮保留，避免把不同规则塞入笼统 utils。 |
| Rust／跨进程校验 | Host 与 Python 模型文件校验在不同进程边界，模型事实来自生成投影；保留两端校验，不跨语言调用 Python 代替 Host 本地边界。 |
| 发布与清理 | 已有 generated_paths.ps1 公共路径防护、manifest 校验及成功清理；本轮复用现有完整构建流程。 |
