# Qwen 1.7B 专用应用压缩包

## 目标与范围

用户要求提供仅含 Qwen3 的应用压缩包，并明确排除 Qwen3-ASR 0.6B。交付只保留 Qwen3-ASR 1.7B 与 SRT 所需的共享 ForcedAligner 0.6B；后者是时间戳依赖，不是被排除的 ASR 0.6B。

从同日已验收便携版派生，保留运行中的标准 `dist/WhisperSubtitle/`、开发模型和环境，不修改应用运行时、UI、默认模型、IPC、Preset 或输出规则。本轮只更新打包工具、对应测试和文档，因此复用已验运行时字节，没有重新编译 Host／Worker。

## 实施

- `release:archive -ModelId qwen3-asr-1.7b` 先全量验证标准版，再通过 `prepare_selected_portable.py` 复制独立 stage，只保留注册表解析出的指定模型及伴随模型。
- 派生 manifest 显式记录 `modelIds`，校验精确模型目录、配置、权重和伴随完整性；未声明该字段的旧 manifest 继续要求 Turbo。模型校验复用 canonical registry 与 `AppPaths`，不维护另一份模型清单。
- 新 stage 位于 `build/release-selected/WhisperSubtitle-qwen3-asr-1.7b/`。只复用来源 manifest 哈希一致且全量校验通过的 stage；未知、过期、损坏、越界和链接路径均拒绝覆盖或删除。
- 专用包说明去掉两档 ASR 均已安装的通用描述，明确首次在“模型与参数”选择 1.7B；默认仍为 Turbo，未安装模型不可选。标准说明和完整版校验文件不变。
- ZIP 和独立 SHA256 使用专用名称，不被日常标准 ZIP 清理规则移除；验收后清理可再生 stage。

## 验证

- Python 全量 **560 项及 2 个 subtest** 通过，打包／工作区清理定向 **40 项**通过；`corepack pnpm check` 通过，Web **173 项**，仓库卫生、模型／Preset 投影、样式、格式、Lint、TypeScript 均通过。
- 全量测试曾发现旧清理夹具独立复制 manifest 工具后无法导入应用源码；改为仅选择模型分支延迟导入，保持旧 manifest 工具的纯标准库独立执行能力，原测试未放宽。PowerShell 语法与非法路径拒绝也通过。
- 从专用 stage 启动冻结 Worker，真实中文夹具分别完成 command／EOF 两种退出流程，均成功生成 TXT 和 SRT。输出为“今天天气很好，我们一起测试中文语音转录。”，SRT 分为 0.080–1.680 秒与 2.000–4.560 秒两段；任务前后真实 metrics 激活监控，Windows HANDLE 分别约 **0.976／0.852 秒**完成，无后代残留。
- 专用 EXE 使用隔离 WebView profile，真实 Worker 握手并持续就绪；UI Automation 验证仅 1.7B 可选，Turbo 与 ASR 0.6B 均未安装且禁用，1.7B 选择状态生效。Host／Worker 双 HANDLE 约 **0.385 秒**结束，无残留，原标准版进程继续运行。
- ZIP **5,935 个成员**（manifest 内记录 5,934 个文件），逐成员读到 EOF 校验 CRC 并核对 SHA256／大小；模型目录恰为 1.7B 与共享对齐模型。除专用说明、provenance 和 manifest 外，**5,932 个文件**与标准版清单哈希完全一致，运行时和保留权重字节未变。

## 收尾

已运行 `workspace:clean` 预览和 `workspace:finish`；正式清理前再次全量校验标准版 **5,947 个文件**。清理派生 stage、构建／测试缓存及本轮隔离 WebView profiles，另外通过共用路径守卫移除本轮工具导入产生的 `tools/release/__pycache__`。清理预览首次遇到瞬时进程退出引发的 Path 空值，重跑通过；本轮没有扩展清理工具修改范围。

`workspace:size` 记录 **37.86 GiB，40,652,572,119 字节，50,376 文件**；dist 23.62 GiB，包含原标准版与用户明确要求保留的 10.045 GiB 专用 ZIP。保留用户的 `prompt/`、原标准版及其运行进程、模型、开发环境、Node 依赖和用户媒体／输出。清理后仅执行不写字节码的记忆与 Git 收尾，源代码、文档、索引与本日志一并独立提交推送。
