# B：可复现音频质量与资源基准

新增同一 benchmark 目录中的语料运行入口、指标模块、八类清单和开发说明。复用旧 golden 音频、Worker 协议编码、RSS／NVML 采样及 Windows HANDLE 检查，不另设转录实现，不改模型与 preset。原四预设 golden 门禁继续保留。

运行器逐素材冷启动生产 Worker，三格式输出，记录输入／参考／权重 SHA256、代码与环境、实际参数、CER/WER、无语音意外文本量、可确认的漏段及边界偏移、耗时／速率和峰值 RSS／显存。JSON 和 Markdown 可逐模型逐素材比较；无参考、模糊时间对齐及缺失设备指标均为 null。拒绝覆盖旧结果，失败停机保留诊断。

## 验证及边界

- 指标和运行器 6 项单测通过；编辑距离对所有短二元字符串与独立 DP 校验，覆盖混合文本、静音、漏识别、时间歧义、语料声明、报告对比及输出读取。全 Python 566 通过，2 subtest 通过。
- 本机三模型真实中英文及 120 秒静音共 9 例成功，均生成 TXT/MD/SRT，正常关闭 Worker。固定语音 CER=0、英文 WER=0；三模型静音意外文本字符均为 0。仅为这三段样本，不推断整体质量。
- 最终口径基线保存在忽略的 `tests/benchmark/runs/2026-11-04-quality-before/`；初次运行的探测返回值适配错误及指标归一化调整保留为本地诊断，不能作为候选性能提升。
- 无授权配乐旁白、混说、纯音乐、快速专业语音和长媒体的完整参考集；15 个模型／类别组合明确 blocked，未伪造验收。未测人工标注时间戳偏移。
- 每例冷启动峰值包含模型加载；NVML 设备显存含其他应用，进程显存不可用则 null。单次耗时波动不宣称性能改善。
- 后续最终运行时版本须同语料复验，并完成正式产物验收。
