# C：恢复前核验与多格式失败反馈

原恢复只看存在性，多格式写入遇错即退出且遗漏已成功路径。现保留单文件临时文件、fsync 和 replace，逐格式写入并汇总 `PartialOutputError`，携带成功路径与每个失败格式／原因。Worker 通过既有 progress 的 output_paths／message 和终态 failure_count 回传；部分失败仍由前端识别为失败，不改 Desktop IPC v1。重试继续经过原磁盘冲突与活跃任务预留门禁，不默许覆盖。

Host 原 inspect_output_paths 增加可选 valid/reason（配套前端使用 valid=true 才确认），阻塞 I/O 移入后台，流式核验 UTF-8、文本控制字符、SRT 序号和起止时间；空 TXT/MD/SRT 合法，超长单行明确不能确认。未增加公共 Worker 命令。TXT/Markdown 本就是可含任意普通正文的格式，此核验不证明正文未被人工编辑或识别正确。

恢复按原冻结 output 格式核对逐媒体清单；缺格式、缺文件、内容无效或无法确认均重新处理。用户明确 skipped 的媒体保持跳过。完成后输出缺失可恢复；没有可靠完整媒体清单的历史不能直接续跑。详情复用现有分区显示可用／需重跑／失败原因／明确跳过／尚无法确认，成功路径继续保留。原输出目录移动、不可写和占用仍由核验／写入错误／既有冲突管理报告。
