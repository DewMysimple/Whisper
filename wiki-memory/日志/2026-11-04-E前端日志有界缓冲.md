# E：前端日志内存上限

原 worker.log 无界数组追加且每条均重新解析／渲染。现保留最新 1500 条，每条最多 8000 字符；独立保留最近错误一条，超出窗口时仍可展开查看。日志清空同步重置偏移／错误／截断计数。固定绝对行号作为 memo 行组件 key，满窗后保留行不重建 DOM；自动跟随用偏移＋行数触发，解决满窗后长度不再改变的问题。正文只在复制／导出时拼接，不在每次渲染全量拼接。

复制／导出仍使用原 typed bridge，界面明确“当前缓冲区”与截断范围。Host 的既有完整会话日志来源保持兼容，本轮前端操作未冒称全历史导出，也未另建日志后端。该上限不等于整个 Host 会话日志也有界，不将前端变更宣称为全进程 RSS 优化。

## 验证

- Web check 全门禁通过，193/193 单测；样式 12/12 通过。
- 20000 条生产状态事件压力测试：保留 1500、偏移18500、最新行正确、任务数组不变、早期最近错误可见；追加后保留行 DOM 身份不变；复制／导出与缓冲完全相同，定位第20001行、滚动回调和清空通过。另覆盖十万字符单事件截断。
- Playwright 40/40：包括 D 新复核操作、原日志定位／人工滚动与自动跟随、浅深色／多宽度和复制入口。压力输入与 DOM 核验在组件环境执行，未将其冒称浏览器堆内存实测。
- 静态状态字符上限约 1200 万字符加一条错误；未测实际堆字节或整体进程 RSS 收益。
- 正式产物留待 F 后统一构建。
