# 标准便携部署与验收收口

用户正常关闭标准目录的旧版窗口后，确认 Host 和 Worker 已退出。通过旧版 5,948 项清单校验，暂留备份用于视觉对照。将已验收的 `dist/iteration-validation/` 候选移入标准目录，复核 6,562 项发布清单，EXE 与清单 SHA-256 均与已验收候选一致。

从标准入口用仓库 8.697 秒 WAV 实测 Qwen 1.7B CUDA/BF16。准备中取消后无输出，重试生成 102 字节 Markdown 并核对参考尾句。Host 和 Worker 正常退出，测试期间创建的后代进程全部回收。

Host 日志分别记录路径元数据检查、目录遍历和排序，并保留总发现耗时及独立的 Worker 探测指标。600 个 WAV 的递归目录在 Rust Host 发现逻辑上跑 30 次，三个阶段中位分别为 0.015、0.345、0.074 ms，P95 分别为 0.043、0.450、0.105 ms。文件数量和排序逐轮一致。复现 Worker 对照使用 `python -m tests.benchmark.run_media_inspection_benchmark`，参数见正式质量基准文档。

原串行 Qwen 1.7B 在 72.079 秒组合夹具的驻留实验中，第一段文本中位 2.116 秒、文件完成中位 7.623 秒，可能存在约 5.5 秒的预览提前量。5.323 秒生产路径夹具中，首段与推理结束几乎重合。首段耗时已纳入诊断，预览界面和节流尚未经可用性验证，生产路径继续通过现有进度事件反馈。

清单只在原文字换行会触发原生滚动条的情况下保留相同槽宽。使用受限的尺寸与文本观察，短路径和当前平台的滚动条规则按实际布局处理。96 DPI、1600×1000 的同窗口对照使用 239 字符长路径和 18 字符短路径，四卡、两个操作按钮和外框的位置和尺寸差均为 0 个物理像素。长路径显示省略号，覆盖策略完整可见，清单没有垂直滚动内容。真实系统 125%／150% 缩放以及原反馈视频仍未测。

Rust 格式检查、47 项测试和 Clippy 通过，3 项按原配置忽略。通用检查包含 Web 198 项，Playwright 45 项通过。再次以正式 Tauri Release 流程装配 Host 和前端，实际重新校验 6,562 个文件，两版清单中只有桌面 EXE 的文件哈希改变。最终 EXE SHA-256 为 `cb1aa938106d0537119b59f7e6a5617b2c9d24b8a3a1035206d4ae1a92118f29`，发布清单 SHA-256 为 `c5a2a7b7e773695eccf135a500ab695df03ed244c4e535cc062b3f881666268a`。

最终哈希对应的标准入口再通过真实 600 个 WAV 的目录导入。一次标准 EXE 日志记录 `path_check_ms=0.04`、`directory_walk_ms=0.42`、`directory_sort_ms=0.07`、最慢探测 4.89 ms、Worker 批次 179.73 ms。1,800 文件检查中清空并重新从资源管理器拖入同路径，449 ms 完成。第一次试验复用原 Explorer 选择时没有观察到拖放高亮，重新定位同目录后的独立复跑成功。

最终标准 EXE 实际以 Qwen 1.7B CUDA/BF16 运行同一短 WAV。准备取消阶段没有输出，重试生成 102 字节 Markdown、参考尾句匹配。目录测试和 GPU 测试的 Host／Worker 退出码均为 0，各自测试进程树全部回收。

执行 `workspace:clean` 及旧发布清理预览，再用 `workspace:finish` 复核当前 6,562 项并清除两份临时备份和构建缓存。`workspace:size` 记录 40,768,611,733 bytes（37.97 GiB）、50,803 个文件。标准便携版、校验文件、既有 Qwen 专用包、模型、开发环境和未跟踪 `prompt/` 继续保留。
