# 发布与模型管理

- `tools/release/build.ps1` 构建冻结 Worker、便携目录、ZIP、manifest、SHA-256 和 SBOM；`corepack pnpm release:build` 是默认便携版入口。仓库根目录 `buildStart.cmd` 可双击运行同一流程，构建当前本地源码并显示结果；它不自动拉取远程提交。NSIS 只由 `release:build:installer` 或显式传入 `-IncludeInstaller` 生成。
- 发布运行时不依赖 Python、Node.js 或 Rust；Worker、CUDA 用户态依赖、WebView2 要按发布布局验证。
- 模型使用 `_internal/models/large-v3-turbo/` 的直接离线快照；发布脚本负责版本一致性和产物清单。
- 正式交付只认 `dist/WhisperSubtitle/` 与 `dist/WhisperSubtitle.zip`；技术依赖进入 `_internal/`。`target/release` EXE 只用于开发编译，不是完整交付物。
- 可选安装介质隔离在 `dist/installer/`，setup 必须与完整 `_internal/` 相邻；模型位于 `_internal/models`，微软签名的 WebView2 x64 离线安装器位于 `_internal/distribution`。bundler 不下载前置依赖。

2026-09-26 最新完整便携版已通过 `buildStart.cmd` 纳入当前本地源码，包括 9 月 24–25 日的文件输出和启动区整改；完整清单、ZIP／校验和、冻结 Worker 协议与正式 EXE 生命周期验收通过。同日四预设旁白校准后再次全量重建；当前识别行为以 [[日志/2026-09-26-校准四预设并修复配乐旁白漏识别]] 的真实 Turbo、固定夹具和冻结 Worker 验证为准，旧 CUDA／CPU 记录仅用于追溯。不能混用旧冻结 Worker 与新前端／Host。便携版中文说明源为 `tools/release/user_guide.zh-CN.md`，应在 assemble 之前更新，不能仅修改已生成 dist 内的副本。

当冻结 Worker 和 stage 未变、仅修正 Web 或 Host 时，可直接运行 `tools/release/assemble.ps1`；它仍重新构建 Web／Tauri，再整体生成便携目录、manifest、ZIP 和 SHA256。2026-09-20 的错误文案修复曾按该流程重新组装并完整复验；任何类似更新都不能只替换成品 EXE。
