# 发布与模型管理

- `tools/release/build.ps1` 构建冻结 Worker、便携目录、ZIP、manifest、SHA-256 和 SBOM；`corepack pnpm release:build` 是默认便携版入口，NSIS 只由 `release:build:installer` 显式生成。
- 发布运行时不依赖 Python、Node.js 或 Rust；Worker、CUDA 用户态依赖、WebView2 要按发布布局验证。
- 模型使用 `_internal/models/large-v3-turbo/` 的直接离线快照；发布脚本负责版本一致性和产物清单。
- 正式交付只认 `dist/WhisperSubtitle/` 与 `dist/WhisperSubtitle.zip`；技术依赖进入 `_internal/`。`target/release` EXE 只用于开发编译，不是完整交付物。
- 可选安装介质隔离在 `dist/installer/`，setup 必须与完整 `_internal/` 相邻；模型位于 `_internal/models`，微软签名的 WebView2 x64 离线安装器位于 `_internal/distribution`。bundler 不下载前置依赖。
