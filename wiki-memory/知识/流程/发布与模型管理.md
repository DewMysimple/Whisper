# 发布与模型管理

- `packaging/build_release.ps1` 构建冻结 Worker、便携目录、manifest、SHA-256 和 SBOM，再由 Tauri 生成 NSIS current-user 安装介质。
- 发布运行时不依赖 Python、Node.js 或 Rust；Worker、CUDA 用户态依赖、WebView2 要按发布布局验证。
- 模型使用安装目录相邻的直接离线快照；发布脚本负责版本一致性和产物清单。
- `dist/release` 只在明确执行完整发布时生成，不维护独立旧版本；target Release EXE 是开发验收入口。
