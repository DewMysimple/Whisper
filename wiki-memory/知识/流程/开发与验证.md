# 开发与验证

常规验证：

```powershell
python tools/codegen/generate_model_catalog.py --check
python tools/codegen/generate_preset_catalog.py --check
python tools/maintenance/check_repository_hygiene.py
corepack pnpm check
corepack pnpm check:styles
.\whisper_env\Scripts\python.exe -m pytest -q
python wiki-memory/工具/memory_lint.py index
python wiki-memory/工具/memory_lint.py check
```

UI 开发入口：`corepack pnpm web:dev` 提供浏览器/mock bridge 预览；根目录 `runStart.cmd` 会从脚本所在目录启动同一预览并打开浏览器。`corepack pnpm desktop:dev` 由 Tauri 自动启动同一个 `127.0.0.1:1420` Vite/HMR 服务并连接真实 Worker，需要 Rust/Cargo 工具链。端到端测试默认使用独立 4173 预览端口，若有其他本地预览占用，可用 `WHISPER_E2E_PORT` 指定未占用的高位端口再运行 `corepack pnpm e2e`；不复用来源未知的旧预览服务。正式构建仍使用静态 `apps/web/dist/`，不依赖开发服务器。

系统 Python 未安装项目依赖时，应选择当前已安装工程的虚拟环境解释器，不把纯导入失败当作代码回归。涉及 UI 时补充 `corepack pnpm e2e`；涉及 Rust Host 时运行 fmt、test 和 clippy；涉及桌面产物时补充 Tauri Release 构建和启动烟测。桌面烟测必须确认受控 Worker 子进程持续运行并已通过握手，不能只检查桌面 EXE 未退出。涉及 GPU、依赖、模型或输出行为时，必须增加真实媒体、四 preset、冻结 Worker 和必要的 benchmark/golden 验证。

## 修改后的提交与推送

每完成一次仓库修改任务并通过对应验证，必须立即创建独立 Git 提交并推送到当前分支的远程。推送失败时如实报告原因，保留本地提交，不使用强推或历史改写；提交前确认范围外的用户改动未被混入。

Golden 只能在明确接受行为变化后更新；benchmark 至少区分冷进程和暖系统缓存。测试结果必须写入对应任务日志，不凭计划补写结果。

`check:styles` 已纳入 `check`，先运行检查器的 10 项测试，再由 PostCSS 递归检查 Web 源码 CSS。任务、Worker 日志、模型／硬件工作台与公共交互／文字组件样式强制按责任文件归属，同条件下不得重复选择器（包括选择器列表中的单项）或属性，不得使用 `!important` 和旧页面祖先变体；禁止全局 button 的 transform／translate／scale 改变公共卡片命中区域；其他旧 CSS 继续使用保守的同规则属性覆盖检查，`--fix` 只清理可确定被覆盖的旧声明，不修正归属问题。整理级联时应先保留旧样式，再在相同 DOM 上比较修改前后的计算属性，并覆盖浅色／深色与支持的窗口宽度；不能仅凭构建成功判断样式等价。

`e2e/interaction-contracts.spec.ts` 在真实浏览器中采样开始按钮的底边悬停位置和渐变、按下过程的卡片边界，覆盖鼠标与 Space、浅深主题和减弱动画偏好；历史标题／时间层级与底部覆盖 620–1920px 窗口、12／18px 内容字号、图标点击区域、二次确认取消与详情焦点；外观预览按钮覆盖浅深主题、悬停和按压动画帧、固定命中区域、实际 Tab／Space 操作、返回工作台及减弱动画。界面截图应通过实际主题入口切换，等待过渡完成或禁用截图动画，避免把切换中间态当作最终配色。

`e2e/readable-diagnostics.spec.ts` 检查浅深主题、620–1728px 窗口和工作台／日志字号独立响应，验证正文列对齐、长日志换行、空白保留、可选取及原责任规则直接生效。`WorkerLogsView.test.tsx` 对复制和导出调用的实际参数检查原始中英文日志、未结构化错误和空白不变。

`e2e/configuration.spec.ts` 验证模型／参数工作台、非法编辑反馈、配置隔离与刷新保存、提交快照和主题／宽度；`tests/test_public_parameters.py` 验证全部 36 项公开选项从协议冻结到引擎适配器、非法字段边界与已安装 faster-whisper 签名。`generate_preset_catalog.py --check` 同时检查类型／默认投影和 IPC 的 ParameterOverrides。GPU benchmark 读取 Worker 实际 outputs，不能硬编码输出子目录。

硬件设置验证须覆盖省略与显式零线程、实际设备能力与不支持错误、提交冻结及模型缓存重用；`tests/worker/test_runtime.py` 检查真实 FasterWhisperEngine 构造器接收到的设备／精度／线程。真实验收用已有 Turbo 顺序执行默认四 preset、CUDA 混合 INT8 和 CPU INT8，避免并发占用模型；默认中文结果与既有 golden 比较。Rust 的真实 GPU 忽略用例可用 `WHISPER_SUBTITLE_GPU_EXECUTION` 传入 JSON 执行设置，验证 Host 到 Worker 完整路径。
