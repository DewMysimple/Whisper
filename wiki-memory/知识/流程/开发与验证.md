# 开发与验证

常规验证：

```powershell
python -m pytest -q
python -m whisper_subtitle check
corepack pnpm check
```

涉及 UI 时补充 `corepack pnpm e2e`、Tauri Release 构建和桌面启动烟测。涉及 GPU、依赖、模型或输出行为时，必须增加真实媒体、四 preset、冻结 Worker 和必要的 benchmark/golden 验证。

Golden 只能在明确接受行为变化后更新；benchmark 至少区分冷进程和暖系统缓存。测试结果必须写入对应任务日志，不凭计划补写结果。
