# 开发与验证

常规验证：

```powershell
python scripts/generate_model_catalog.py --check
python scripts/generate_preset_catalog.py --check
python scripts/check_repository_hygiene.py
corepack pnpm check
.\whisper_env\Scripts\python.exe -m pytest -q
python wiki-memory/工具/memory_lint.py index
python wiki-memory/工具/memory_lint.py check
```

系统 Python 未安装项目依赖时，应选择当前已安装工程的虚拟环境解释器，不把纯导入失败当作代码回归。涉及 UI 时补充 `corepack pnpm e2e`；涉及 Rust Host 时运行 fmt、test 和 clippy；涉及桌面产物时补充 Tauri Release 构建和启动烟测。涉及 GPU、依赖、模型或输出行为时，必须增加真实媒体、四 preset、冻结 Worker 和必要的 benchmark/golden 验证。

## 修改后的提交与推送

每完成一次仓库修改任务并通过对应验证，必须立即创建独立 Git 提交并推送到当前分支的远程。推送失败时如实报告原因，保留本地提交，不使用强推或历史改写；提交前确认范围外的用户改动未被混入。

Golden 只能在明确接受行为变化后更新；benchmark 至少区分冷进程和暖系统缓存。测试结果必须写入对应任务日志，不凭计划补写结果。
