# 启动与模型路径

开发检查：

```powershell
python -m whisper_subtitle check
```

开发编译验收可运行 `apps/desktop/src-tauri/target/release/whisper-subtitle-desktop.exe`；完整便携版必须从 `dist/WhisperSubtitle/WhisperSubtitle.exe` 启动，并保留同级 `_internal/`。CLI 示例：

```powershell
whisper-subtitle transcribe "input.wav" --preset cn
whisper-subtitle transcribe "input.mp4" --preset en2 -o "output"
```

模型路径由 `AppPaths` 和 `ModelLocation` 解析。发布态 Host 优先查找 `_internal/worker` 并注入 `_internal/models`；开发态继续检查工程模型、`WHISPER_SUBTITLE_MODEL_DIR`、`HF_HOME` 和用户缓存。模型缺失时先执行 `check`，不要让 UI 自行猜路径。
