# 启动与模型路径

开发检查：

```powershell
python -m whisper_subtitle check
```

桌面验收运行 `apps/desktop/src-tauri/target/release/whisper-subtitle-desktop.exe`。CLI 示例：

```powershell
whisper-subtitle transcribe "input.wav" --preset cn
whisper-subtitle transcribe "input.mp4" --preset en2 -o "output"
```

模型路径由 `AppPaths` 和 `ModelLocation` 解析，优先检查便携目录、`WHISPER_SUBTITLE_MODEL_DIR`、`HF_HOME` 和用户缓存。模型缺失时先执行 `check`，不要让 UI 或 Host 自行猜路径。
