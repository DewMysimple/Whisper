# 已知故障与待授权事项

排障时先区分：协议/生命周期错误、模型/CUDA 环境错误、输出路径冲突、UI 状态错误和识别质量边界。优先查看 Worker 生命周期日志、结构化错误码、模型路径和对应测试，而不是解析展示文案。

当前暂缓且不得自动实施的方向：软件内下载模型、Qwen3-ASR 接入、自定义标题栏、开发者 UI 调节分支和正式工程瘦身。它们的原始讨论仍在 `历史归档/40-第四阶段-UI成果回迁与正式应用/工程讨论与待办/`。

真实模型补测、系统通知点击复验和复杂 code-switch 质量验证必须有用户授权和独立测试记录。
